# 单机战斗框架迁移现状与剩余对标项

基线：ET10 `743c635dd5b0f6f6bab549c0093382c85f3f8307`；结论按当前工作区源码核对。这里比较框架机制，正式玩法和 Unity Player 发布不计入迁移范围。

## 已经迁到哪一层

| ET10 机制 | 当前项目的对应实现 | 仍有差别 |
| --- | --- | --- |
| `Room`、`FixedTimeCounter`、权威 updater | `BattleRoom` 持有世界、时钟、更新器和帧历史；TEngine FSM 驱动初始化、开始、进行、结束；本地权威按 50ms 计划步进 | 有准备条件，正式入口只检查复用的 `main` 是否已加载；尚未接入独立战斗场景资源链路 |
| `OneFrameInputs`、环形 `FrameBuffer` | 开局固定玩家槽，缺输入沿用最近确认值；保留 1,200 帧输入、帧前快照和指纹 | 只处理本地待提交输入和已推进历史，没有未来帧收包及预测输入管理 |
| `Room.Update`、`LSWorld` 和 `LSUpdater` | 实时与回放共用 `BattleRoom.Tick`；写入输入后取帧前快照，再执行 Entitas 系统并递增世界帧号。世界有可恢复的稳定 ID、独立随机数和组件编解码；按 ID 遍历工具已开放 | Entitas 按系统树顺序执行；有顺序要求的系统显式选用 `GetEntitiesInOrder`，不会自动把所有 Group 按 ID 排序。正式玩法由 `BattleWorldSetup` 装配，生产 Battle Context 目前为空 |
| 录像、检查点、定位和变速 | 已有录像保存/读取、周期快照、恢复世界与系统树、向前和向后定位、1×/2×/4×/8× 播放 | 定位同步重演；正常播放已有分批追帧。项目会对账回放帧前指纹，当前发现分歧后仍执行当帧一次，再停止后续推进 |
| TrueSync | `Utility` 已有确定性标量、向量、朝向和独立随机数 | 当前迁入的是所需子集；793 项样本的 `RawValue` 对账通过，不代表全部数学 API 已移植 |

已有 [1,206 帧检查点重建记录](./单机战斗世界快照与重建分步执行方案.md) 和 [40 帧回放倍速及定点对账记录](./定点运算对账与单机回放倍速验收.md)。这些是框架案例，不代表正式玩法的确定性已经验证。原 [完整源码对比](./单机战斗框架与ET10源码完整对比.md) 保留当时的快照，本文以现有实现更新其中的世界和定点状态。

## 还可以搬的机制

1. **回放定位交给更新器分批追帧，是单机最直接的剩余对标项。** ET 的 [`JumpReplay`][jump] 同一检查点区间向前可以沿用当前世界，需要回退或跨区间时从快照重建，再交给[回放 updater][replay]重演。当前 [`BattleRoom.SeekReplay`](../../Assets/GameScripts/HotFix/GameLogic/Module/BattleModule/BattleRoom.cs) 每次都重建并在调用中同步执行，目标落在检查点区间末尾时最多执行 1,200 帧。可迁移的是调度思路：`定位请求 → 必要时恢复检查点 → 更新器分批执行 → 到目标帧后继续正常播放`。保持项目自己的帧前快照与目标帧已执行语义，先用 Demo 量测最长定位路径，再决定是否改生产代码。验收应对比真实 Tick 数、每次轮询的开销和目标帧指纹。
2. **进场和表现重绑等到实际接入再搬。** ET 把[场景准备][scene]、[单位表现初始化][view]和[回滚后通知][jump]从逻辑世界分开。项目已能等待 `isReady`，但尚未有独立战斗场景加载链路或世界替换后的表现重绑。独立场景与第一批真实表现出现时，再按这个顺序接入；不照搬 ET 的单位、相机、键位或场景资源。
3. **联机准备从本地双房间回环开始。** ET 完整联机还包含[按帧收集、补齐并广播权威输入][server]、[客户端预测][prediction]、[权威确认及分歧回滚][confirm]、[校时][clock]、[跨端 Hash 比较与快照诊断][hash]和[重连同步][scene]。项目已有回滚可用的快照与重建能力，但没有第二份预测状态、权威输入纠正链路和跨端一致性证据。进入联机阶段时，可先在可移除 Demo 内用同一套 `BattleWorld` 跑本地权威与预测两份状态，注入一帧不同的权威输入，验证回滚后的逐帧指纹一致；再接网络传输、会话及重连。

当前定位：**单机 Lockstep 底座已完整到可以接入 Entitas 玩法的程度；与 ET10 仍存在回放调度、场景表现和联网语义差异。** 回放 Hash 分歧的当帧执行边界属于项目自身的行为决策，不算待迁 ET 功能。全量 TrueSync、ET 实体系统、Fiber 和网络包均无须整包迁入当前单机阶段。

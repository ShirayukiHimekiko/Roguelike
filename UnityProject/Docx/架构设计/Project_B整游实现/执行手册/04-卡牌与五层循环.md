### 核心 C# 方法

```csharp
// BattleDeck.TryDrawOne。抽前先检查上限，不消耗随机数和牌库。
internal bool TryDrawOne(int handLimit)
{
    if (_hand.Count >= handLimit) return false;
    if (_draw.Count == 0)
    {
        if (_discard.Count == 0) return false;
        _draw.AddRange(_discard);
        _discard.Clear();
        Shuffle(_draw);
    }

    int last = _draw.Count - 1;
    _hand.Add(_draw[last]);
    _draw.RemoveAt(last);
    return true;
}
```

```csharp
// PlayCardSystem.Execute。先从命令队列按序取一个合法会话的请求。
internal PlayResult Execute(in PlayCardCommand cmd, long tick)
{
    if (_receipts.TryGet(cmd.Id, out PlayResult previous)) return previous;
    if (!_deck.TryGetInHand(cmd.CardId, out BattleCard card))
        return _receipts.Record(cmd.Id, PlayResult.CardUnavailable);
    if (!_cost.TryQuote(card, out int debit))
        return _receipts.Record(cmd.Id, PlayResult.InsufficientFee);
    if (!_effects.TryPlan(card, cmd.Target, tick, out CardPlayPlan plan))
        return _receipts.Record(cmd.Id, PlayResult.InvalidTarget);

    _cost.DebitQuoted(debit);
    _deck.CommitPlay(card.Id, plan.CompletionToken, card.AfterPlay);
    _effects.ApplyPrepared(plan); // 不再做普通业务失败的分支。
    return _receipts.Record(cmd.Id, PlayResult.Played);
}
```

`TryQuote` 同时计算当前减费与可用性，返回本次报价；同一 Tick 处理下一张时重新计算。上文 ApplyPrepared 依赖预检通过、同一线程、不中途通知；如果遇到不可恢复错误，按故障战场丢弃未提交批次。早于定时抽牌处理命令派生的即时抽牌；定时抽牌下一次能抽时仍按自己的计时状态。随机流按命名用途分出洗牌、商店、奖励等分支，保存各流初始 seed 和当前状态。分流序号由固定表指定，不使用字符串 GetHashCode。采用以下实现，初始 state 可为零，记录算法版本。
```csharp
// Contracts/RandomStream.cs。以同一值流驱动一次完整洗牌。
internal struct RandomStream
{
    private ulong _state;
    internal RandomStream(ulong seed) { _state = seed; }

    private uint NextUInt()
    {
        unchecked
        {
            ulong z = (_state += 0x9E3779B97F4A7C15UL);
            z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9UL;
            z = (z ^ (z >> 27)) * 0x94D049BB133111EBUL;
            return (uint)((z ^ (z >> 31)) >> 32);
        }
    }

    internal int NextInt(int maxExclusive)
    {
        if (maxExclusive <= 0) throw new ArgumentOutOfRangeException(nameof(maxExclusive));
        uint bound = (uint)maxExclusive;
        uint threshold = unchecked(0u - bound) % bound;
        uint sample;
        do { sample = NextUInt(); } while (sample < threshold);
        return (int)(sample % bound);
    }
}

// BattleDeck.Shuffle，在备牌与弃牌重洗时共用。
private void Shuffle(List<BattleCard> cards)
{
    for (int i = cards.Count - 1; i > 0; i--)
    {
        int j = _shuffleRandom.NextInt(i + 1);
        (cards[i], cards[j]) = (cards[j], cards[i]);
    }
}
```


核心效果在规划器按卡类型分派。CommitPlay 若有完成令牌，Pending 保存最终去向；消耗进入 Exhausted，临时牌离场或用尽时销毁，只有普通牌可进入 Discard。

// CardEffectPlanner。所有 TryPlan 只改计划临时区。

定时抽牌维护 `remainingDrawTicks`，在未满手且牌区可供抽取时减 1，到零抽一次并重置间隔。满手保留剩余间隔，补位后继续。初始 Hand、普通初始牌、临时牌分别用固定卡实例 ID 规则，避免 UI 以卡种当实例。

### 验收

- 5 张起手可重复，满手点击/到时不会推进牌库或 RNG，空库只洗弃牌，待完成卡不被抽回。
- 任意费用不足/非法格、在暂停或旧战斗发出命令，费用和牌区不动。重复有效 command id 同回执只扣一次；两个命令争同一张只有先受理者成功。
- 用一张单位、一张建筑、一张技能、一张强化卡从真实 UI 操作，查生成、命中、持续期和足额扣费。卡造成伤害时复验同一固定阵容账本顺序。
- 期间获得普通新卡，当前卡池不受影响，下战可抽。临时牌/星级离场回收。
- 使用阶段 08 固定种子运行禁用卡牌版本，原摘要不变。

灰盒牌表固定 6 张可识别实例，前三类各至少一张、强化至少一张。建议初始费用 3；单位牌费用 1、建筑 2、技能 2、强化 1；定时抽牌每 60 Tick，临时建筑寿命 120 Tick。值只用于测试。另做 11 张牌夹具，在手牌达到 10 时读取 Deck.Count、抽牌剩余间隔与随机流值，放出一张后观察恢复。

```csharp
// RoundEndRules 的候选步核心。剩余时间为 RoundClock 的整数预算。
internal EndFacts Evaluate(in RoundSnapshot round)
{
    bool timedOut = round.RemainingBudget <= 0;
    bool exhausted = !round.PlayerHasLiveNonBuilding &&
        !_cards.HasAffordableReachableCard(round) &&
        !_scheduledPlay.HasPlayablePathBeforeDeadline(round);
    return new EndFacts(round.CoreDestroyed, timedOut, exhausted);
}
```

将阶段 03 `BattleTickResult.Ended` 扩展为读取 `EndFacts.ShouldEnd`，按击破、超时、耗尽顺序取显示原因。当终止时 FinalTick 读已提交候选，避免 UI 关闭时重算。待定的提前结束条件以 [规则决策表](../05-规则决策表.md) 为限；可达性由手牌、能抽到的牌库/弃牌和已排定回费/临时发牌的数据提供，临时点位不可部署不触发提前结束。未来抽牌的可用输入 Tick 至少是 DrawTick+1，Late 回费亦须等下一输入 Tick。灰盒只启用能提供明确排程的效果。

```csharp
// RoundScoring.Grade。规则表预排序为 S、A、B、C、D、E、F；阈值单位百分之一。
internal GradeRule Grade(long towerDamage, long directBreakPoints, long scoreBase)
{
    long numerator = checked(towerDamage + directBreakPoints);
    long scaled = checked(numerator * 100);
    foreach (GradeRule row in _gradeRulesDescending)
    {
        if (scaled >= checked(scoreBase * row.MinHundredths))
            return row;
    }
    throw new InvalidOperationException("评分表需要 0 起点和正分母。");
}

// RoundSettlement.Decide。先从规则表计算 Rating/HonorDelta，并裁剪荣誉。
internal RoundBranch Decide(int layer, bool coreDestroyed, int honorAfter)
{
    if (coreDestroyed && layer == 5) return RoundBranch.Win;
    if (honorAfter <= 0) return RoundBranch.Lose;
    return coreDestroyed ? RoundBranch.ChangeHero : RoundBranch.NextRound;
}

// RunSession.AcceptBattle，Build 对所有输入做预检，Commit 一次写入。
internal void AcceptBattle(in FinalBattleSnapshot result)
{
    if (!MatchesActiveBattle(result.Round, result.BattleId, result.Tick)) return;
    if (_settlements.Contains(result.Round)) return;

    RoundSettlementPlan plan = _roundRules.Build(result, _state);
    _state = plan.NextState; // 计划带已入账 RoundId、下个入口和新敌方状态。
    PublishRoundReceipt(plan.Receipt); // 发布前完成写入。
}
```

### 验收

- 准备双击/装配失败重试，恢复/部署/扣库存都只一次。恢复规则用 100 上限、当前 40 的普通塔含舍入样本检查。
- 评分测试覆盖阈值两侧、拆塔/核心独立积分、超量伤害、抵抗及连带归因，并用相同战果重送一次。
- 第 1 层全局第 6 回合击破后，第 2 层首战是第 7 回合，按第 7 回合规则；玩家牌组/局累计值保留，下一英雄状态依其配置初始化。
- 前四层击破且荣誉降至 0 → 失败并记击破；第五层同组合按评审默认获胜。超时与核心归零同 Tick 仍只结算一次。
- 有可达定时回费或能在截止前从牌库抽到零费卡则继续；最后输入 Tick 才到的抽牌/回费，D+1 已关输入则允许结束；暂没有放牌点不触发提前结束；取消时无评分和奖励。
- 用五个可击破的固定模板跑一局，每层最短一战，检查结果序列 `ChangeHero × 4 → Win`。另设置首层初始荣誉为 10、评分为 F 的超时战，验证荣誉归零进 Lose。两者均经 EndGame 返回大厅。

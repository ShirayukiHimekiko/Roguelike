# Project B · 经验等级与敌方成长

2026-11-15 · 设计评审稿

修订 5989 L127–132、L238–252、L348–350、L535–553。双方回合固定经验，高评分可以更多，玩家可购经验，敌方升级增加格位并领塔。白板显示购买经验也给敌人以及固定回合海克斯，正文无对应完整规则。[需求 18](../../游戏设计/功能需求/18-经验与等级.md)

## 发放方案

评审默认双方获固定经验，高评分附加只给玩家，玩家付费经验只给玩家。成长规则提供双方起始等级、经验曲线、上限、费用上限或格位回报，需完整表。达到上限后丢弃溢出，按规则异常上报负经验或非递增阈值。每个赠塔原因带来源；升级发塔和回合表达成同时成立时可分别给同模板的不同实例，数量可区分。

```text
grant = planXp(owner, base + eligibleBonus, sourceId)
for each levelCrossedOrdered:
    attachLevelRewardsAndFlags(owner, level)
attachConfiguredRoundGrantsIfRecipientStillPlays()
commit(grant, walletSpendIfPurchase, levelRewards, recipientGrants)
```

玩家跨过 3/7/12/18/24/30 则生成独立海克斯机会，有中间阈值的一次性全记，按升序；清层、任务另有原因。敌方升级在下次准备前改变当前层地图允许格并把塔写入背包。清层结算可记旧层所得经验；旧层直接退场时不投递赠塔、物品或 Buff。下一层初始等级和格位由 LayerDef 给出。

**验收**　从 2 级跨到 8 级同笔发 3/7 两张机会。相同回合固定发塔和升敌等级发塔均有不同来源。已关闭的商店窗口请求不能扣钱买经验。

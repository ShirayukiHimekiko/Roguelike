# Project B · 海克斯重置

2026-11-15 · 设计评审稿

修订 5989 L133 明确通过海克斯重置已有海克斯，随机或手选。觅目标、单双边和副作用未定。本稿给出原型规则，以稳定持有实例和来源撤销实现。[需求 41](../../游戏设计/功能需求/41-海克斯重置.md)

## 玩法提案

重置令由一个明确的海克斯效果发放。令声明目标角色、能选的持有类别/稀有度、替换池、范围以及是否可重置自身。评审默认仅重置玩家持有的单个海克斯，配对历史及敌方已持有半边保留。若做成整对重置，必须声明两个有效持有者及撤销/授予同批条件，旧层配对敌方已离场的历史项不能参与成对重置。手选指选择被替换的已持有实例，新内容仍按配置随机；未来支持手选新内容时另加模式。

从已持有来源只撤销可逆持续贡献，已经消费的金币和物品保留。绑定任务按 [任务规则](26-海克斯与羁绊绑定任务.md) 退场。新海克斯获得新的持有 ID 和来源。首版排除自身与同定义重抽，替换池不足时保留重置令，允许玩家继续其他局级操作。随机重置由指定稳定顺序过滤后再取局部游标。失败不推进 RNG、任务或撤销原效果。

```text
target = selectEligibleHeldHex(token, optionalPlayerChoice)
next = drawReplacement(target, token.rule, localRng)
commitOnce(revokeOldSource, detachOldTask, grantNewHex, consumeToken)
```

**验收**　曾在上一层给敌方的半边已经归档，重置玩家半边仍有效且不会给新英雄加未选过效果。新内容不合法时，旧卡面、来源和任务均保留。

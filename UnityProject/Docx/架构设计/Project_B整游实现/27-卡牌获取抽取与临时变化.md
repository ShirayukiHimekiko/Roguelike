# Project B · 卡牌获取抽取与临时变化

2026-11-15 · 设计评审稿

原案 L55–77、L161–191，白板 1 补“抽 X”。现有 [卡牌 01](../Project_B战斗与局内系统/01-卡牌实现方案.md) 管卡实例、牌区、合成。下列规则供多来源统一接线。[需求 40](../../游戏设计/功能需求/40-局内卡牌获取.md)

| 入口 | 执行 |
| --- | --- |
| 商店、任务、海克斯、法球授予普通卡 | 交卡牌域 `CardGrant(SourceId, CardDefId, Star, Count)`。加到局级永久牌组，当前 Battle 的参战集合不变 |
| 羁绊生成临时卡 | 在战斗按明确定时/触发给手牌，CardInstance 单独标寿命。本稿扩展口径：满手时本次发牌跳过且报告；打出后进入回合内移除区，禁止洗回 |
| 永久升星/合成 | 评审默认在局级安全窗执行，合成同名同星两实例升一星，保留唯一新实例。奖励指定实例及上限。满星、被锁定或无合法目标时预检拒绝，绝不先消费奖励 |
| 临时升星 | 场内把修正挂卡实例，一律先读实际星级、上限与配置档。回合回收时删除临时星修正，不向永久牌组回写 |
| 抽 X 与定时抽牌 | 先按已接受的指令及效果动作稳定顺序执行确定的即时抽牌；再做单次定时抽牌；后续效果生成的抽请求按其已声明阶段处理。刚出而载荷未结束的牌处于待完成区，不参与洗回。抽 X 到上限为止，多余不积压，定时抽牌因满手保持到期。新增卡下一 Tick 可出 |

```text
buildRoundDeck(eligiblePersistentCards)
play: moveToPending → commitCostAndPayload → finishToDiscardOrExile
draw: if handAvailable then refillEmptyDeckFromDiscardThenDraw
export: persistentRemovals + persistentGrantFacts + originalStarForTemporaryUpgrade
```

**验收**　唯一在结算中的牌不会抽回自己。抽 2 时只剩一手位，只抽 1，随后定时抽仍待空位，下一 Tick 才能使用该牌。合成后卡配置保持原 CardDefId 的羁绊种类。

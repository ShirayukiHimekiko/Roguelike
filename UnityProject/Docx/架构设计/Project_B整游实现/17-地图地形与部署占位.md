## 数据和统一查询

`MapRuleData` 包含定点原点、格宽、大小、圆心、半径、格地形 ID、塔格 Anchor/Footprint、分层与方向掩码。格的点归属采用半开区间和数学 floor，负坐标也一致。配置提供玩家/敌方出生区及格解锁次序。部署、站立、通行、受击体、方向保护分别查询。围栏恰好相切按 “常规单位在外” 处理，评审建议考察整个部署足迹或圆形体积而非仅中心。

| 查询 | 参数和消费者 |
| --- | --- |
| `CanDeploy` | 单位放置完整几何、阵营、地形限制、占位及围栏例外。UI 调用同一规则的只读预览，Tick 处理权威判断 |
| `CanStand / CanTraverse` | 地形及当前阻挡快照，按拓扑版本同步 RVO2 的固定与动态障碍。围栏只在配置为实体墙时生成移动障碍 |
| `CanTarget / HitShape` | 可交互目标和碰撞形状仍由命中权限及目标模块判断 |
| `CanPlaceTower / IsScreening` | 有标签的可用格和塔足迹做全量校验，核心保护走独立方向映射 |

准备布局只由局级部署域提交，World 独占战斗内动态占位，变化会升级 `TopologyRevision`。地形效果按目标进入、停留、退出的阶段边界增减来源，重新算脏属性。地形投影和渲染地块共 ID，素材缩放不改变逻辑边界。

**验收**　普通单位跨围栏半格时拒绝投放，内圈特许单位仍需满足地形和占位。塔拆完仍保持原部署范围。障碍更新后旧路线和旧索敌结果须由版本重算，抵抗塔保留复活占位时按核心专项判断屏障。

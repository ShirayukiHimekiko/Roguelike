# Project B · 伤害公式与破损归因

2026-11-15 · 设计评审稿

原案 L213–236、L254–270、L505–511 有攻防属性、元素塔及破损积分；防御公式、伤害下限和技能穿透待策划确认。沿 [独立 HitResolver](../03-HitResolver独立模块方案.md) 的定点候选、同段去重、工作生命、授权和稳定提交；这里只补玩法公式与归因。

## 样本规则

`DamageRule` 先区分物理、元素/魔法与显式真实伤害。评审样本用 `calculated = max(0, EffectiveAttack × Coefficient + Flat - EffectiveDefense)`，真实伤害配置 Defense=0。物理读物防，元素/魔法读魔防，系数与加法沿定点及一个明确的舍入点。未定护甲曲线可替换 `DamageRule`，保留目标权限、计算伤害、实际伤害输出合同。攻击间隔与持续效果用整数 Tick 和明确起始步。零伤害但合法命中占本段资格；权限拒绝和免疫沿原命中方案处理。

| 事实 | 消费 |
| --- | --- |
| `ResolvedHit` | 先前 HP、计算值、实际扣血、剩余 HP、归因源/阵营；评分、技能充能、任务分别订立它们需要的统计 |
| `DirectTowerBreak` | 单实例生命首次归零。普通塔走积分和抽球，核心走积分与清层，抵抗塔走恢复标记 |
| `CollateralTowerBreak` | 核心击破后逐个标注原因，评审默认计作场地清理，不影响直接拆塔数、积分及法球 |
| `Expired / Reclaimed` | 到期/回收清理，归还占位并解除来源，不发击杀事件。回收时间表见回合方案 |

```text
resolved = resolver.resolve(orderedIntents, eligibilitySnapshot, hitLedger, DamageRule)
precheckAllChanges(resolved)
units.apply(resolved); buildings.apply(resolved)
world.collectCommittedFacts(actualDamage, breakCause, lastSource)
```

**验收**　5 HP 目标连续受计算值 3、4，统计 3+2，只产生一个击破，后续同批直伤不重复计分。装备增加攻击应用到卡召唤的每个单位，装备的回费限次仍以卡源计。

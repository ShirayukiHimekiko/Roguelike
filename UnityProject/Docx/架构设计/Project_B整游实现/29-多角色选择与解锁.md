修订 5989 L49–51 对多角色标“暂无”；L531–533 已定义角色初始牌组、属性、技能与解锁字段。本篇提供扩展首版流程。初始角色直开可用。[需求 36](../../游戏设计/功能需求/36-多角色选择与解锁.md)

## 交互与数据

大厅从 Profile 拿角色持有集合。从已发布 `RoleDef` 读取锁定条件、成本、初始牌组、费用/金币/荣誉、技能和展示。已拥有项可预览、选择、进入难度页；未拥有项显示要求，可用一次解锁命令。条件来源采用已落盘的永久事实，例如已通过的难度或已经解锁节点，由策划确定。角色解锁无成本也要校验其条件并一次提交。

```text
unlock(role, expectedProfileRevision):
    checkPermanentConditionAndWallet()
    commitProfileOnce(spend, appendOwnedRole)
select(role): updateLobbyDraft()
start(): freezeValidatedRoleLoadout()
```

资源 F 的实际启用与联动见 [荣誉勋章](32-荣誉勋章.md)。默认无免费永久奖励附加，若增加由档案同批写入。角色选择在开局冻结，选错或内容下架时可回到选择页再确认。活动 Run 不允许切换角色。

**验收**　条件达成且余额足够时扣一次解锁费；连点返回原结果。切换角色更换全部开局值和技能种子，旧下拉选择不能通过新版准入。

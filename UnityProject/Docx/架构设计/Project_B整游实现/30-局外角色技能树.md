# Project B · 局外角色技能树

2026-11-15 · 设计评审稿

修订 5989 L41–43、L465–473 的角色技能树为单根，使用 F。资源章节将 F 标暂时不做，首期 Profile 账本与界面可在扩展后一起启用。本篇定义扩展后的装配合同。[需求 34](../../游戏设计/功能需求/34-局外角色技能树.md)

## 定义、存储和派生

`RoleSkillNode` 指向所属角色、前置节点、F 成本、效果/技能修正。原案角色技能表有技能能量与回费参数但未给节点完整字段。补结构时沿用 Profile 通用树购买事务，配置独立校验每角色仅一个根及前置无环，不复用卡星解锁的含义。

角色已拥有，前置和余额满足时才能激活。档案持永久节点 ID，允许重建角色读模型。开局将选定角色节点编译为 `SkillLoadout`，有优先级的主动技能替换按配置校验唯一，不同效果参数按各自修正规则合成。树只影响以后的 Run，场内技能系统消费定好的阈值、回复等，不读取档案。原型单角色基础技能可独立联调。

```text
planActivate = CanUnlockRoleNode(profile, role, node)
commit(FDebit, NodeAdded)
runSkill = BuildSkillLoadout(roleDef, ownedNodes, rules)
```

**验收**　给 A 角色点节点，不改变 B 角色和进行中的局。升级降低能量上限后，新局按新上限显示和充能。角色树、解锁共用 F 时低余额不能同批透支。

# Project B · 通用效果与生效范围

2026-11-15 · 设计评审稿

修订 5989 L89–121、L223–230、L372–405、L519–529 的效果载荷被卡牌、物品、装备、羁绊、科技、海克斯、任务、普通/元素塔等共享。沿 [Buff 06](../Project_B战斗与局内系统/06-Buff实现方案.md) 的来源模型和 [技能 07](../Project_B战斗与局内系统/07-技能实现方案.md) 的效果编排细化通用合同。

## 可编排的效果

配置编译为有序的 `EffectDef(Trigger, TargetScope, Phase, Lifetime, Actions, RepeatBudget)`。每种动作绑定唯一拥有者（费用、卡牌、Buff、召唤、伤害、成长、票据等）。数值均验证单位、范围、目标和阶段。有序动作样本限定为数值动作与少量明确条件，复杂行为由专用函数按 ID 扩展。动作自触发及奖励链必须有可验证的次数上界。

| 类型 | 生命周期与撤销 |
| --- | --- |
| 即时资源、赠卡、直接伤害、任务进度 | 创建已提交事实和对应的子来源身份，消费标记插入同批。后续来源卸下时保留已发生事实 |
| 常驻玩家/敌方来源 | 局级持有者生成导入种子，按 Run 或 Layer 范围激活。仅移除该 SourceId 的贡献，重算受影响属性 |
| 回合或单位寿命内的效果 | BattleWorld 按 Tick 到期，清理单位或场次时统一结束。到期影响应在输入合法性采样前应用。强化卡“持续一整轮战斗”评审默认即本场回合至收尾；跨回合强化需要明示为局级来源 |
| 特殊效果：光环、地形、装备 | 分别按格邻域、地形进出和卡实例生成稳定来源，约束目标域，专用模块负责决定何时添加/撤销 |

```text
plan = resolveTypedActionHandlers(valueFacts, targetSnapshot, sourceId, limits)
validateAllOwners(plan)
commitPatchesThenFacts(plan)
```

资源和效果互相触发时使用明确阶段与次序，例如由命中反应生成的新攻击归下一 Tick；合计费用上限由资源域夹紧。即时局级效果用于当前店面已经持有状态，进入下一战才创建场内投影。禁止通过 UI 或外部事件路由跳过正式动作。

费用上限从角色基础和冻结的科技、等级、物品、海克斯、羁绊及任务贡献计算。准备回满；场内增加上限是否同步补当前费用由动作声明，评审默认只改上限。消耗按实际扣除记，恢复裁到上限。羁绊和海克斯固定/概率触发以 `(RoundId, EffectId, SourceInstanceId)` 记次数，卡牌回费按卡实例与效果，装备按卡实例与所装装备，物品评审默认按持有实例；均在回合重置。同一牌洗回不重置，概率落空不占额度，获准的恢复动作即使被上限裁为零也消耗本次触发额度。去重或预检失败不占用次数。[资源 09](../Project_B战斗与局内系统/09-资源系统实现方案.md)

**验收**　同卡两个装备或物品实例只撤销指定来源。策划误配敌塔接收玩家地形效果在规则校验时报错。结束后场内临时来源清空，常驻值按各自作用域保留。

# Project B · 英雄核心屏障与暴露

2026-11-15 · 设计评审稿

原案 L234–236：核心占圆心，单位从外到内逐层选塔。八方向有一路塔清空则核心暴露并开火，核心击破立刻结束本层，余塔连带破损。[需求 11](../../游戏设计/功能需求/11-英雄核心.md)

## 八方向合同

地图按八方向给 `EntryEnabled` 和按 `RingIndex` 从外向内排列的格集合，塔跨方向足迹的归属由地图定义。方向尽头既能沿合法通路接近核心，又能满足合法攻击位置时才可用于保护判定。评审默认该英雄首次部署确认时八向都应有有效屏障，堵不住的方向必须由内容显式标记为固定开口或不可用方向；至少一路可经破塔开启。固定开口可以从首 Tick 暴露。未声明的初始空方向报告配置错误。后续回合沿用已打通方向历史，允许保留突破成果。

一层记录由合法部署建立的屏障方向，跨回合保留已成功突破的方向历史。在每个方向只暴露当前最外层的合格屏障；普通攻击和伤害技能再按来源所属的访问方向与射程校验，不从别的方向绕过屏障。掩码重叠时任一可访问方向对该塔已合法即可。没有存活屏障的可达方向，在曾有屏障或明示固定开口的条件下满足暴露。抵抗塔破损本轮退出屏障、受击和动作，保留复活占位，下一准备时回满并重新算方向。回合间重新堵上时可恢复保护。技能特批绕过屏障需在效果表和策划中明确。

```text
onEndOfHitBatch(newLayout):
    frontierByDirection = firstScreeningRing(newLayout)
    exposed = anyEnabledDirectionOpenAndReachable(newLayout, frontierByDirection)
    battleMap.commitFrontierForNextTick(frontierByDirection)
    buildingOwner.commitCoreExposureForNextTick(exposed)
```

**验收**　外层被两个命中击破仍只变更一次。第 N 步清口，N+1 才允许核心受击、选敌、开火。将核心周围 UI 隐藏，规则不变。核心击破与终帧超时并存且其他塔的连带原因可追溯。[伤害与破损](19-伤害公式与破损归因.md)

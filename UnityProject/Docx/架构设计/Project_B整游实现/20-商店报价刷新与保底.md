# Project B · 商店报价刷新与保底

2026-11-15 · 设计评审稿

沿用 [局内养成商店](../Project_B战斗与局内系统/05-局内养成实现方案.md) 的报价所有权，补齐原案 L407–429、L513–517 的回合语义、锁定与保底。[需求 20](../../游戏设计/功能需求/20-商店格位、刷新与锁定.md)

## 候选和刷新

- 第一回合前无商店。每次真正打开局级商店窗口自动刷新一次。界面切页、重开或加开海克斯界面还用原 WindowId。付费刷新校验余额并同批写报价、扣款和随机游标。
- 各侧六格，固定格位过滤及 `[AppearRound, RemoveRound)`。首轮战后按刚结算的全局轮次选商品和保底周期，并注明下轮目标英雄。权重为整数。冻结报价内容、星级、价格和收货层。等级更新只影响之后抽取。
- 己方普通未购报价本窗可锁，重刷保留价格、星级和内容。闭窗解除并销毁报价。购后空格等下次刷新。
- 软计数按完整刷新更新一次。某个商品至少一个可抽格且未出现，权重按步长累加；出现归零，全部资格格被锁时无落选计数。接收者不合法的商品不进分母。
- 拆除保底按有资格的回合计。付费刷新可满足保底，但不增加经过的回合数。到期无有效目标时挂债，当前明确可用的敌方拆除格中预留一个空位，该格暂不抽普通商品。喂养等交易新增合法目标时填入该预留格，只做这次增量报价，普通报价、软权重与刷新随机流保持原样。若无合法预留格则挂债到下个合格窗口。硬保底只有生成实际可购买的报价后才记为兑现，保留至消费、目标失效或闭窗。若目标失效而玩家还未消费硬保底报价，重新选择合法目标或恢复保底债。

```text
planRefresh = filterByRoundSideSlotAndEligibility
              → reserveDueRemoval → drawEligibleSlots → updateSoftCountersOnce
commitOnce(planRefresh, optionalRerollSpend)
```

**验收**　限定 3/4/5 格的商品不会影响其他格。硬保底回合无目标，随后同店喂养获得可拆项目时可兑现保底，旧报价身份作废。解锁与付费刷新失败均不改变 RNG。

## 资产和读值

| 视觉对象 | 提供与辨识 |
| --- | --- |
| 卡面、单位、塔与核心 | 资产 ID/地址、图标、轮廓、绘制锚点、受击缩放点和可选状态变化。阵营靠色彩加轮廓/符号区分。核心未暴露、暴露和破损分别可辨 |
| 地图、围栏和部署提示 | 地形图例、围栏、八向前沿、合法/不可投放提示从规则地图及战果投影读取；表现遮挡只改变绘制次序 |
| 战斗反馈 | 用已提交命中和破损值批触发受击、伤害字、核心/法球表现和音效；敌方射击和玩家技能有各自前摇与命中识别 |
| 商店与选择 | 两侧效果成对呈现，明确不利一侧，稀有度颜色需辅以文本或标记。法球五色与奖励来源可辨 |

先做一套完整战场、若干灰盒牌/塔和确定性输入，检查主机位上能否分清投放、战果与选择。正式阶段按同一资产清单替换卡图和战场视图。排序首样按 2D 现行分析用脚底锚点，同高使用稳定次序，密集实例数量和渲染批次按目标机采样后再决定后端。声音、镜头、粒子由表现作用域消费一次带序事实；过载时优先合并非关键伤害字并保留核心、失败等状态。

TEngine/YooAsset 的实例走 `LoadGameObjectAsync`，普通素材 `LoadAssetAsync` 与 `UnloadAsset` 配对。按 `RunId + LayerInstanceId + BattleId/PresentationGeneration` 绑定；异步完成过期释放原资源。逻辑地图加载失败保留安全阶段，缺单件图案可用灰盒替代并记录地址。

**验收**　去掉正式效果或帧率变化，命中与塔阵结算一致。前后重复入场无旧图案、音效或错误的伤害字。用目标分辨率与最大同屏样本评估辨识、遮挡与资源释放。

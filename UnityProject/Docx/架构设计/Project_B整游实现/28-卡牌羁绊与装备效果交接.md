# Project B · 卡牌羁绊与装备效果交接

2026-11-15 · 设计评审稿

修订 5989 L79–101、L479–499 与白板 1。羁绊按牌组 CardDefId 去重，按档位给效果；装备归背包，卡施放时作用于本次卡的产物。[需求 23](../../游戏设计/功能需求/23-卡牌羁绊.md) · [需求 25](../../游戏设计/功能需求/25-局内装备.md)

## 合同

局级卡牌域每次已提交牌组变化后重算受影响羁绊，将每个 `(SynergyDefId, Tier)` 投影为稳定来源。回合建立时已锁定的有效牌组贡献给场内，临时卡与转换牌区均不改计数。战斗中的永久移除效果是否中途改档为待确认，本稿默认下轮生效。附带任务的资格读取档位及已消费记录，避免重达同档重复领。[绑定任务](26-海克斯与羁绊绑定任务.md)

背包持有装备实例及卡绑定，卡牌域读 `EquippedEffectSnapshot(CardInstanceId, EquipInstanceId)`。装备修正费用时在卡输入阶段预检，仅作用该卡；攻击等召唤修正由生成载荷投到该卡召唤出的每个单位。回费次数键按该卡、该装备与 RoundId，不能因召 3 个单位而重复发三次。同星合成后仅有一件装备时继承，两件时先预检背包能收再出新卡。其他移除卡操作默认把已绑装备退回背包，满容量处理按实际背包规则和事务。

```text
tiers = evaluateDistinctCardIds(committedDeck)
battleEffects = compileSourceDelta(previousTiers, tiers, equipmentBindings)
```

**验收**　两张同名不同星卡只贡献一种；三召唤物均获装备 +10 攻击，装备限次回费只发生一次。一个羁绊从第二档降至第一档时只保留第一档来源。

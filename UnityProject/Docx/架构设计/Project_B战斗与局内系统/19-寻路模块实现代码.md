## 生命周期和障碍

- Spawn：按本场稳定 ActorId 注册 Agent，设置移动规格的 `radius`、`radiusObst`、`maxSpeed`、`maxNeighbors`、`neighborDist` 和时间范围。开步已失效对象在本次 ORCA 采样前移除，收尾死亡在后续步不可见。释放旧对象前先从 ActorId 映射移除。
- 地图固定边界与实体地形墙来自地图静态轮廓，加入 `staticObstacles`；可召唤、可拆除、可复活的塔或建筑加入 `dynamicObstacles`，以占位阻挡版本同步。使用已有 `ObstacleGroup.Add(vertices, inverseOrder)`，多边形顶点顺序用一道可复现的墙验证。围栏只有在配置为实际障碍时才投影。动态障碍更新可首期按版本整批替换，按稳定障碍 ID 追加。验证同数量换位能更新实时几何。占位合法、攻击保护和地形效果仍由战斗负责。
- 地图、Agent 与 Entity 的并行读写边界为一次 `Run`。所有 Agent 的输入准备完成后统一推进，从完成的 Agent 读取结果，之后才写实体。退出不再调度，结束在途任务后由该场 `Dispose()` 清理容器。场内障碍更新、删除和释放只在无在途 Job 的边界做。

## 调用代码

在建场时把固定轮廓按顺序加入 `_bundle.staticObstacles`。动态障碍由版本变化触发同步，`PolygonInput` 由地图构造，包含障碍 ID、XY 顶点与是否翻转绕序。送入的数组已完成空轮廓、坐标域和方向检查，按障碍 ID 排序。

~~~csharp
// Rvo2Movement。首次同步时使用不同于有效布局的版本哨兵。
private long _dynamicVersion = -1;

/// <summary>在无在途 Job 时更新可拆、可复活或可重新部署的障碍。</summary>
public void SyncDynamicObstacles(long version, ReadOnlySpan<PolygonInput> polygons)
{
    if (version == _dynamicVersion) return;
    _bundle.dynamicObstacles.Clear(true);
    foreach (ref readonly PolygonInput polygon in polygons)
        _bundle.dynamicObstacles.Add(polygon.Vertices, polygon.InverseOrder);
    _dynamicVersion = version;
}
~~~

下面是核心方法。输入由单位和地图投影产生，`MoveInput` 包含 ActorId、当前位置（由 ECS 定点坐标转换）、业务目标点、停步标记、当步有效速度。投影稳定排序；未锁定攻击目标时可使用地图配置的一个入口点。预设路点只作为可选地图/夹具数据，控制器到当前点后递增游标。没有目标则停步。ORCA 一次固定步即可输出本批单位的新位置。

~~~csharp
using System;
using System.Collections.Generic;
using GameLogic.FixedPoint;
using Nebukam.Common;
using Nebukam.ORCA;
using Unity.Mathematics;

// Rvo2Movement 的字段及方法。MoveInput、MoveOutput、AgentSpec 为业务投影。
private readonly ORCABundle<Agent> _bundle =
    new ORCABundle<Agent> { plane = AxisPair.XY };
private readonly Dictionary<long, Agent> _agents = new Dictionary<long, Agent>();
private const double RawPerUnit = Fixed64.Scale;

/// <summary>已预检本场 ActorId 唯一，在无在途 Job 时注册。</summary>
public void Register(long actorId, Point2 point, in AgentSpec spec)
{
    Agent agent = _bundle.NewAgent(ToXY(point));
    agent.radius = spec.Radius;
    agent.radiusObst = spec.ObstacleRadius;
    agent.maxSpeed = spec.Speed;
    agent.maxNeighbors = spec.MaxNeighbors;
    agent.neighborDist = spec.NeighborDistance;
    agent.timeHorizon = spec.TimeHorizon;
    agent.timeHorizonObst = spec.ObstacleTimeHorizon;
    agent.collisionEnabled = true;
    agent.velocity = default;
    agent.prefVelocity = default;
    _agents.Add(actorId, agent);
}

/// <summary>从本场移除池化 Agent，在下一次步进前完成。</summary>
public void ReleaseAgent(long actorId)
{
    Agent agent = _agents[actorId];
    _agents.Remove(actorId);
    agent.Release();
}

/// <summary>推进固定步，完整输出到调用方预分配缓冲。</summary>
public void Step(int tickRate, ReadOnlySpan<MoveInput> inputs, Span<MoveOutput> outputs)
{
    if (inputs.IsEmpty) return;
    float dt = 1f / tickRate;
    for (int i = 0; i < inputs.Length; i++)
    {
        ref readonly MoveInput input = ref inputs[i];
        Agent agent = _agents[input.ActorId];
        agent.pos = ToXY(input.Position);
        agent.maxSpeed = input.Speed;
        agent.navigationEnabled = !input.Stop && input.Speed > 0f;
        if (!agent.navigationEnabled)
        {
            agent.prefVelocity = default;
            agent.velocity = default;
            continue;
        }

        float3 delta = ToXY(input.Goal) - agent.pos;
        float distance = math.length(delta);
        agent.prefVelocity = math.normalizesafe(delta) * math.min(input.Speed, distance / dt);
    }

    _bundle.orca.Run(dt);

    for (int i = 0; i < inputs.Length; i++)
    {
        ref readonly MoveInput input = ref inputs[i];
        Agent agent = _agents[input.ActorId];
        Point2 position = agent.navigationEnabled ? QuantizeXY(agent.pos) : input.Position;
        outputs[i] = new MoveOutput(input.ActorId, position);
    }
}

/// <summary>将当前权威定点坐标投影到 ORCA 的 XY 平面。</summary>
private static float3 ToXY(Point2 point)
{
    return new float3((float)(point.XRaw / RawPerUnit), (float)(point.YRaw / RawPerUnit), 0f);
}

/// <summary>将库的输出一次性转回战斗共用整数刻度。</summary>
private static Point2 QuantizeXY(float3 position)
{
    return new Point2(
        checked((long)Math.Round(position.x * RawPerUnit, MidpointRounding.AwayFromZero)),
        checked((long)Math.Round(position.y * RawPerUnit, MidpointRounding.AwayFromZero)));
}

public void Dispose()
{
    _bundle.orca.Complete();
    _bundle.Dispose();
    _agents.Clear();
}
~~~

输入契约要求本批覆盖当前所有已注册单位，包含停步 Agent。地图与速度在首次发布前校验范围和正参数，`maxNeighbors` 保持正值，本地实现取 0 时会跳过避障/移动求解。确定需要站定的单位用 `navigationEnabled = false`，保持可被其他 Agent 作为邻居。希望可为队友让步时应显式把它作为可移动的零意图单位。业务移动输出在当步写入 Entitas 后再冻结 PostMove；下一 Tick 重新以实体位置作为输入。Job 完成前无实体写回。

## 验收合同

- 指定空地图目标与移动速度，以固定 Tick 到达，检查停步、旋转轴/坐标精度、暂停和恢复。
- 两单位在同一战场相向通过，使用错开起点；测试静态墙、计划路点形成的绕墙入口，以及动态塔落地、换位、破损的几何刷新。
- 完全封路且没有配置可走入口时，验证不会直接穿墙、不会把暂时停滞当作全局不可达。全局搜索能力不作为阶段 05 或阶段 08 的测试期望。
- 同 Unity Player、运行目标、RVO2 配置、初始状态及命令重复运行，记录每步位置、战果与摘要。浮点输出量化到定点字段，重放实测结论以该环境为准。

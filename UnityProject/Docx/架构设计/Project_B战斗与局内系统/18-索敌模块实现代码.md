# Project B 索敌模块 C# 实现

实现稿，供评审后迁入主包。承接 [四叉树与 Job System](12-四叉树JobSystem索敌实现方案.md) 和 [战斗接入](13-索敌与寻路接入战斗模块方案.md)。本文两个 C# 代码块可分别保存为同一程序集中的源码文件，拟建目录为 Assets/GameScripts/Main/BattleSpatial。BattleSpatial.asmdef 引用 Unity.Burst、Unity.Collections，Unity.Jobs 使用引擎提供的引用。GameLogic 引用 BattleSpatial。下游 [寻路代码](19-寻路模块实现代码.md) 和 [战斗接入代码](20-战斗编排接入实现代码.md) 共用本文的 EntityRef、RawPoint、RawBox、BatchStamp。

- 坐标和半径用定点 Raw，比例 1,000,000。本文采用已提议的坐标域 ±1,000 世界单位、半径上限 1,000。输入构建器负责在半径平方、盒外伸等运算前校验原值。根区间为半开，受击盒和搜索圆为闭边界。
- 同一目标快照内业务 ID 唯一且大于零。Default EntityRef 表示空目标。TeamBit 为单一阵营位，KindBit 为目标类型位，AllowTeams 是由战斗解析的可选阵营。八方向资格使用 8 个层索引，-1 表示该方向关闭。核心等特殊资格需先由战场投影到对应类别/方向层规则。
- 一棵树一个 QuadTargetBatch。塔树使用可复用的几何修订号及稳定槽位，移动单位树每 PostMove 有查询时重建。SetTarget 每批填入当前属性，几何或目标槽位顺序变化时增加 GeometryRevision。使用者按稳定业务 ID 生成查询及消费结果；排序最终键唯一，因此个别数组重排不改变赢家。
- 第一次先按约定的顺序调用 Begin、SetTarget/SetQuery/SetExcluded、Run、ReadResult。Run 内调度建树和并行查找，并以 Complete 返回批结果。战斗集成在第 20 份文档。代码与调度接口基于 Unity 6.0 和 Collections 2.6，尚待目标 Player 编译验证。 [Unity IJobParallelFor](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Unity.Jobs.IJobParallelFor.html) · [批量建树参考](https://github.com/marijnz/NativeQuadtree/blob/master/Assets/QuadTreeJobs.cs)

## 战斗值、建树和查询

~~~csharp
using System;
using Unity.Burst;
using Unity.Collections;
using Unity.Jobs;

namespace ProjectB.BattleSpatial
{
    public struct EntityRef
    {
        public long Id;
        public uint Generation;

        /// <summary>比较场内业务身份及代际。</summary>
        public bool Matches(EntityRef other)
        {
            return Id == other.Id && Generation == other.Generation;
        }
    }

    public struct RawPoint
    {
        public long X;
        public long Y;

        public RawPoint(long x, long y)
        {
            X = x;
            Y = y;
        }

        /// <summary>比较两个定点坐标。</summary>
        public bool Matches(RawPoint other)
        {
            return X == other.X && Y == other.Y;
        }
    }

    public struct RawBox
    {
        public RawPoint Min;
        public RawPoint Max;

        /// <summary>求点到闭区间受击盒的距离平方。</summary>
        public long DistanceSquared(RawPoint point)
        {
            long dx = AxisDistance(point.X, Min.X, Max.X);
            long dy = AxisDistance(point.Y, Min.Y, Max.Y);
            return dx * dx + dy * dy;
        }

        /// <summary>求两个定点盒的保守外包盒。</summary>
        public static RawBox Union(RawBox a, RawBox b)
        {
            return new RawBox
            {
                Min = new RawPoint(Math.Min(a.Min.X, b.Min.X), Math.Min(a.Min.Y, b.Min.Y)),
                Max = new RawPoint(Math.Max(a.Max.X, b.Max.X), Math.Max(a.Max.Y, b.Max.Y))
            };
        }

        /// <summary>求轴坐标到闭区间的差值。</summary>
        private static long AxisDistance(long value, long min, long max)
        {
            if (value < min)
            {
                return min - value;
            }

            return value > max ? value - max : 0;
        }
    }

    public enum TargetPhase : byte { PreMove, PostMove }

    public struct BatchStamp
    {
        public long BattleId;
        public long Tick;
        public TargetPhase Phase;
        public long GeometryRevision;
        public long EligibilityRevision;

        /// <summary>核对结果是否属于当前战斗的对应阶段。</summary>
        public bool Matches(BatchStamp other)
        {
            return BattleId == other.BattleId && Tick == other.Tick && Phase == other.Phase
                && GeometryRevision == other.GeometryRevision
                && EligibilityRevision == other.EligibilityRevision;
        }
    }

    public struct SpatialTarget
    {
        public EntityRef Entity;
        public RawPoint Anchor;
        public RawBox HitBox;
        public uint TeamBit;
        public uint KindBit;
        public byte Selectable;
        public byte DirectionMask;
        public int Ring;
        public int Weight;
    }

    public struct TargetQuery
    {
        public EntityRef Seeker;
        public RawPoint Origin;
        public long RangeSquared;
        public uint AllowTeams;
        public uint AllowKinds;
        public byte CheckFrontier;
        public FixedList64Bytes<int> AllowedRing;
        public int ExcludedOffset;
        public int ExcludedCount;
    }

    public struct TargetResult
    {
        public EntityRef Seeker;
        public EntityRef Target;
        public int Weight;
        public long DistanceSquared;
    }

    internal struct QuadNode
    {
        public RawBox Bounds;
        public int FirstChild;
        public int ChildCount;
        public int Start;
        public int Length;
    }

    internal struct BuildWork
    {
        public int Node;
        public int Start;
        public int Length;
        public int Depth;
        public int Source;
        public RawPoint Min;
        public long Side;
    }

    [BurstCompile]
    internal struct BuildQuadTreeJob : IJob
    {
        [ReadOnly] public NativeArray<SpatialTarget> Targets;
        public NativeArray<int> IndexA;
        public NativeArray<int> IndexB;
        public NativeArray<int> LeafIndices;
        public NativeArray<QuadNode> Nodes;
        public NativeArray<BuildWork> Stack;
        public NativeArray<int> NodeCount;
        public RawPoint RootMin;
        public long RootSide;
        public int TargetCount;
        public int LeafLimit;
        public int MaxDepth;

        /// <summary>对活跃区间稳定分区，保存实际受击盒的并集。</summary>
        public void Execute()
        {
            if (TargetCount == 0)
            {
                NodeCount[0] = 0;
                return;
            }

            for (int i = 0; i < TargetCount; ++i)
            {
                IndexA[i] = i;
            }

            int nextNode = 1;
            int stackLength = 1;
            Stack[0] = new BuildWork { Length = TargetCount, Min = RootMin, Side = RootSide };

            while (stackLength != 0)
            {
                BuildWork work = Stack[--stackLength];
                NativeArray<int> source = work.Source == 0 ? IndexA : IndexB;
                NativeArray<int> destination = work.Source == 0 ? IndexB : IndexA;
                SpatialTarget first = Targets[source[work.Start]];
                RawBox bounds = first.HitBox;
                RawPoint minAnchor = first.Anchor;
                RawPoint maxAnchor = first.Anchor;
                int end = work.Start + work.Length;

                for (int i = work.Start + 1; i < end; ++i)
                {
                    SpatialTarget target = Targets[source[i]];
                    bounds = RawBox.Union(bounds, target.HitBox);
                    minAnchor.X = Math.Min(minAnchor.X, target.Anchor.X);
                    minAnchor.Y = Math.Min(minAnchor.Y, target.Anchor.Y);
                    maxAnchor.X = Math.Max(maxAnchor.X, target.Anchor.X);
                    maxAnchor.Y = Math.Max(maxAnchor.Y, target.Anchor.Y);
                }

                while (work.Length > LeafLimit && work.Depth < MaxDepth && work.Side >= 2)
                {
                    int lower = Quadrant(minAnchor, work.Min, work.Side);
                    int upper = Quadrant(maxAnchor, work.Min, work.Side);
                    if (lower != upper)
                    {
                        break;
                    }

                    work.Side /= 2;
                    work.Min = ChildMin(work.Min, work.Side, lower);
                    ++work.Depth;
                }

                if (work.Length <= LeafLimit || work.Depth >= MaxDepth || work.Side < 2)
                {
                    for (int i = work.Start; i < end; ++i)
                    {
                        LeafIndices[i] = source[i];
                    }

                    Nodes[work.Node] = new QuadNode
                    {
                        Bounds = bounds, Start = work.Start, Length = work.Length
                    };
                    continue;
                }

                FixedList32Bytes<int> counts = default;
                FixedList32Bytes<int> offsets = default;
                FixedList32Bytes<int> cursors = default;
                for (int q = 0; q < 4; ++q)
                {
                    counts.Add(0);
                }

                for (int i = work.Start; i < end; ++i)
                {
                    int q = Quadrant(Targets[source[i]].Anchor, work.Min, work.Side);
                    counts[q] = counts[q] + 1;
                }

                int offset = work.Start;
                int childCount = 0;
                for (int q = 0; q < 4; ++q)
                {
                    offsets.Add(offset);
                    cursors.Add(offset);
                    offset += counts[q];
                    if (counts[q] != 0)
                    {
                        ++childCount;
                    }
                }

                for (int i = work.Start; i < end; ++i)
                {
                    int index = source[i];
                    int q = Quadrant(Targets[index].Anchor, work.Min, work.Side);
                    int cursor = cursors[q];
                    destination[cursor] = index;
                    cursors[q] = cursor + 1;
                }

                int firstChild = nextNode;
                nextNode += childCount;
                Nodes[work.Node] = new QuadNode
                {
                    Bounds = bounds, FirstChild = firstChild, ChildCount = childCount
                };
                int child = nextNode - 1;
                long half = work.Side / 2;
                for (int q = 3; q >= 0; --q)
                {
                    if (counts[q] == 0)
                    {
                        continue;
                    }

                    Stack[stackLength++] = new BuildWork
                    {
                        Node = child--, Start = offsets[q], Length = counts[q],
                        Depth = work.Depth + 1, Source = 1 - work.Source,
                        Min = ChildMin(work.Min, half, q), Side = half
                    };
                }
            }

            NodeCount[0] = nextNode;
        }

        /// <summary>中线一律归高坐标一侧。</summary>
        private static int Quadrant(RawPoint point, RawPoint min, long side)
        {
            long half = side / 2;
            return (point.X >= min.X + half ? 1 : 0) | (point.Y >= min.Y + half ? 2 : 0);
        }

        /// <summary>取得对应子象限的最小端点。</summary>
        private static RawPoint ChildMin(RawPoint min, long half, int quadrant)
        {
            return new RawPoint(min.X + ((quadrant & 1) != 0 ? half : 0),
                min.Y + ((quadrant & 2) != 0 ? half : 0));
        }
    }

    [BurstCompile]
    internal struct FindTargetJob : IJobParallelFor
    {
        [ReadOnly] public NativeArray<SpatialTarget> Targets;
        [ReadOnly] public NativeArray<TargetQuery> Queries;
        [ReadOnly] public NativeArray<EntityRef> Excluded;
        [ReadOnly] public NativeArray<int> NodeCount;
        [ReadOnly] public NativeArray<int> LeafIndices;
        [ReadOnly] public NativeArray<QuadNode> Nodes;
        [WriteOnly] public NativeArray<TargetResult> Results;

        /// <summary>遍历定点内容盒，按权重、距离和稳定 ID 归约。</summary>
        public void Execute(int index)
        {
            TargetQuery query = Queries[index];
            TargetResult best = new TargetResult { Seeker = query.Seeker };
            FixedList512Bytes<int> stack = default;
            if (NodeCount[0] > 0)
            {
                stack.Add(0);
            }

            while (stack.Length > 0)
            {
                int last = stack.Length - 1;
                QuadNode node = Nodes[stack[last]];
                stack.RemoveAt(last);
                if (node.Bounds.DistanceSquared(query.Origin) > query.RangeSquared)
                {
                    continue;
                }

                if (node.ChildCount != 0)
                {
                    for (int i = node.ChildCount - 1; i >= 0; --i)
                    {
                        stack.Add(node.FirstChild + i);
                    }

                    continue;
                }

                int end = node.Start + node.Length;
                for (int i = node.Start; i < end; ++i)
                {
                    SpatialTarget target = Targets[LeafIndices[i]];
                    if (!CanSelect(query, target))
                    {
                        continue;
                    }

                    long distance = target.HitBox.DistanceSquared(query.Origin);
                    if (distance <= query.RangeSquared && IsBetter(target, distance, best))
                    {
                        best.Target = target.Entity;
                        best.Weight = target.Weight;
                        best.DistanceSquared = distance;
                    }
                }
            }

            Results[index] = best;
        }

        /// <summary>执行阵营、方向层和导航排除过滤。</summary>
        private bool CanSelect(TargetQuery query, SpatialTarget target)
        {
            if (target.Selectable == 0 || target.Entity.Id == query.Seeker.Id
                || (target.TeamBit & query.AllowTeams) == 0
                || (target.KindBit & query.AllowKinds) == 0)
            {
                return false;
            }

            if (query.CheckFrontier != 0)
            {
                bool allowed = false;
                for (int direction = 0; direction < 8; ++direction)
                {
                    if ((target.DirectionMask & (1 << direction)) != 0
                        && query.AllowedRing[direction] >= 0
                        && query.AllowedRing[direction] == target.Ring)
                    {
                        allowed = true;
                        break;
                    }
                }

                if (!allowed)
                {
                    return false;
                }
            }

            int end = query.ExcludedOffset + query.ExcludedCount;
            for (int i = query.ExcludedOffset; i < end; ++i)
            {
                if (target.Entity.Matches(Excluded[i]))
                {
                    return false;
                }
            }

            return true;
        }

        /// <summary>比较完整排序键，遍历顺序不影响结果。</summary>
        private static bool IsBetter(SpatialTarget target, long distance, TargetResult best)
        {
            if (best.Target.Id == 0 || target.Weight != best.Weight)
            {
                return best.Target.Id == 0 || target.Weight > best.Weight;
            }

            if (distance != best.DistanceSquared)
            {
                return distance < best.DistanceSquared;
            }

            return target.Entity.Id < best.Target.Id;
        }
    }
}
~~~

## 批次调度与缓冲所有者

~~~csharp
using System;
using Unity.Collections;
using Unity.Jobs;

namespace ProjectB.BattleSpatial
{
    public sealed class QuadTargetBatch : IDisposable
    {
        private const long MaxCoordinate = 1_000_000_000L;
        private const long MaxDistanceSquared = MaxCoordinate * MaxCoordinate;
        private readonly RawPoint rootMin;
        private readonly long rootSide;
        private readonly int leafLimit;
        private readonly int maxDepth;
        private readonly int exclusionCapacity;

        private NativeArray<SpatialTarget> targets;
        private NativeArray<TargetQuery> queries;
        private NativeArray<EntityRef> excluded;
        private NativeArray<TargetResult> results;
        private NativeArray<QuadNode> nodes;
        private NativeArray<BuildWork> work;
        private NativeArray<int> indexA, indexB, leafIndices, nodeCount;
        private JobHandle pending;
        private int targetCount, queryCount, excludedCount, cachedCount;
        private bool hasTree, hasResults, acceptingInput;
        private BatchStamp stamp, cachedStamp;

        /// <summary>按关卡峰值在战斗开始时分配所有工作区。</summary>
        public QuadTargetBatch(RawPoint min, long side, int targetCapacity,
            int queryCapacity, int exclusionCapacity, int leafLimit = 16, int maxDepth = 8)
        {
            CheckPoint(min);
            if (targetCapacity <= 0 || queryCapacity <= 0 || exclusionCapacity < 0
                || side <= 0 || side > (1L << 31) || (side & (side - 1)) != 0
                || leafLimit <= 0 || maxDepth < 0 || maxDepth > 30)
            {
                throw new ArgumentOutOfRangeException(nameof(targetCapacity), "索敌容量或根范围无效");
            }

            int nodeCapacity = checked(2 * targetCapacity - 1);
            rootMin = min;
            rootSide = side;
            this.leafLimit = leafLimit;
            this.maxDepth = maxDepth;
            this.exclusionCapacity = exclusionCapacity;

            try
            {
                targets = Allocate<SpatialTarget>(targetCapacity);
                queries = Allocate<TargetQuery>(queryCapacity);
                excluded = Allocate<EntityRef>(Math.Max(1, exclusionCapacity));
                results = Allocate<TargetResult>(queryCapacity);
                nodes = Allocate<QuadNode>(nodeCapacity);
                work = Allocate<BuildWork>(1 + 3 * maxDepth);
                indexA = Allocate<int>(targetCapacity);
                indexB = Allocate<int>(targetCapacity);
                leafIndices = Allocate<int>(targetCapacity);
                nodeCount = Allocate<int>(1);
            }
            catch
            {
                Dispose();
                throw;
            }
        }

        /// <summary>预检批容量并开启填充窗口，覆盖本批各有效槽位。</summary>
        public void Begin(BatchStamp current, int count, int requestCount, int exclusionCount)
        {
            if (!targets.IsCreated)
            {
                throw new ObjectDisposedException(nameof(QuadTargetBatch));
            }

            if ((uint)count > (uint)targets.Length || (uint)requestCount > (uint)queries.Length
                || (uint)exclusionCount > (uint)exclusionCapacity)
            {
                throw new InvalidOperationException("索敌批次超过预分配容量");
            }

            hasResults = false;
            acceptingInput = true;
            stamp = current;
            targetCount = count;
            queryCount = requestCount;
            excludedCount = exclusionCount;
        }

        /// <summary>填充当前阶段目标值。</summary>
        public void SetTarget(int index, SpatialTarget target)
        {
            CheckInputSlot(index, targetCount);
            CheckPoint(target.Anchor);
            CheckPoint(target.HitBox.Min);
            CheckPoint(target.HitBox.Max);
            if (target.Entity.Id <= 0 || target.HitBox.Min.X > target.HitBox.Max.X
                || target.HitBox.Min.Y > target.HitBox.Max.Y
                || target.Anchor.X < rootMin.X || target.Anchor.X >= rootMin.X + rootSide
                || target.Anchor.Y < rootMin.Y || target.Anchor.Y >= rootMin.Y + rootSide)
            {
                throw new ArgumentException("目标身份、受击盒或根范围无效", nameof(target));
            }

            targets[index] = target;
        }

        /// <summary>填充寻敌请求，检查八方向和排除切片。</summary>
        public void SetQuery(int index, TargetQuery query)
        {
            CheckInputSlot(index, queryCount);
            CheckPoint(query.Origin);
            if (query.Seeker.Id <= 0 || query.RangeSquared < 0
                || query.RangeSquared > MaxDistanceSquared
                || (query.CheckFrontier != 0 && query.AllowedRing.Length != 8)
                || query.ExcludedOffset < 0 || query.ExcludedOffset > excludedCount
                || query.ExcludedCount < 0 || query.ExcludedCount > excludedCount - query.ExcludedOffset)
            {
                throw new ArgumentException("索敌请求无效", nameof(query));
            }

            queries[index] = query;
        }

        /// <summary>填充由单位系统确认仍有效的排除身份。</summary>
        public void SetExcluded(int index, EntityRef entity)
        {
            CheckInputSlot(index, excludedCount);
            excluded[index] = entity;
        }

        /// <summary>按构建依赖调度并查询，在本阶段消费位完成。</summary>
        public void Run(int batchSize, bool forceRebuild)
        {
            if (!acceptingInput || batchSize <= 0)
            {
                throw new InvalidOperationException("索敌批次尚未开启或批大小无效");
            }

            acceptingInput = false;
            if (queryCount == 0)
            {
                hasResults = true;
                return;
            }

            bool rebuild = forceRebuild || !hasTree || cachedCount != targetCount
                || cachedStamp.BattleId != stamp.BattleId || cachedStamp.Phase != stamp.Phase
                || cachedStamp.GeometryRevision != stamp.GeometryRevision;

            if (rebuild)
            {
                hasTree = false;
                pending = new BuildQuadTreeJob
                {
                    Targets = targets, IndexA = indexA, IndexB = indexB, LeafIndices = leafIndices,
                    Nodes = nodes, Stack = work, NodeCount = nodeCount, RootMin = rootMin,
                    RootSide = rootSide, TargetCount = targetCount, LeafLimit = leafLimit,
                    MaxDepth = maxDepth
                }.Schedule();
            }

            pending = new FindTargetJob
            {
                Targets = targets, Queries = queries, Excluded = excluded, NodeCount = nodeCount,
                LeafIndices = leafIndices, Nodes = nodes, Results = results
            }.Schedule(queryCount, batchSize, pending);

            pending.Complete();
            pending = default;
            cachedCount = targetCount;
            cachedStamp = stamp;
            hasTree = true;
            hasResults = true;
        }

        /// <summary>读取已经完成且身份一致的查询结果。</summary>
        public TargetResult ReadResult(BatchStamp expected, int index)
        {
            if (!hasResults || !stamp.Matches(expected) || (uint)index >= (uint)queryCount)
            {
                throw new InvalidOperationException("索敌结果的阶段或槽位无效");
            }

            return results[index];
        }

        /// <summary>完成作业后归还所有 Native 缓冲。</summary>
        public void Dispose()
        {
            pending.Complete();
            pending = default;
            hasResults = false;
            acceptingInput = false;
            Release(ref targets);
            Release(ref queries);
            Release(ref excluded);
            Release(ref results);
            Release(ref nodes);
            Release(ref work);
            Release(ref indexA);
            Release(ref indexB);
            Release(ref leafIndices);
            Release(ref nodeCount);
        }

        /// <summary>校验写入窗口和本批有效前缀。</summary>
        private void CheckInputSlot(int index, int count)
        {
            if (!acceptingInput || (uint)index >= (uint)count)
            {
                throw new InvalidOperationException("索敌输入槽位无效");
            }
        }

        /// <summary>确保定点距离的中间值处于已证明的范围内。</summary>
        private static void CheckPoint(RawPoint point)
        {
            if (point.X < -MaxCoordinate || point.X > MaxCoordinate
                || point.Y < -MaxCoordinate || point.Y > MaxCoordinate)
            {
                throw new ArgumentOutOfRangeException(nameof(point));
            }
        }

        /// <summary>为整场创建复用的非托管数组。</summary>
        private static NativeArray<T> Allocate<T>(int count) where T : struct
        {
            return new NativeArray<T>(count, Allocator.Persistent, NativeArrayOptions.UninitializedMemory);
        }

        /// <summary>释放已分配的非托管数组。</summary>
        private static void Release<T>(ref NativeArray<T> array) where T : struct
        {
            if (array.IsCreated)
            {
                array.Dispose();
                array = default;
            }
        }
    }
}
~~~

两个子树至少各有一个锚点时才建子节点，单象限链用当前区间继续下探。节点容量 2N−1，遍历栈上界 1+3D。查询按 ContentBounds 的下界剪枝，较远的同层高权重目标仍参与比较。缓存塔树要求几何修订与槽位顺序同步，资格和权重每批刷新。当前接口由战斗主线程串行填充及消费，来自同一批的结果严禁跨 Tick 写回。

验收时用线性全扫对照同一输入，覆盖空树、等距稳定 ID、锚点在范围外但受击盒相切、同坐标、闭合方向、移动后才进入塔射程、生成代际不同。实际建树/查询耗时、Player AOT 和 Native 内存峰值待运行采样。

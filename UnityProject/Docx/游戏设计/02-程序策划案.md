## 1. 游戏目标与范围

玩家以大魔王身份发动进攻，依靠牌组、费用、角色技能和局内养成依次击败五名 AI 英雄。击破本层核心结束本层，击败第五名英雄完成挑战。战斗表现决定荣誉变化，荣誉耗尽则失败。双向商店允许玩家强化自己、强化对手以换金币、或付费移除敌方可拆内容。双向海克斯把两边的效果绑成一组供玩家选择。

完整范围包含局外养成、难度选择、战斗、局内成长、两类双向选择、任务、法球、局末结算与正式视觉表现。多角色选择、属性叠层升级、荣誉勋章与剩余荣誉奖励需要补充规则。

## 2. 模块向玩家提供的功能

| 模块 | 操作、条件与结果 |
| --- | --- |
| 局外养成与禁用 | 用 A 点亮科技树、用 B 点亮卡牌技能树、用 F 点亮角色技能树。卡牌、物品、海克斯的初始禁用额度为 2、2、1。全局背包保存局外养成资源和已开启角色相关内容。 |
| 角色与难度 | 难度在进局前选定。角色决定初始牌组、荣誉、费用、金币与主动技能。当前已明确初始角色的技能，完整角色选择和难度规则待定义。 |
| 回合准备与敌方部署 | 费用恢复，建筑按类型回血。敌方可调整、部署已经获得的塔，准备结束时清理未部署建筑。等级和道具可增加敌方格位。 |
| 抽牌、出牌与战斗 | 起手 5、手牌初始上限 10。使用费用出牌，单位和敌方塔自动战斗。满手暂停定时抽牌，牌库空时洗弃牌。战场地形限制站立和部署，通常只允许围栏外部署。 |
| 伤害、核心与掉落 | 按建筑和单位规则处理攻击、破损与阵亡。核心按八方向条件暴露，暴露后开火。拆常规塔按星级概率掉法球，击败英雄另有通关法球。核心自身的破坏积分有效。 |
| 角色技能 | 仅战斗内主动释放。初始角色需 1000 能量，每 5 点费用或达到该回合伤害门槛各积累 1 点。释放后减慢回合时间、持续回费，技能期间停止积能。 |
| 评分、荣誉与回合奖励 | 按总伤害及拆塔积分得 F 至 S 评分，再调整荣誉。回合结束给予固定经验，可发放敌方塔、物品、BUFF。金币有评分、利息、敌方向交易三种收入来源。 |
| 双向商店与等级 | 两侧各 6 格。进店刷新，可付费重刷或锁定己方商品。商品按回合资格、格位条件与权重出现。玩家升级影响刷卡星级、费用和海克斯机会。敌方升级发塔、开格。 |
| 卡牌获取、升星与羁绊 | 普通卡可来自商店、海克斯、任务、法球，下回合参与抽牌。商店可加卡、删卡、同名同星合成，也可通过物品、海克斯或任务升级。临时升星回合末还原。羁绊按牌组内卡牌 ID 统计，取最高档。 |
| 装备、物品与背包 | 每张卡可带一件装备，效果仅随该卡。合成时一件可继承，两件均回背包。物品、装备、海克斯及局内卡组按类别归入局内背包。敌方已部署的塔不可从商店拆除。 |
| 海克斯、重置与任务 | 达到 3、7、12、18、24、30 级，击败前四名英雄，或完成指定任务时可获得三选一。每个候选给双方各一个海克斯。特定海克斯可随机或自选重置已持有海克斯。任务可发指定奖励或效果。 |
| 增益、减益与属性成长 | 增益减益作用于玩家、单位或建筑。常驻跨回合，非常驻在回合末重置，离局全部清空。BUFF 可叠层、刷新持续时间或取最高。六类属性叠层升级仍待定义。 |
| 结果与回到局外 | 区分整局胜利和失败，展示击败英雄、拆塔和回合数等表现与累计评分，发放适用局外奖励，返回局外继续养成。 |
| 正式表现 | 像素简笔画表现卡牌和战场，辨别双方阵营、塔和核心、地形与可部署区、法球品质及双方海克斯效果。具体展示需求随玩法口径确认。 |

## 3. 结算与保留规则

| 对象 | 规则 |
| --- | --- |
| 回合进度 | 全局回合号跨英雄累加。回合时限、预期牌组张数和超额补时按回合确定。角色充能按同一回合号递增伤害要求。 |
| 费用和能量 | 费用下回合恢复满值。能量跨回合、跨层保留。卡牌、装备、物品、羁绊、海克斯和初始角色技能可在战斗内回费。 |
| 牌与玩家战斗对象 | 可用牌归并回本局牌组，移除牌不参与后续抽牌。临时升星还原。玩家单位和建筑回收不触发死亡结果。 |
| 敌人建筑与格位 | 常规塔破坏后不恢复，尚存塔准备时恢复已损生命的 15%。核心回满，抵抗塔满血复活或恢复。核心击破时余塔同时破损。 |
| 法球、任务与三选一 | 同阶段若有通关掉落、任务奖励、等级选择，顺序和待领内容的处理仍需明确。击败前四层触发额外海克斯三选一，最后一层走胜利结算。 |
| 局内持有与局外资源 | 对局牌组修改和效果限本局。局外依靠科技点、技能点等成长。荣誉勋章有法球与结算来源设想，具体纳入规则待定。 |

## 5. 用于评审的玩法情景

| 情景 | 修订 5989 对应的结果 |
| --- | --- |
| 第 1 层打到全局第 6 回合后进入第 2 层 | 下一回合是全局第 7 回合，选用第 7 回合的规则。初始角色伤害门槛为 400 点/能量。 |
| 牌组有两张同名不同星卡，羁绊要求两种 | 只贡献一种。手牌和场上单位不另加种数。 |
| 合成两张同名同星卡 | 得到一张更高星同名卡。只一件装备时继承，两张各有一件时两件都返回背包。 |
| 战斗中获得一张普通卡并临时提升另一张卡星级 | 普通新卡下回合参与洗牌。临时升星回合结束后还原。 |
| 手牌已达上限且定时抽牌倒计时到 0 | 等出现空位并实际抽出一张，再重新计时。 |
| 角色在技能持续期内继续造成伤害、出牌 | 能量停止上涨，持续按技能规则回费。减速和持续时间口径需确认。 |
| 玩家升到 7 级，另击败前四位英雄之一 | 两个来源各满足一次三选一；同时遇到时的展示和处理顺序待定。 |
| 击破核心 | 该击破给核心积分，核心本体不掉法球，结束本层并使其余塔同时破损。通关法球按独立规则处理。 |
| 商品限定 3、4、5 号位且本回合不在可售范围 | 本回合不参与刷新或权重计算。可售回合内仍只在指定位置参与。 |

## 6. 待确认的关键规则

1. **核心击破与回合结算**。确定评分、经验、金币和荣誉是否在通过回合照常结算，归零与通关同时发生时的结果，通关掉落、海克斯和商店的先后。
2. **首回合商店和主动终止**。正文最小循环从战斗开始，白板 2 从准备进商店开始。白板还提到强制结束回合或召唤，需决定相应操作和之后是否继续自动战斗。
3. **敌方即时生效、拆除和交易**。明确已生效且未入背包的敌方物品能否同回合拆除、如何撤销；确认零金币能否买敌方道具及实际净收益。
4. **付费经验与海克斯触发**。白板写买经验也帮助对手升级、固定回合给三选一，正文写共享回合经验，三选一列等级、前四层和任务。明确附加条件及多次选择的顺序。
5. **角色主动技能计时**。原案同时写 0.5 倍、持续 15 秒和延长 30 秒，需统一受影响的时钟、实际持续和回费次数。费用将恢复时能否触发提前结束也要定义。
6. **法球、核心暴露与敌塔地形**。确认第二、三层紫金奖励的组合方式、第五层法球、核心连带破损的计分和掉落、八方向计算、地形是否对敌塔生效。
7. **完整成长链**。补齐多角色选择、属性叠层升级、勋章来源和用途，明确敌方背包与局内持有内容跨层归属、回合表具体内容和累计评分口径。

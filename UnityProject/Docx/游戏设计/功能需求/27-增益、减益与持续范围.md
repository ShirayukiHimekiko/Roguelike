# 增益、减益与持续范围

**来源**　原案「强化卡」L223–230、「战斗场地」L264–266、「BUFF 系统」L372–405、「效果表」「BUFF 表」「总的技能表」L519–529。

## 功能需求

| 作用对象 | 来源与持续范围 |
| --- | --- |
| 玩家 | 海克斯、羁绊、技能卡、强化卡和科技树。回合结束清除非常驻效果，是否常驻由效果规则决定。 |
| 玩家单位 | 上述来源以及敌方与地形效果。单位回收时清除其增益与减益。 |
| 敌方建筑 | 海克斯、羁绊、技能卡、强化卡、科技树、塔之间的增益和单位施加的减益。回合结束清除非常驻效果。敌塔是否受地形影响待统一。 |

常驻效果跨回合保留，所有局内效果离局清空。内容条目适用的叠加规则包括叠层、刷新持续时间、取最高，并区分目标为玩家、单位或建筑。买给敌方的商店物品与 BUFF 的即时生效规则见 [双向购买与拆除](21-双向购买与拆除.md)。

## 待确认

各效果的对象、触发、持续和叠加口径，常驻敌方效果是否跨英雄，强化卡的「一整轮」与回合清理如何衔接。地形是否影响敌塔需统一。BUFF 叠层是已列明的效果处理规则，独立的属性叠层升级功能见 [属性叠层升级](42-属性叠层升级.md)。

# 法球掉落与领取

**来源**　原案「卡牌装备」L89–101、「法球」L139–157、「敌方建筑」L232–236、「敌人建筑类型」L254–262、「局外资源」L330–336。

## 功能需求

- 破坏常规敌塔有概率掉落法球。抵抗塔与核心本体不发拆塔法球。击败英雄触发独立的通关掉落，科技树可改变掉落概率。
- 不同稀有度的法球可提供卡牌、物品、海克斯、装备或装备宝箱。蓝至金法球额外掉落荣誉勋章的设想纳入完整需求，保留原有法球奖励。

| 稀有度 | 拆塔掉落条件 | 层通关掉落条件 |
| --- | --- | --- |
| 白 | 1–3 星塔概率掉落 | 无 |
| 绿 | 2–4 星塔概率掉落 | 无 |
| 蓝 | 3–5 星塔概率掉落 | 无 |
| 紫 | 4–5 星塔概率掉落 | 第 1 层必定，第 2、3 层概率。 |
| 金 | 5 星塔概率掉落 | 第 2、3 层概率，第 4 层必定。 |

## 待确认

第 2、3 层的紫/金是同一奖励的品质二选一，还是两次独立掉落。新版正文写击败敌人必定有法球，但表只列前四层，需明确第五层、各稀有度概率与掉落数量。奖励池、开球或领用方式、失败和换层时未领取奖励去向、核心连带破损是否触发掉落也待定。

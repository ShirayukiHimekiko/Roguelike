# 卡牌羁绊

**来源**　原案「卡牌获取」「卡牌升级」L55–77、「卡牌羁绊」L79–87、「临时卡与移除」L181–185、「羁绊表」L495–497。

## 功能需求

- 每种卡有 1–3 个羁绊。按当前局内牌组拥有的卡牌 ID 计种数，同卡多张只计一种。手牌、弃牌和在场单位不单独参与计数。
- 达到多档阈值时取满足的最高档。相同卡牌升星后仍是同一种，升星不改变其羁绊与词条。
- 羁绊可发临时卡、临时升星、回复费用或施加增益减益。临时卡直接进入手牌并于回合结束移除。绑定任务可发卡、升卡、给装备或提升费用。

## 待确认

档位切换和效果生效时点，战斗中新增普通卡入牌组是否立即改羁绊，临时牌是否从羁绊计数中排除，最高档是否合并低档效果，临时卡打出和满手的去向。

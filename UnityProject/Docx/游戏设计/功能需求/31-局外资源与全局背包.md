# 局外资源与全局背包

**来源**　原案「局外养成」L31–47、「局外资源」L298–336、「全局背包」L360–362。

局外养成属于完整游戏范围。资源 F 在原案的资源章节仍单独标为「暂时不做」，用途和产出规则需进一步确认。

| 资源 | 用途 | 来源 |
| --- | --- | --- |
| A 科技点（暂定） | 科技树 | 局末按击败英雄、击破塔、回合数发放，胜负有额外奖励。 |
| B 技能点（暂定） | 卡牌技能树 | 局内每次升卡、局外解锁新卡及胜负额外奖励。 |
| C 卡牌禁用点（待定） | 卡牌禁用 | 初始 2，科技树可增加。 |
| D 物品禁用点（待定） | 物品禁用 | 初始 2，科技树可增加。 |
| E 海克斯禁用点（待定） | 海克斯禁用 | 初始 1，科技树可增加。 |
| F 荣誉勋章（待定） | 资源章节写解锁新角色，角色技能树章节也写消耗 F | 蓝至金法球额外概率掉落、胜负额外奖励，另有剩余荣誉值奖励设想。 |

全局背包持有局外养成资源和已经开启的英雄。

## 待确认

资源 F 是否共用于解锁角色和点技能，以及完整版本的产出与消耗方案。原案在全局背包写「已经开启的英雄」，战斗里也用「英雄」称呼守方，需要明确两处所指。资源 A、B 具体奖励数值和新卡解锁路径也需补齐。

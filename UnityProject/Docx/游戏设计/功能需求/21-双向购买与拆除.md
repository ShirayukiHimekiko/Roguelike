# 双向购买与拆除

**来源**　原案「敌人 AI」L248–252、「局内资源」L338–344、「双向选择」L407–429，白板 2。

## 功能需求

| 选择 | 玩家及敌方获得的结果 |
| --- | --- |
| 买给自己 | 花金币获得玩家向卡牌、物品、装备或其他增益。 |
| 买给对手 | 敌方获得增益物品或防御塔，玩家获得额外金币。商店买给敌人的物品和 BUFF 立即生效，防御塔在准备阶段由敌方部署。 |
| 花钱拆除敌方内容 | 从敌人背包中移除符合条件的增益物品、防御塔或海克斯。已经上场的建筑不能通过商店拆除。 |

拆除选项会随机出现，原案要求一定回合内必出。原案 QA 允许同回合拆掉刚给对手的内容。白板 2 另写没有金币时可以通过买敌方道具获得金币。

## 待确认

敌方物品和 BUFF 即时生效且不入背包，与「只能拆背包内内容」「本回合可以拆」的共同边界。需明确本回合可拆的是哪类对象、即时生效后是否撤回效果、拆除时由玩家选目标还是商品指定、定价、零金币可用规则、奖励金币及同店重复交易限制。

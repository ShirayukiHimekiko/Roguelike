# 卡牌类型与效果

**来源**　原案「玩家卡牌类型」L223–230、「BUFF系统」L376–403、「卡牌表」L487–489。

## 功能需求

| 卡牌类型 | 玩家可做的事和结果 |
| --- | --- |
| 单位牌 | 在允许位置召唤卡牌描述的单位，单位随后自动行动。 |
| 技能牌 | 施加单位增益、敌方减益，或直接攻击。具体目标与效果随卡牌而变。 |
| 建筑牌 | 部署有存在时间的玩家建筑。建筑不移动，也不攻击。 |
| 强化卡 | 强化玩家自身，原案描述持续一整轮战斗。 |

卡牌还涉及星级、稀有度、解锁、初始牌组、召唤对象、效果和携带羁绊。普通牌、消耗牌和羁绊临时牌的去向见 [牌组与卡牌区域](05-牌组与卡牌区域.md)。

## 待确认

卡牌名单、费用、召唤数量、技能目标、效果明细、建筑存在时间，以及强化卡所说的「一整轮战斗」具体指回合、本层还是整局。

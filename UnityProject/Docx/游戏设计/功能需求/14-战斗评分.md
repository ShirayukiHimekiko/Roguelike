# 战斗评分

**来源**　原案「敌方建筑」L236、「战斗评分」L268–274、「回合表」L535–539。

## 功能需求

每回合用「（造成的总伤害 + 破坏塔获得的积分）÷ 该回合需求的分数底」得到评分比值。根据比值判定档位，区间含左端、不含右端。

| 评分比值 | 档位 | 荣誉值变化 |
| --- | --- | ---: |
| [0, 0.2) | F | -10 |
| [0.2, 0.4) | E | -8 |
| [0.4, 0.6) | D | -6 |
| [0.6, 0.8) | C | -3 |
| [0.8, 1.1) | B | 0 |
| [1.1, 1.5) | A | +2 |
| [1.5, +∞) | S | +5 |

回合编号全局累加，回合分数底随该回合内容确定。评分档位影响奖励，原案另提及高评分可带来更多经验。核心被直接击破时照常获得核心的塔破坏积分。局内累计各回合评分用于额外奖励。

## 待确认

每回合分数底及其变化、伤害统计是否扣除过量伤害、击破核心时连带破损是否计分、是否计入抵抗塔重复破损、局内累计的是比值还是档位对应数值、以及结算时如何向玩家展示分项。

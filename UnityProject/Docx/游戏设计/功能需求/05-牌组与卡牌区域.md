# 牌组与卡牌区域

**来源**　原案「卡牌羁绊」L79–87、「牌组、牌库、手牌、弃牌区、移除区」L161–191，白板 1。

## 功能需求

| 区域 | 用途及变化 |
| --- | --- |
| 局内牌组 | 记录本局整套卡牌。首回合来自角色初始牌组。回合之间可在商店查看及更改。 |
| 牌库 | 战斗期间尚未抽到的牌，开战时由牌组洗匀形成。 |
| 手牌 | 已抽到的牌，初始上限 10 张。白板 1 补充科技树可以提升上限。 |
| 弃牌区 | 收纳结算完成的普通牌与回合结束时弃下的普通手牌，可重新洗回牌库。 |
| 移除区 | 收纳本局已移出的牌，与后续抽牌、洗牌和牌组重建隔离。 |

- 战斗或商店新获得的普通卡进入局内牌组，从下一回合参与洗牌。羁绊临时牌直接入手牌。
- 普通牌结算后进弃牌区，召唤单位继续在场。带「消耗」的牌打出后移除。回合结束时仍在手中的羁绊临时牌直接移除。
- 回合结束后归并牌库、剩余手牌、弃牌区的可用牌与本回合新增的普通牌，供商店阶段操作。局内牌组改动在离局后还原。

- 羁绊按本局牌组中拥有的卡牌种类计算，同一张牌在牌库、手牌和弃牌区之间移动时，牌区变化本身不作为羁绊判据。

## 待确认

羁绊临时牌已打出时去哪里、能否在同回合再抽到，临时牌满手时如何处理，移除牌是否在局内牌组界面可查看。原案明确临时牌应避免反复洗回，但只写明了回合末仍在手中的处理。

## 2. 分步执行

### 2.1 异步启动/释放安全

**目标**：启动帧内退出，不会在释放后又创建 Manager/FSM。

**改 `GameApp.cs`**

```csharp
private static bool _released;

private static async UniTaskVoid StartGameLogic()
{
    await UniTask.Yield();

    if (_released)
    {
        Log.Info("[GameApp] start skipped: app released.");
        return;
    }

    GameAppManager.Instance.Start();
}

private static void ReleaseLogic()
{
    if (_released)
    {
        return;
    }

    _released = true;

    if (GameAppManager.IsValid)
    {
        GameAppManager.Instance.Release();
    }

    SingletonSystem.Release();
    GameModule.Shutdown();
    Utility.Unity.RemoveDestroyListener(ReleaseLogic);
}
```

**验收**：启动后立刻退出，不出现 `fsm started`，也不出现退出后的 Manager 日志。

### 2.2 状态迁移安全

**目标**：End/Exit 不会被暂停/恢复拉回；FSM 已回收时不再 NRE。

**改 `GameAppManager.cs`**

- `_currentState` 返回 null 时，调用方先判空，或增加 `TryGetCurrentState(out GameAppState)`。
- 暂停只接受 Run：

```csharp
if (paused && _currentState is RunGameState run)
{
    run.SwitchState<PauseGameState>(_fsm);
    return;
}
```

- 恢复只接受 Pause：

```csharp
if (!paused && _currentState is PauseGameState pause)
{
    pause.SwitchState<RunGameState>(_fsm);
    return;
}
```

- `OnRelease` 去掉 `!_isStarted` 早退；退订和 `DestroyFsm` 必须无条件执行：

```csharp
protected override void OnRelease()
{
    Utility.Unity.RemoveOnApplicationPauseListener(OnApplicationPause);
    Utility.Unity.RemoveOnApplicationQuitListener(OnApplicationQuit);

    if (!_fsm.IsDestroyed)
    {
        GameModule.Fsm.DestroyFsm(_fsm);
    }

    _fsm = null;
    _isStarted = false;
    Log.Info("[GameApp] manager released.");
}
```

**改 `GameAppState.cs`**：自切换保护去掉 `#if UNITY_EDITOR`，或改成合法迁移校验：

```csharp
public bool SwitchState<TState>(IFsm<GameAppManager> fsm) where TState : FsmState<GameAppManager>
{
    if (GetType() == typeof(TState))
    {
        return false;
    }

    ChangeState<TState>(fsm);
    return true;
}
```

**验收**：End/Exit 收到暂停/恢复不改变状态；未 `Start()` 就释放也会退订/销毁；无 NRE。

### 2.3 单局数据与结果

**目标**：每局有身份、进度、结果，End 只发布一次。

**改 `GameAppManager.cs`**，先加最小字段：

```csharp
private int _runId;
private int _nextRunId;
private float _runSeconds;
private bool _hasResult;
private GameAppResult _lastResult;

public int RunId => _runId;
public float RunSeconds => _runSeconds;
public bool HasResult => _hasResult;
public GameAppResult LastResult => _lastResult;
```

```csharp
public enum GameAppResult
{
    None = 0,
    Completed,
    Abandoned,
    Faulted,
}
```

- `StartGameState.OnEnter` / Manager `BeginRun()`：`_runId = ++_nextRunId; _runSeconds = 0; _hasResult = false; _lastResult = None;`
- `RunGameState.OnUpdate`：`_runSeconds += realElapsed;` 到阈值后 `CommitResult(Completed)` → End。
- `CommitResult(result)`：`if (_hasResult) return; _hasResult = true; _lastResult = result;`

**验收**：RunId 递增；每局只出现一次结果；重复结束不覆盖。

### 2.4 End / Exit 闭环

**目标**：自然结束 → End → Exit → 回 Start，可再开一局。

**改 `EndGameState.cs`**

```csharp
protected override void OnEnter(IFsm<GameAppManager> fsm)
{
    fsm.Owner.CommitResult(GameAppResult.Completed);
}
```

**改 `ExitGameState.cs`**

```csharp
protected override void OnEnter(IFsm<GameAppManager> fsm)
{
    // 下一步在这里做资源/战斗清理
    fsm.Owner.ClearRun();
}
```

`ClearRun()` 只清单局字段；清理完成后切回 `StartGameState`。可以放在 `OnEnter` 末尾直接切，也可以等下一帧，先选简单方案：

```csharp
protected override void OnEnter(IFsm<GameAppManager> fsm)
{
    fsm.Owner.ClearRun();
    ChangeState<StartGameState>(fsm);
}
```

**注意**：`ExitGameState` 不再自动切 `EndGameState`；End 由自然结束/手动结束进入，Exit 只负责清理和回 Start。退出应用时如果希望先 End 再 Exit，由 `OnApplicationQuit` 决定切 End 还是 Exit，不要在两个状态里互相切。

**验收**：Run → End → Exit → Start；再次 Start 得到新 RunId；应用退出不会进入死循环。

### 2.5 主动结束/放弃入口

**目标**：没有 UI 也能验收结束/放弃。

**改 `GameAppManager.cs`**，加两个最简方法：

```csharp
public void EndGame()
{
    if (_currentState is RunGameState run)
    {
        run.SwitchState<EndGameState>(_fsm);
    }
}

public void AbandonGame()
{
    if (_currentState is RunGameState || _currentState is PauseGameState)
    {
        CommitResult(GameAppResult.Abandoned);
        _currentState.SwitchState<ExitGameState>(_fsm);
    }
}
```

`EndGame` 进入 End 后由 `EndGameState.OnEnter` 提交 `Completed`；`AbandonGame` 先提交 `Abandoned`，再 Exit。

**验收**：Run 中 EndGame → End；Run/Pause 中 AbandonGame → Exit → Start；结果只出现一次。

### 2.6 日志

建议补齐：

```text
[GameApp] start skipped: app released.
[GameApp] run begin: runId=1
[GameApp] run end: runId=1, result=Completed
[GameApp] abandon: runId=1
[GameApp] exit: runId=1
[GameApp] manager released.
```

日志只记录状态变化和结果，不在每帧打。

## 3. 验收总表

| 用例 | 预期 |
|---|---|
| 正常启动 | `fsm started`，当前 Run，RunId=1 |
| 启动帧内退出 | 不创建 Manager，不出现 `fsm started` |
| 暂停/恢复 | 仅 Run ↔ Pause；End/Exit 不受影响 |
| 自然结束 | Run 到阈值 → End(Completed) → Exit → Start |
| 手动结束 | Run 中 `EndGame()` → End(Completed) |
| 主动放弃 | Run/Pause 中 `AbandonGame()` → Exit(Abandoned) → Start |
| 再开一局 | Start 后 RunId=2，进度归零 |
| 未启动释放 | 退订 + DestroyFsm，无 NRE |
| player 关闭 | 先 Exit/End，再 OnRelease 销毁，不复活 Manager |
| 重复 Start/End | 只生效一次，有 ignore/去重日志 |

## 4. 不包含

- 固定帧驱动：Run 的推进先用 `realElapsed` 或手动，等第二步闭环后再接原 02。
- 战斗模块、UI、样本/资源加载、存档/回放、事件总线。
- 奖励/结算数值；结果只保留枚举。

# F10：玩家暂停 vs 切后台实现方案

2026-11-16 · 待确认实施稿

前置：[第二步功能补充清单](02-游戏生命周期第二步功能补充清单.md) 的 F10。  
目标：把“玩家主动暂停”和“应用切后台”分开记录，避免切后台暂停后回到前台被玩家的暂停状态卡住，或玩家暂停被后台恢复自动顶掉。

## 0. 当前行为

`GameAppManager.OnApplicationPause` 现在不区分来源：

```csharp
if (paused)
{
    _currentState.SwitchState<PauseGameState>(_fsm);
    return;
}

_currentState.SwitchState<RunGameState>(_fsm);
```

问题：

- 玩家暂停后切后台，再回前台，会被直接切回 Run，玩家的暂停丢失。
- 没有玩家主动暂停入口，只有切后台。
- 无法知道当前 Pause 是玩家按的还是系统切的。

## 1. 暂停来源模型

新增最小枚举，放在 `GameAppManager.cs` 顶部即可，不单独建文件：

```csharp
public enum GamePauseSource
{
    None = 0,
    Player,
    Application,
}
```

`GameAppManager` 增加字段：

```csharp
private GamePauseSource _pauseSource;
```

规则：

| 当前状态 | 事件 | 结果 |
|---|---|---|
| Run | 玩家 `PauseGame()` | Pause，source=Player |
| Run | 应用切后台 | Pause，source=Application |
| Pause(Player) | 应用切后台 | 保持 Pause，source 仍为 Player |
| Pause(Player) | 应用回前台 | 保持 Pause，不自动恢复 |
| Pause(Application) | 应用回前台 | Run，source=None |
| Pause(Application) | 玩家 `ResumeGame()` | 拒绝（等应用回前台） |
| End / Exit | 暂停/恢复 | 忽略，不切状态 |
| 任意 | 重复切后台/回前台 | 幂等，不重复切状态 |

## 2. 玩家暂停 API

```csharp
public bool PauseGame()
{
    if (!_isStarted || _currentState is not RunGameState)
    {
        Log.Info("[GameApp] pause rejected: not in run.");
        return false;
    }

    _pauseSource = GamePauseSource.Player;
    _currentState.SwitchState<PauseGameState>(_fsm);
    Log.Info("[GameApp] pause: source=Player.");
    return true;
}

public bool ResumeGame()
{
    if (_currentState is not PauseGameState)
    {
        Log.Info("[GameApp] resume rejected: not paused.");
        return false;
    }

    if (_pauseSource != GamePauseSource.Player)
    {
        Log.Info($"[GameApp] resume rejected: source={_pauseSource}.");
        return false;
    }

    _pauseSource = GamePauseSource.None;
    _currentState.SwitchState<RunGameState>(_fsm);
    Log.Info("[GameApp] resume: source=Player.");
    return true;
}
```

规则：

- 玩家只能从 Run 进 Pause。
- 玩家只能恢复自己按下的暂停；`Pause(Application)` 必须等应用回前台。
- 没有 UI 时，这两个方法就是调试入口。

## 3. 切后台/回前台

```csharp
private void OnApplicationPause(bool paused)
{
    if (!_isStarted)
    {
        Log.Info("[GameApp] pause event ignored: manager not started.");
        return;
    }

    if (paused)
    {
        if (_currentState is RunGameState)
        {
            _pauseSource = GamePauseSource.Application;
            _currentState.SwitchState<PauseGameState>(_fsm);
            Log.Info("[GameApp] pause: source=Application.");
        }

        return;
    }

    if (_currentState is PauseGameState && _pauseSource == GamePauseSource.Application)
    {
        _pauseSource = GamePauseSource.None;
        _currentState.SwitchState<RunGameState>(_fsm);
        Log.Info("[GameApp] resume: source=Application.");
    }
}
```

关键点：

- 切后台只在 Run 时进入 Pause；Pause(Player) 不覆盖来源。
- 回前台只恢复 `Pause(Application)`；`Pause(Player)` 保持暂停。
- 切后台/回前台重复触发时，状态检查保证不会重复切换。

## 4. 清理

`OnRelease` / 后续 `ExitRun` 里清空来源：

```csharp
_pauseSource = GamePauseSource.None;
```

不入结果、不写存档；暂停来源只属于运行期。

## 5. 文件变更

```text
Module/GameAppModule/
├── GameAppManager.cs      （改：GamePauseSource + _pauseSource + PauseGame/ResumeGame + OnApplicationPause）
└── State/
    ├── RunGameState.cs    （不变）
    └── PauseGameState.cs  （不变）
```

`GameApp.cs` 不改。

## 6. 验收

| 用例 | 预期 |
|---|---|
| Run 中 `PauseGame()` | 进入 Pause，source=Player |
| Pause(Player) 中 `ResumeGame()` | 回到 Run，source=None |
| Run 中切后台 | 进入 Pause，source=Application |
| Pause(Application) 回前台 | 自动回 Run，source=None |
| Pause(Player) 切后台再回前台 | 仍是 Pause，source=Player，不自动恢复 |
| Pause(Application) 调 `ResumeGame()` | 拒绝，状态不变 |
| End/Exit 切后台 | 不切状态 |
| 未 Start 时暂停事件 | 只打 ignore 日志 |
| 重复切后台/回前台 | 不重复切换 |
| 玩家暂停后退出 | Exit 正常，source 清理 |

## 7. 不包含

- UI 暂停菜单/按钮。
- `Time.timeScale`、动画/音频/粒子的表现冻结。
- 输入系统、断线重连、剧情暂停。
- 暂停原因扩展（如 `Reconnect`、`Cutscene`）；需要时再加枚举值。

# 游戏生命周期第一步：GameAppManager + FSM

2026-11-16 · 第一步最小稿

## 0. 这一步只做什么

只做：

1. `GameAppManager` 单例。
2. 在 `OnInit()` 里创建 5 状态 FSM，`Start()` 只负责启动。
3. 5 个状态类 + 1 个状态基类；`StartGameState` 进入即切 `RunGameState`，`End/Exit` 先空着。
4. `GameAppManager` 内部订阅应用暂停、恢复、游戏退出；销毁走 `OnRelease`。

```text
GameAppManager.Instance          // 单例创建时 OnInit 里 CreateFsm + 订阅
  └─ Start()                     // _fsm.Start<StartGameState>()
       └─ StartGameState.OnEnter // 立即 SwitchState<RunGameState>

应用事件：
  OnApplicationPause(true)   → 当前状态切 PauseGameState
  OnApplicationPause(false)  → 当前状态切 RunGameState
  OnApplicationQuit          → 当前状态切 ExitGameState
  OnRelease                  → 当前状态切 EndGameState → DestroyFsm
```

**这一步不做**：`GameAppStateId`、`GameAppRequest`、`GameAppExitReason`、手动开始/结束方法、计时、结果、进度、样本、资源、UI、事件总线、快照。

`GameApp.cs` 不改；FSM 启动后停在 `RunGameState`，由应用事件驱动。

## 3. GameAppManager.cs

```csharp
using TEngine;

namespace GameLogic
{
    /// <summary>
    /// 生命周期唯一入口：创建并持有一个 5 状态 FSM。
    /// 同时订阅应用暂停/恢复、游戏退出和销毁。
    /// </summary>
    public sealed class GameAppManager : Singleton<GameAppManager>
    {
        private IFsm<GameAppManager> _fsm;

        private bool _isStarted;

        private GameAppState _currentState
        {
            get
            {
                if (_fsm.CurrentState is not GameAppState state)
                {
                    Log.Error($"[GameApp] current state is not GameAppState: {_fsm.CurrentState?.GetType().Name ?? "null"}.");
                
                    return null;
                }

                return state;
            }
        }

        protected override void OnInit()
        {
            _fsm = GameModule.Fsm.CreateFsm("GameApp", this,
                new StartGameState(),
                new RunGameState(),
                new PauseGameState(),
                new EndGameState(),
                new ExitGameState());

            Utility.Unity.AddOnApplicationPauseListener(OnApplicationPause);
            
            Utility.Unity.AddOnApplicationQuitListener(OnApplicationQuit);
        }

        public void Start()
        {
            if (_isStarted)
            {
                Log.Info("[GameApp] start ignored: manager already started.");
                    
                return;
            }

            _isStarted = true;
            
            // Start 可能被重复调用（热更重入）；Fsm.Start 重复会抛，只留这一条
            if (_fsm.IsRunning)
            {
                return;
            }

            _fsm.Start<StartGameState>();
            
            Log.Info($"[GameApp] fsm started");
        }

        private void OnApplicationPause(bool paused)
        {
            if (!_isStarted)
            {
                Log.Info("[GameApp] pause ignored: manager not started.");
                    
                return;
            }
            
            // 应用进入后台后 Update 不会再跑，不能等下一帧；这里直接切状态
            if (paused)
            {
                _currentState.SwitchState<PauseGameState>(_fsm);
                    
                Log.Info("[GameApp] fsm pause.");

                return;
            }

            _currentState.SwitchState<RunGameState>(_fsm);
                
            Log.Info("[GameApp] fsm resume.");
        }

        private void OnApplicationQuit()
        {
            if (!_isStarted)
            {
                Log.Info("[GameApp] quit ignored: manager not started.");
                    
                return;
            }
            
            _currentState.SwitchState<ExitGameState>(_fsm);
                
            Log.Info("[GameApp] fsm quit.");
        }

        protected override void OnRelease()
        {
            if (!_isStarted)
            {
                Log.Info("[GameApp] release ignored: manager not started.");
                    
                return;
            }
            
            _isStarted = false;
            
            Utility.Unity.RemoveOnApplicationPauseListener(OnApplicationPause);
            
            Utility.Unity.RemoveOnApplicationQuitListener(OnApplicationQuit);
            
            _currentState.SwitchState<EndGameState>(_fsm);
                
            Log.Info("[GameApp] fsm destroy.");

            // player 关闭顺序可能先 ModuleSystem.Shutdown，FSM 已被回收；只留这一条
            if (!_fsm.IsDestroyed)
            {
                GameModule.Fsm.DestroyFsm(_fsm);
            }

            _fsm = null;
            
            Log.Info("[GameApp] manager released.");
        }
    }
}
```

### 3.1 关键判断说明

| 判断/字段 | 作用 | 说明 |
|---|---|---|
| `_isStarted` | 标记生命周期是否已启动 | `Start` 前收到暂停/退出/释放事件直接忽略并打日志 |
| `_currentState` | 把 `_fsm.CurrentState` 转成 `GameAppState` | 不是状态基类时打 Error 并返回 null |
| `Start` 里的 `_isStarted` | 防重复启动 | 重复调用只打 `start ignored` |
| `Start` 里的 `_fsm.IsRunning` | 防热更重入时重复 `Fsm.Start` | `Fsm.Start` 重复会抛 |
| `OnRelease` 里的 `!_fsm.IsDestroyed` | player 关闭顺序可能先回收 FSM | 只在 FSM 仍存活时 `DestroyFsm` |

### 3.2 生命周期订阅

| 事件 | 订阅方式 | 处理 |
|---|---|---|
| 暂停 | `Utility.Unity.AddOnApplicationPauseListener` | `OnApplicationPause(true)` → `_currentState.SwitchState<PauseGameState>(_fsm)` |
| 恢复 | 同一个 `OnApplicationPause(false)` | `_currentState.SwitchState<RunGameState>(_fsm)` |
| 游戏退出 | `Utility.Unity.AddOnApplicationQuitListener` | `_currentState.SwitchState<ExitGameState>(_fsm)` |
| 释放/销毁 | `SingletonSystem.Release()` → `OnRelease` | `_currentState.SwitchState<EndGameState>(_fsm)` → `DestroyFsm` |

`OnRelease` 里统一退订暂停和退出两个入口；没有单独订阅 Destroy，销毁统一由 `OnRelease` 处理。

### 3.3 TEngine 扩展：Utility.Unity 增加游戏退出事件

原 `Utility.Unity` 只有 Pause 和 Destroy 注入，没有 OnApplicationQuit。此次补三处：

| 文件 | 增加 |
|---|---|
| `IUpdateDriver` | `AddOnApplicationQuitListener(Action)` / `RemoveOnApplicationQuitListener(Action)` |
| `UpdateDriver` | 包装到 `MainBehaviour`，新增 `OnApplicationQuitEvent`；`OnApplicationQuit()` 里触发；`Release()` 里清空 |
| `Utility.Unity` | 对应静态 `Add/RemoveOnApplicationQuitListener` |

### 3.4 当前代码的待确认点

| # | 现状 | 风险/建议 |
|---|---|---|
| 1 | `OnRelease` 先 `_currentState.SwitchState<EndGameState>`，再判断 `!_fsm.IsDestroyed` | 若 player 关闭时 `ModuleSystem.Shutdown` 已回收 FSM，`_currentState` 会返回 null，`.SwitchState` 直接 NRE；建议先判 `_fsm.IsDestroyed` 再切 End，或给 `_currentState` 加空判断 |
| 2 | `OnRelease` 在 `!_isStarted` 时直接 return | `OnInit` 已经创建 FSM 并订阅事件；未 `Start()` 就释放时不会退订、也不会 `DestroyFsm`；确认是否有意，否则应补清理 |
| 3 | `OnApplicationPause(true/false)` 不判断当前状态 | End/Exit 收到暂停/恢复会被切到 Pause/Run；建议恢复 `is RunGameState` / `is PauseGameState` 限制，或由 `SwitchState` 做合法迁移校验 |
| 4 | `_currentState` 返回 null 后调用方直接 `.SwitchState` | 事件回调里先判 null，或让 `SwitchState` 返回 bool，避免异常路径 NRE |

```csharp
using TEngine;

namespace GameLogic
{
    /// <summary>
    /// 状态基类：对外公开切换方法，Manager 不需要知道具体状态类型。
    /// </summary>
    public abstract class GameAppState : FsmState<GameAppManager>
    {
        public void SwitchState<TState>(IFsm<GameAppManager> fsm) where TState : FsmState<GameAppManager>
        {
            if (GetType() == typeof(TState))
            {
                return;
            }

            ChangeState<TState>(fsm);
        }
    }
}
```

## 5. GameApp.cs 不改

这一步不修改 `GameApp.cs`，也不改 `StartGameLogic` / `ReleaseLogic`。

- 需要启动时，由现有流程或后续接线调用 `GameAppManager.Instance.Start()`。
- 暂停/恢复、游戏退出都在 `GameAppManager.OnInit` 内部订阅，不改 `GameApp`。
- 需要释放时，现有 `SingletonSystem.Release()` 会走 `GameAppManager.OnRelease()`；`OnRelease` 负责退订、切 End、销毁 FSM。
- 因此这一步只落 7 个脚本，不改任何已有文件。

## 9. 说明

- 这一步没有 `GameAppStateId`、没有 `GameAppRequest`、没有 `GameAppExitReason`、没有手动推进方法、没有计时。
- `CreateFsm` 放在 `OnInit`，`Start()` 只负责 `_fsm.Start<StartGameState>()` 和日志；`Start` 用 `_isStarted` 防重复。

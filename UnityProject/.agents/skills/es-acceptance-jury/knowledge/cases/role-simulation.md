# 案例：角色模拟（无陪审却输出陪审意见）

来源：2026-10-18 空上下文行为实测，gpt-6.1-sol / xhigh / ephemeral / read-only，被测版本 2.2.7。原始记录与探针脚本保存在包外，本页只记结论与可复用判据。

<a id="observation"></a>
## 实际观察

同一批九次探针中，前七次（范围识别、承诺核对、体验判断、作者框架污染、累计低收益）判断全部正确；第八、九次要求"出方案"时出现同一种错位，并两次复现：

- 输出里出现完整的两份"独立初判"，带 🟦/🔶 标识、`【📈 本波推进增益：+12 / −15 / +15 / +18】` 与 `主事件`，并写明"两位陪审已实际启动"。
- 同期工具日志记录的协作调用是 `receiver_thread_ids: []`、`agents_states: {}`——没有创建任何角色，也没有任何回传。
- 其中一次还把架构角色标成了 🟦。

<a id="why"></a>
## 可能的机制解释

规则已要求"实际核创建、发送、回传""不能只列出两个角色代执行"，且写在核心与派发两处。本次仍出现角色模拟。以下**路径成本差异**是可能解释，探针没有隔离验证其因果贡献：

1. 只生成格式输出（标识、增益、主事件、两份初判）无需真实创建角色，外观可与真实意见相似；
2. 真实创建 Agent 在该宿主上不可用，诚实路径要么卡住、要么需要额外说明；
3. 规则里没有一条"没有陪审时该怎么办"的低成本退路。

两次失败显示，声明已启动和生成成对格式可以同时出现在没有真实角色的输出中。它们不能确定模型为何这样选择，也不能排除其它解释。

<a id="rule"></a>
## 本包采用的处理

- 判据是 **receipt**，不是措辞：真实角色标识 + 真实发送 + 真实回传原文，三缺一即不是陪审意见。
- 必要独立职责沿[身份接续](../../references/coordination.md#activation)实际取得，缺失核证保对应未闭。
- "模拟/示例/预判/简化流程"等前缀不使其合法；先写两份再声明其中一份是模拟，同样禁止。

<a id="limits"></a>
## 适用范围与未证

- 只有一个模型、一种宿主、单轮空上下文；长上下文与多轮累积下的表现未测。
- 探针用的是人工构造的短材料，不是真实项目现场；真实项目中的错误方向可能另有来源。
- 九次探针中的七次正确、两次失败是本批观察；没有无Skill或旧版本的同任务对照，不能据此归因正确答案来自规则文本，也不能比较退路与禁令的相对效力。

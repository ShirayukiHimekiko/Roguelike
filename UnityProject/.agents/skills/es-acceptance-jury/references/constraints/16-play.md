# 内置候选｜16真实玩法

Unity游戏按本阶段批准的玩家过程命中；方案核可实施性，原型按指定机制，不统一追加胜败/存档。命中须沿[专项扫描](../candidate-scan.md)实际看源、玩法规则/生产caller与相应真实观察。

| 编号与短名 | 精准触发 | 要核的风险与实际对象／唯一正文 |
|---|---|---|
| 16/01 玩家目标与阶段 | 功能/代码列表代用户要玩的结果 | 验收对象被作者实作反推；核原目标与批准机制，读[玩家目标](../real-play.md#play-target) |
| 16/02 玩家可达局面与当下世界 | 场景/视角转换、局面可达或当前对象状态待证 | 核真实推进到此刻的依据及全部应有单位/建筑/UI的位置状态，读[游戏流程](../real-play.md#play-chain) |
| 16/03 规则与选择后果 | 按钮/动效有反应却不影响真实机制或挑战 | 假经济/永成功/目标不推进；核选择→规则→后果，读[规则](../real-play.md#rule-consequence) |
| 16/04 暂停退出与后继 | Busy/取消/已提交/读档/再次进入卡死或重放 | 丢状态/重扣/重奖/旧回调穿run；核实际合法事件顺序，读[状态与后继](../real-play.md#play-states) |
| 16/05 整体可玩品质与改法 | 难度、节奏、风格、流畅、机制配合或视听品质待证 | 按本游戏与玩家判断整体体验，追原因并给可制作改法，读[可玩性](../real-play.md#feel-and-presentation) |
| 16/06 可玩证据与本波推进 | 源码/编译/候选数量签可玩，玩法长期后排 | 局部绿掩实际断点；核当前宿主与连续结果/有限下一步，读[证据](../real-play.md#play-evidence) |

必要业务、资源、生命周期、视觉和性能的已有编号仍定位其唯一责任，不重复造规则。仅真实适用状态列反例，不新造游戏机制求测试覆盖。

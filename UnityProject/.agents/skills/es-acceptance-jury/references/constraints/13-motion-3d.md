<a id="scope"></a>
## 13/01 完整动作目标

当任务包含角色、生物或物件的3D动作、转向、移动、持物、接触或动作衔接时读取本页。
先按[当前要求与证据范围](../review-standard.md#decision-order)固定本批阶段：旋转算法、动作白盒、完整动作或
明确的高品质表现分别取证。检查本阶段约定的空间关系与动作范围，不自动追加顶尖观感。
目标包含完整动作/运动体验时，单个Clip播放、碰撞/扣血或终态正确不能代表完整通过。
纯UI、静态模型和无此目标的代码任务不因此新增动画要求；方案审查只能验方案，不能称成品通过。

从原目标与项目当前功能固定必要动作、角色/骨架、装备组合、环境及分支：例如起步/行走/
奔跑/制动/转身、瞄准侧移、跳跃落地、翻越攀爬、攻击防御受击、持物换手或双人交互。
只选实际适用者，但不得由已经做出的动作反推需求。需要完整动作时，按实际阶段走准备→发力/移动→接触或
作用→收势→到达约定终态，覆盖目标内的循环、取消、反向、连发、状态重入和相邻转换。
可操作角色按约定恢复控制；死亡、一次性破碎或演出结束允许合法终止，不强制恢复操作。
一个代表小样用于找共同原因；未经说明不能代表全部动作、骨架或方向都已通过。

原有[目标覆盖](../review-standard.md#goal-coverage)拥有分项与整体裁定；本页不新建状态、评分
或审批系统。既有风险优先检查，未知与失败分开；资料/工具缺失按[恢复路径](../evidence-recovery.md)
主动补齐适用缺口，不擅降既定要求，也不强制用户手工逐帧检查。

<a id="basis"></a>
## 13/02 原项目依据

先读原项目动作约定、当前作者数据和真实控制/动画链。记录实际坐标与单位、上下/前向轴、
左右侧、父空间、当前移动/动画/碰撞所有者；不能默认所有项目Y向上、Z向前或1单位=1米。
骨骼局部旋转、模型朝向、世界轨迹、相机画面分别观察；镜像、负缩放、重定向与父级旋转
可能改变解释，名称如Left、Forward或Socket不证明实际语义。

正常速度玩家视角用于体验；必要诊断视角与原生采样用于定位。已有定义/动作要求、合适的
公开参考和实测共同形成预先成立的容差与时序，不统一写死所有动作的角度、速度、距离、
足滑厘米数或过渡时长。不能发现偏差后扩大阈值让当前结果通过；未知阈值要说明哪些判断
仍可成立、缺什么依据，已明确的反关节/错向等问题不能被“尚无阈值”抹掉。

业内资料按[来源与使用边界](../../knowledge/sources/motion-3d-sources.md)选择；记录具体页面/章节或真正观察过的
视频片段。只有标题、缩略图或演讲介绍时不能声称看过动作。不把实现算法、技术功能或
某家引擎默认值当成审美标准。高质量目标同时检查动作意图、轮廓、重心/支撑、重量感、
发力与回收、连续性、输入反馈及风格；技术与表现分别结论，不用“接上IK”代替。

任务要求特定游戏或顶尖表现时，选可核实的团队分享、官方演示或实际交互录像，注明游戏/版本、角色/动作、片段和触发。先核移动系统、视角、锁定方式、角色尺度/风格、输入和地形的可比性，再以正常速度比较双方完整阶段及方向/位移轨迹，慢放诊断另标；单个精彩剪辑不代表全部场景。参考支持具体可读性、重量、连贯或响应判断，不要求照搬技术栈或物理写实。精确同类素材缺失时主动查找并保目标与缺口，不以知名来源代当前作品验收。

<a id="spatial-checks"></a>
## 13/03 空间时序

每个命中问题先写一句待推翻假设，选择最容易揭错的阶段/方向，用现有项目工具取证。
下表为检查方法，不是所有任务全量必跑的固定清单。陪审不得只看作者的结果摘要。

| 对象 | 必须区分与实际检查 | 失败信号与合法对照 |
| --- | --- | --- |
| 完整旋转 | 在同一空间检查实际完整姿态，包括扭转/roll、祖先变换、左右侧与重定向；180度附近转向、斜向和非正对目标按风险选。四元数q与-q同姿态；仅forward点积不能证明握持/关节旋转正确。 | 同向但手腕翻转、反关节、错手、意外绕长弧、父变换后姿态跳变需定位；设计要求翻滚/多圈旋转合法。 |
| 时间上的旋转 | 保留带真实时间的中间姿态、转向方向/角速度及切换前后连续性；故意多圈需轨迹或足够采样，端点最短旋转无法表达圈数。零方向和接近180度的左右选择按项目合同判断。 | 非预期抖动、瞬时反转、接缝突跳、输入已释放仍持续转身；风格化有意顿帧/跳切按既定设计和作用评判。 |
| 方向关系 | 分开输入意图、世界移动/速度、模型身体朝向、头/眼/瞄准、武器作用端、目标/命中和相机朝向；把每条关系映射到当前阶段。检查前后左右及必要斜向、转身/锁定/失去目标的边界。 | 锁定目标却打向背后、镜头旋转导致世界方向错配、枪口/刃向与实际作用矛盾；侧移、倒退、独立瞄准不能因身体不朝速度方向被否决。 |
| 位移与所有者 | 对齐动画根、角色/碰撞体、视觉模型的实际轨迹与预期路径；明确Root Motion提取/应用和控制器驱动各自作用，检查是否重复应用或视觉/碰撞分离。按实际dt看距离、速度、制动、落地和恢复，禁止把局部位移当世界位移相加。 | 双重位移、收势回弹/瞬移、脚步频率与行进不匹配、撞墙仍穿行或意外丢高度；in-place配控制器、合法冲刺/传送和设计要求mesh offset均可成立，须按合同检边界。 |
| 路径与可达性 | 检查路径/目标本身是否可达，再看实际角色体积、接触边界、碰撞修正和到达方向；目标变化/越界或运动扭曲超有效范围时观察失败/回退。 | 穿障碍到端点、强行拉长肢体、忽略垂直差、位移到了但朝向/后续站姿错误；合理受阻停止、重选路径或明确受控位移不算失败。 |
| 接触与支撑 | 按真实接触阶段检查脚/掌/握柄/作用端与实际表面、关节可达、穿插和相对滑动；移动/旋转平台在各时刻支撑物局部坐标下比较接触点，不能只看世界速度。 | 承重脚滑移、足底悬浮、穿地、手离柄、持物突然换侧、非预期肢体伸缩；摆腿腾空、设计滑步、移动平台带动的世界位移与允许的软表面形变不是同类缺陷。 |
| 动作与结果时序 | 对齐预备、发力、接触/攻击有效窗、业务结果、音画反馈和可操作恢复；实际攻击轨迹/方向与命中判定检查空间及时间对应，合法宽容度按玩法约定。 | 未接触先结算却无既定规则、攻击从错误方向命中、恢复后仍锁输入、重复触发双结算；提前缓冲、取消窗口、辅助瞄准/宽容判定不机械等同真实物理。 |
| 衔接与控制权 | 在上/下身分层、additive、IK、根运动、重定向和状态转换后观察最终求解姿态；按风险测取消、反向、连发、死亡/落地/碰撞及控制移交的适用分支。 | 单Clip正常但混合后扭曲、上一动作残余权重、旧目标继续控制、恢复一帧跳变；设计冻结/短暂无输入阶段须有原约定及正确恢复。 |

旋转误差可用规范化四元数的同姿态最短角辅助判断，但它不测累计转数，也不能在零长度、
非有限值或来源空间未知时给有效结果；不得新造数值填空。位移/角速度使用相同时间基准，
区分仿真步与渲染帧；时间空洞、重复时间和稀疏采样标缺口，不能插值补成实测。
动态支撑要使用随时间变化的完整支撑变换；仅减平台线速度会漏掉平台旋转。
最终提交的所有权清晰不等于只能有一种运动贡献：平台、动画、主动控制、外力和碰撞修正
可以按原项目明确顺序合成；分别核对来源、适用阶段及仅应用一次，不强制拆成单驱动方式。
非人形、飞行、游泳和机械运动使用各自支撑/驱动模型；没有双足承重的对象不套人体步态条件。

<a id="evidence"></a>
## 13/04 动作真实证据

以下按本阶段要声明的结论选择；算法或方案审查可用相应技术/文本证据，不自动要求成品录像。

1. 绑定适用的构建/场景、角色/动作/资产、必要输入、原始媒体或采样和版本。固定诊断相机或
   显示空间参照，区分相机移动与目标移动；不能单凭屏幕像素轨迹推算世界位移。
2. 验收动作表现时，亲自以正常速度观察实际运行或可播放的完整片段；任务包含交互/输入时，再观察真实操作的
   状态/反馈。自主机械动作或非交互演出不新增玩家输入义务，仍检查其实际触发与约定终态。
   按实际动作覆盖适用的往返与中断，不把Editor拖时间、慢放、关键帧或骨架线框当正常速度体验。
3. 对怀疑的旋转/方向/位移/接触问题，在风险时刻补原生变换/接触时间序列与适用多视角。
   数据从项目最终求解/提交阶段取，原始数据与对照可复读；单帧仅支持该时刻，图像不独自
   证明3D旋转、深度或接触。只要证据能回答目标问题就不强制装某家工具或新增采集框架。
4. 针对已成立的质量目标分别写技术状态与表现判断：准备/发力/收势是否有可读意图和重量，
   起停与转向是否可信，轮廓与肢体跟随是否清楚，操作到反馈是否及时，强调是否服务任务。
   绑定具体片段和理由；缺连续观察时不能称动作流畅，只有数字过线时不能称顶尖观感。
5. 复验保留原失败输入/时刻和合法对照，从当前版本重走受影响完整链及相邻阶段；共享骨架、
   材质、控制器、IK或混合改动按实际依赖复查已通过内容。姿态修好了不自动关闭命中时序
   或手感问题，不能把失败改成缺证、删分支或靠换版本清零。

技术结果、动作表现、适用的输入体验与参考一致性分别保留通过/返工/证据不足/未运行，汇回既有
目标记录。记录原目标、实际对象/阶段、空间/时间依据、观察、影响、责任源与复验条件即可，
不另加所有任务必填字段。没有采集工具或参考时双方主动查找；本页提供审查方法，不声称
已内置3D运行器、自动姿态识别器或数学求解器，不授予操作游戏或改角色资产权限。

## 02/03—02/05 共同性能边界

证据协议、游戏 JSON/schema 时机与业务身份的适用边界，只按[运行边界](../must-read-continuity.md#runtime-evidence-boundary)执行；落盘及工具调用按[关键增量](../must-read-continuity.md#incremental-records)。

<a id="budget-cost"></a>
### 02/03 真实项目预算

按当前预算沿受影响生产caller追到实际宿主/引擎及依赖实现，区分已知成本、用户报告、已有测量和本轮未测，核调用次数及累计负载。查无变化全刷新、整对象复制、每击排序/闭包、装箱、监听重装、隐藏初始化、热扩、重复采样/重建和不必要保存；Unity/UGUI例中ColorTint可经CrossFadeColor创建回调/迭代器并启动协程，须核实际包及发生条件，不判每次赋值都分配。减少一处调用或移到首次、准备、预热、失败、退出/后台不证明全链达标；项目禁止这些阶段分配时不得豁免。

Unity ObjectPool空Get可创建，defaultCapacity不预建实例，maxSize不限制全部在用量；RaycastNonAlloc满缓冲可漏命中且不保证最近，须保原选取语义和饱和处理。

<a id="equivalent-effects"></a>
### 02/04 等效效果

修真实责任源并保玩法、交互、反馈及合法对照；位置/颜色/姿势/几何按真实变化处理。不得未经任务依据或用户认可删反馈、动作/内容、关控件或冻结动画冒称原标准达标，也不隐藏失败；已批准质量档位按目标验证并说明取舍，复用既有授权。已知分配违反当前禁令标失败，否则按项目预算和必要测量判断；未观察CPU/GPU/帧稳定性标缺证。项目预算不推广全域；平均FPS、池化/缓存名称或源码无关键词不认证逐帧结果。

Canvas按真实变化关系隔离，同时看Layout、脚本、合批及GPU成本；拆分不必然更快，透明不代输入或生命周期关闭。

<a id="cost-evidence"></a>
### 02/05 准确成本观察

值类型 new 不凭词形判托管分配；GC 计数、失效的零值和限帧参数不证明各线程字节或逐帧达标。核采集是否改变焦点、暂停或业务时间而阻断待测操作，诊断开销与产品成本分开；一次保存耗时不冒认另一玩家动作延迟。

先分CPU/GPU实际工作与等待；Deep Profiling会扰动成本，外部案例只作其设备、版本和场景下的线索。

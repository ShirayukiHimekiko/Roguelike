# 内置候选｜03UI

UI 设计、制作、去冗余、布局或交互变更时读取本页；仅查某接口签名不强制整页视觉验收。按当前用户的真实修改意见和页面用途判断，不把历史原型、旧陪审建议或母版装饰变成更高权威。

<a id="03-01"></a>
## 03/01 页面职责

首样取舍先核这页帮助当前用户完成哪个必要目标，以及新增机制、功能、文字、状态和步骤为何值得存在；F核真实任务与后继代价，A核画面主次及视线／上下文连续性。删除无用途的功能和入口，不只是把它们藏进更深菜单；必要复杂控制按真实任务保留。用户已明确缩窄页面职责时真实作用于生产页，不能借“完整功能”换名回填；其他页面的数据与合法业务不连带删除。

<a id="03-02"></a>
## 03/02 文字减负

新增信息须服务当前可见判断；对重复成功文字、长教程、名称和提示/预警，核是否已有准确状态/图像/音效表达，语义正确或可以折叠本身不证值得存在；移除无用途或用户明确要求删除的项，不换文案复活。保必要教学、对象辨识、真实危险/拒绝原因和不可逆后果；删除范围沿原话，不泛化为全游戏无名称/警示。真实内容、最长必要文案与角色遮挡一起复看。

<a id="03-03"></a>
## 03/03 视觉减负

无意义框、重复底板、抢信息的木纹/草地/装饰按实际用途删减，保认可风格和必要层级。用户明确删除的背景板或选中框不能以母版/默认选中样式为由加回。精简不等于全页无装饰、全缩字、缩点击区或磨掉识别点；把主体、对照和外围信息放回实际视口核主次，指明哪个竞争区削弱当前目标或对照判断，无遮挡／可辨认不代品质。

<a id="03-04"></a>
## 03/04 常驻与收展

按真实使用让闲置信息退场，必要入口、当前决策所需状态、收起后仍适用的能力和约定唤醒条件保持可发现。不能因“方便”新增用户已拒绝的常驻面板；具体信息、能力、键位与自动收回策略沿已采用来源，不从静图猜定。项目对象及决定只在下节对应范围恢复。

<a id="03-05"></a>
## 03/05 卡片与信息关系

涉及卡片待选、移动或入槽时，保持同一对象辨识及认可比例；图像与当前必要信息、状态、标题和菜单不互压。存在预览、选择、章节导航等不同用途时沿各自真实流程；自然候场、群体、变体与数量只在实际存在该对象及已采用目标时核查。细微对齐不能替整屏层级及已要求的动态体验达标。

<a id="03-06"></a>
## 03/06 必要状态与反馈

UI 状态来自原业务：可用、选中、费用/冷却、缺料、锁定、Busy、拒绝及部分结果不能随意归成一色或永拒壳。输入收到与业务成功分别表达；去重复文字仍保每步可感知、准确的必要音画。真实提交及守恒用 05/02，不能靠删除反馈或增加成功弹窗凑体验。

<a id="03-07"></a>
## 03/07 命中与返回

主要动作稳定可达，切换目标容易点中；必要返回有真实去向。实际入口、适用收窗、上下文切换、退出及重开沿当前约定路径与 caller 配套；存在 Busy 时不丢责任。具体输入三链和旧关系归还分别用 06/01、06/04，不能只改外观或粗放扩框抢其他目标。

<a id="03-08"></a>
## 03/08 动作简化

按真实用户完整路径核新增动作是否完成其需要的事情，删除无意义步骤、来回切页、重复确认和冗余按钮/能力；滚动可达不消除来回找上下文的代价，须合计草稿、确认、撤销与重校验等实际负担，保必要后果、复杂控制与可达性。少按钮不等于少必要能力，也不把高频操作藏深。装料/提交等合并须由原业务真实原子处理，不能连续点两个回调冒充一次事务；即时制作不能为“完整闭环”强加等待/领取。存在等待/领取时按该设施现行规则核对。

<a id="03-09"></a>
## 03/09 连续表现

落槽、取消、开关、返回及重开按当前目标保持利落、准确且可打断接续，不以“有 Tween”证明手感。复看方法用 04/07，静图、源码和终态不认证连续体验；性能修复保等效交互/动效，不冻结画面冒通过。

<a id="03-10"></a>
## 03/10 无效存取

核隐藏/未使用页面和无变化状态是否仍持续业务读写、全表查询、重装监听、整页重刷；修真实生产调用源，不把 Update 轮询搬到另一个常驻回调。实际动画、真实事件或必要状态变化可沿其机制更新，不为减负禁掉所有按帧动画或新造全局事件总线。具体预算、分配和允许读存事件用 02/02、02/03。

<a id="03-11"></a>
## 03/11 完整可用性

先消费[共同方法边界](../review-methods.md#scope)。

**触发与假设：** 当前交付包含页面、窗口或成套控件时，质疑“控件可达、单卡清楚是否掩盖整页任务错位、无效排布与操作负担”，同时保必要内容与可达性。

**最短操作：**
1. 先从人的目标确定必须知道什么、亲自决定什么、人和系统各承担什么，再定必要内容与入口→操作→反馈/返回；不把现有人工配置、控件或治理模型预填成任务。按已采用的AI主导／专家控制等分工和[页面](#03-01)、[文字](#03-02)、[视觉](#03-03)、[动作](#03-08)取舍，打开整页核主要阅读/预览、主动作与辅助管理信息的空间、频率及恢复代价。
   按功能块复用或由工作AI补齐最小行为说明：实际交互范围、有效阶段、动作/反馈、禁用行为，以及
   效果服务的状态、覆盖边界与结束方式。陪审核对合理性；不要求用户逐像素定义，装饰无动作合法。
2. 在已支持尺寸中选择边界和代表尺寸，使用最长真实文案及本任务相关的代表状态，例如空/加载/
   错误/禁用/选中；沿实际路径到达并观察整页。确认无缺项、溢出、硬截断、重叠、不可达按钮或
   状态/反馈歧义；按需用[中间态保护](11-methods.md#intermediate-content)与[遮挡三链](06-lifecycle.md#occlusion-input)查动态问题。
3. 按实际需求分别取已知定位、未知候选浏览比较、批量处理或添加找回的证据；已知编号命中不签未知选择。把代表内容放回同一视口、相邻区域、滚动边界和导航，核可同时辨识/比较的信息、长名称、主次及往返成本；单卡清楚、缩小、折叠或可滚达不代整页。必要大图、滚动与留白保合法，未支持的状态/尺寸不强造必测。

**失败信号：** 必要信息/动作缺失、路径中断、长文案遮住主要按钮，实际命中或效果范围无法解释、
透明拦截区/点击空洞违背预期、动效覆盖邻项，或单卡清晰但整页重点失序、
反馈不明导致任务难以完成；即使全部可达，泛化/失焦信息、含混分叉动作或辅助治理流程挤占核心任务并增加不必要的查找/往返，也按[早期P0](../review-standard.md#quality-blocking)当轮指出打回。返工须指具体页面、状态、用户任务与负担/可见性关系，不凭滚条、控件数量或文风偏好造故障。

**校准与合法反例：** 坏例是短标题单卡正常，而已支持窄尺寸的真实长标题遮住确认入口；合法对照
为真实内容体量或专业任务所需、必要信息／主动作清楚且上下文连续的省略、滚动、折叠及留白；合同允许或信息可取不等于排布合理，不强塞首屏或一步完成。不扩为全产品、全语言、未要求功能或
每像素规格。按本任务确定的参照、精度和质量目标裁定；未要求逐像素一致时，不仅凭与任意参照的
像素差异否决。用户已接受近似时，按[近似与交接](10-delivery.md#bounded-approximation)核对范围及保留要求。

**复验解除：** 当前版本重走受影响的完整路径，重看原尺寸/长文案/状态组合及相邻代表状态，确认
必要内容与动作恢复可达、清晰，并从真实任务核无用途内容/步骤已去除、核心与辅助主次及上下文连续性成立；只测修复控件、折叠或滚达仍保留整页结论缺口。

<a id="03-12"></a>
## 03/12 真实整改范围

核用户点名的全部页面、家具/建筑及共因，不能只改一张截图就称全量落实。用户明确多轮真实优化/质变时继承其要求，不能以报告、分析或同字节送验凑轮数；本 Skill 不对所有 UI 强设三轮或删项数量。核心选批用 01/01，连续低收益用 08/10。

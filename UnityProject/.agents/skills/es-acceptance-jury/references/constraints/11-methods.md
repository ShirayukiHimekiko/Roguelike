<a id="early-value-check"></a>
## 11/07 早期价值与可用性

**方向与价值：** 多方向差异、替换方向或新增入口可能引发大量返工时，在扩大制作前用已有代表稿核目标差异；区分可读性失败、指定风格、偏好与假设。普通默认用法新增声明、注册、配置或抽象时，对照现有真实路径：新增前置换来哪项本次必要保证，信息由谁提供，少做什么、多学和维护什么；必要信息不证明当前暴露形式唯一或值得作为普通默认。比较当前任务的理解、操作、切换与反馈总成本，不以两行示例、少参数或把成本移到集成层证明减负；保必要数据、协议和恢复保护；复杂操作须据[价值依据](../review-standard.md#decision-order)核真实必要保证、等效接法与总成本，不能由新增形式自证必要。已有依据足够即可决定，不强求固定候选数、人测人数或用户再次批准。

**真实使用：** 易用、减负、复用、本地化或可继续生产是有效目标，或为普通任务推荐新增前置时，按实际任务区分普通调用者、数据／协议作者、宿主集成人和维护者，同人兼任合计学习、配置、调用、恢复与维护成本；委托者反复解释、催办和纠偏的成本也按真实记录核，不能只验最短调用或把必要用户决定算失败。用首个可用样件走本次相关路径：找到 → 理解 → 使用 → 修改／替换 → 保存／帮助，核首次配置、重复操作、错误恢复和维护中真实存在的成本。查跨界面、目录、资源、说明及实际采用的断点；资源绑定与保存重开复用[身份与编辑链](../reference-fidelity.md)。按角色、任务和阶段选择步骤；纯方案查必要性和可实施依据，不冒使用效果已测；无这些目标或新前置的局部算法修补不扩全产品人测，稳定标识或第三方原文不因外语自动失败。

**失败与复验：** 指明未成立的是哪项推荐或使用目标、必要收益／总成本缺什么依据，给原owner／caller及下一条能决定取舍的证据；按[共同裁定](../review-standard.md#decision-order)分别处理技术可行、推荐适用和已交付效果，只约束依赖未证判断的推荐／采用。先修共同原因，再复走原失败路径及合法对照；样件不代最终覆盖，示例或方案不证明真人学习效率、满意度或长期稳定性。

<a id="result-difference"></a>
## 11/05 结果差分

**触发与假设：** 有输入、状态切换或隔离承诺时，质疑“测试绿是否只是初始值和预期相同”。

**最短操作：**
1. 从真实界面/数据读回初始状态，选择一个能产生不同结果的合法输入。例如已选 B，悬停 A、
   点击 C、再移出；目标只有一个条目时选择确实可区分的开/关或确认前/后状态，不捏造业务项。
2. 观察实际权威状态和独立可见反馈；输入发出、方法返回或作者写入的“成功”日志不够。
   程序化事件和真实 OS 输入分别记录，不互相代替。刷新检查用不同的新数据验证确实发生变化。
3. 只改变一个条件，做应拒绝的反向对照：模态打开时点击底层另一项、禁用后相同位置点击，
   或输入无效数据。禁用后核对实际射线命中/输入路由，不能只直调回调。核对拒绝发生在正确对象；
   预期消费次数按项目合同，不统一规定所有输入只发一次。

**失败信号：** 合法操作未改变目标、错误路径也改变权威状态、显示内容与状态不一致，或用
本来就相同的值签收。测试中的 observer 若直接返回 expected，或与执行端共用伪造结果，检查无效。

**校准：** 坏例“初始0→点击0→断言0”不能证明选择生效；改为初始0→点击1并观察实际选择，
让失效处理器暴露。合法对照：hover 可以改变预览而不提交选择，不能把所有视觉变化判成越权；
拒绝状态不改变选择本来就是正确结果。坏例可在隔离测试中停用处理器，不能私改生产对象来造失败。

**能力不足：** 优先利用已有状态查询、事件记录和目标截图；拿不到独立结果就明确缺这一项，
不要用“按钮已点击”作为替代。ES 桌面输入可按任务使用 ScenarioPlaybook，原生测试沿原测试入口。

**复验解除：** 修复后重做原失败输入和对应合法/拒绝对照，独立状态与可见反馈均满足原合同才关闭。

<a id="intermediate-content"></a>
## 11/06 中间态保护

**触发与假设：** 动效或 Shader 会覆盖、裁切、缩放、移动、变暗信息区域时，质疑“终态正常
是否掩盖了过程中的信息损坏”。

**最短操作：**
1. 选真实代表内容：最长标题、密集属性、当前选中项、滚动边缘，保存正常基线；无需把无关
   页和全部语言强行纳入。确认哪些阶段必须可读、何时允许输入，依据用户目标与项目规则。
2. 采集完整进入/交互过程，在遮幅最强、透明度最低、变形最大等实际风险时刻检查原尺寸画面，
   加上中断和终态。采样按最短相关变化选密度，源视频密采/必要帧放大只支持实际覆盖的结论。
3. 将真实文字/图标与遮罩、覆盖层的关系对照；几何边框相交只提供线索，实际字形与对比度
   仍要看渲染。检查整页同时黑下去是否违反明确目标，不把所有渐变统一判坏。

**失败信号：** 本应可读时关键字被硬截断、遮层盖住相邻项、允许输入却看不清目标、hover改变
信息内容可读范围。截了起终两张图仍不能关闭这个问题。

**校准：** 坏例是卡片侧遮幅从14%扩至25%切断真实标题；合法对照是装饰图的有意裁切，以及
合同允许、输入尚未开放的短暂转场。慢放/手动推进能检查路径，不证明真实速度手感。

**复验解除：** 当前版本以相同真实内容重看原风险时刻、相邻阶段与终态，确认必要信息和输入窗口匹配。

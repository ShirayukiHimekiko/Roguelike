# 进度／功能 P0 权威正文

本文件仅定义进度／功能角色的P0主责候选与完整方法，由SKILL.md及该角色派发直接读取。另一角色按自己的权威正文检查；不把双方合成同一检查任务。

<a id="review-contract"></a>
## 本角色 P0 执行合同

本角色判断必要业务结果是否正确：操作与流程、规则经济与归属、单位世界业务状态、保存恢复后继、关键业务反馈。按实际输入/规则来源→生产赋值与权威提交→状态/反馈→下一操作查询比对；单位及其交互关系的位置合法性与行为正确性归F-P0-03，正常结论也须有据。

以下五类结果按共同合同搜索、匹配并实查。可见位置、遮挡、接地或面向先实际分析并作线索，再追权威来源；不能据静图签权威坐标、碰撞、移动/攻击或保存通过。缺动态观察不跳过已有源码或截图。权威状态正确而视觉空间/连续表现失败转交架构角色；架构通过不能代业务裁定。

证据范围、动作限制与独立关闭沿[共同调查边界](p0-review.md#review-contract)。

## 完整检查方法

<a id="method-f-p0-01"></a>
### F-P0-01｜必要操作与流程

先按[游戏流程贯穿区](game-workspaces.md#flow)核玩家到达当前局面的真实条件、阶段和全部应有对象状态，再追当前Scene/Prefab、输入/启动/Continue入口及真实caller。选合同允许的进入、操作、切换或恢复，对照资格→目标→提交/正确拒绝→场景/状态转换→反馈与下一动作；只展开实际存在的暂停/取消/重入，不能用操作路径或加载成功代游戏局面正确。

真实绑定下必经分支无条件吞合法操作或无退出后继，可静态确证；事件投递/装配未知才执行最小入口至后继，核权威状态。正常对照含同入口合法成功、正确拒绝及等待恢复后下一动作可达，Editor限定不增Player。

修责任入口/分支/续办，不靠恒拒、永久Busy、删入口或新增绕行求绿；复验原坏触发、正确拒绝与后继，核是否把死路搬到下一状态及旧正常操作损失。静态只关源码命题，原真实过程失败需对应观察。入口、依赖、条件和声明范围仍适用且无新反证就复用，不因批名重跑全启动。

命中可玩/视觉对象时，完整执行[实际视觉验收](review-standard.md#visual-review)，流程可达不代品质通过。

<a id="method-f-p0-02"></a>
### F-P0-02｜规则、经济与业务归属

先取有效规则/费用奖励/取得归还合同，追当前定义与工厂生产值、真实caller、权威数值及扣奖owner。选本次合法支付、领取、伤害、生产或存取；原机制有重试/重入/分段提交才追实际操作/实例身份及失败前缀。

复算合法输入预期，沿条件→真实写入/提交点→副作用→matching receipt→反馈/后一次合法操作对照。核实生产前提后的错公式、资格分支、扣奖顺序可静态确证；提交未知才查最小真实权威账与回执，不凭UI猜经济首因或伪唯一stub。

正常对照为合法成功、余额/资格不足的正确拒绝；同操作副作用按合同一次，重试可返回原receipt或正确拒绝，新操作仍成功。多owner、一次输入的合法多效果保原合同，无可重入入口不强加token。

修真实权威/提交/身份责任源，不恒拒、免费取得、删奖励、错退款或吞新操作；Busy/false不抹已取得/已提交前缀，清理/续办按原责任。原错账/归属与正常交易复验，核保护/反馈和成本转移；隔离污染另保A命题。规则、生产路径、消费者和观察前提未变可复用，新反证重开对应链。

<a id="method-f-p0-03"></a>
### F-P0-03｜单位与世界业务状态

本批审查包含单位、世界状态或可玩场景时，从当前推进阶段与有效规则对照全部应有和实际单位、建筑、世界对象及UI业务状态，核此时此刻的位置、状态和关系；不能只挑代表单位。**每个对象按“从哪里来（生成/归属/身份）→ 在干什么（状态/目标/关系）→ 到哪里去（下一转换/退出/回收）”三问逐一作答**，缺任何一问该对象即未查完；三问齐备只说明骨架完整，不代证据。档位与用法见[单位三问](recognition.md#unit-state)。未见症状、未改代码或作者未声明正常，不能免查适用底线。同机制群体可共用源码依据，实例站位、状态或交互条件不同则分别查；本场景全部当前对象不等于全库单位/全池扫描。UI显示品质归A，关键业务反馈仍沿F-P0-06，不重复记同一后果。

实际读取Prefab/工厂→实例、SO/定义、生命/位置/行为的生产赋值及真实写读者。位置查询核生成点、所属区域/路、坐标域/父变换、高度、占用/碰撞与合法边界；行为查询核当前状态、目标选择、朝向与移动/攻击关系、触发/暂停/退出及下一转换，按当前规则核玩家—敌方—目标的距离、阻挡和可达关系。仅查类名、资源在盘、单位数量或同伴结论不足；反常组合先查它在本场景是否合法，不凭其它游戏惯例判错。

将有效规则/参照的预期与同对象版本的查询结果对应。静图可裁定本图可见站位及空间关系，不能签权威坐标、碰撞、真实移动或攻击行为通过；当前可用规则/源码/过程证据应实际查，不能只写“单帧未知”而跳过已有材料。缺口具体到对象和位置/行为问题，跨版源码只解释机制，不证明历史图的实际业务状态。

选本次合法生成、移动、战斗、放置、取用/移除或组合，核触发前状态→正确实例/生命与空间→实际转换/重置/提交→权威后状态→下一交互。池/迟到/共享真实命中才展开两实例、新生命、回收再用。绑定/父空间已核的错赋值、旧生命回写新生命或占用矛盾可静态确证；空间/碰撞/行为未知按具体问题取最小同对象过程，视觉现象不能自证权威位置错。

在本角色既有意见中明确各适用对象/关系的位置与行为分别通过、返工、证据不足或未运行，附实际规则来源、查询位置/观察时刻及决定性比对；正常结果也给依据，未查项保具名缺口。位置通过不代行为通过，对象单独正常不代同场交互关系成立。可用自然句或共用一张简表，不新增固定转发格式或逐实例报告。不以“单位正常”“未发现P0”、另一方的视觉裁定或已发现UI问题替代本项结论。

正常对照为正确实例正常转换、非法放置正确拒绝、按设计允许传送/切换和共享定义；合法第二实例/生命不被吞。修状态责任源，不冻结单位、关碰撞、删建筑/密度求绿，保原移动/交互/取得归还及视觉同步。复验原错状态与合法转换/后继，所需视觉/空间或隔离独立后果转A各自闭，单一状态错误不再凑A一项。生产、坐标/生命周期、绑定及证据条件仍真且无反证才复用。

<a id="method-f-p0-04"></a>
### F-P0-04｜保存、恢复与后继

以当前保存/继续底线为据，从本局应有持久参与者/必要状态反查实际capture和import登记及入口调用，未登记的应有对象也查；追真实触发和参与者capture→codec→持久介质→Continue/import→消费者，核必要字段、引用身份、提交时点、已完成记录与未完成尾。选字段/默认值/版本/顺序变化、继续症状或原未闭的合法保存触发。

必须持久状态没有其它合法来源却漏capture/import，或可达旧快照必覆盖新状态的静态链可确证；字段同名/文件存在/hash/离线roundtrip不能签实际继续。持久、退出加载未知或任务要求真实过程时，对同候选存出→退出重开/Continue→权威状态→下一操作补观察。

正常对照含必要状态正确恢复、已提交不重放、未完成按合同续办及已要求旧格式；不新增单Store/自动存档/未要求迁移。修真实保存责任源，不清档、抹pending、降内容或重开新局假恢复，保玩家数据/引用及合法后继。原静态命题与实际过程分开关闭，核旧好状态与受影响数据，已修未复验保原失败未闭。参与者/codec/顺序/介质与观察条件未变可复用，相关默认值/schema变化才定向补。

<a id="method-f-p0-06"></a>
### F-P0-06｜关键业务反馈真实性

先固定关键反馈的有效业务语义，追同一对象/操作/时点的权威值或真实提交→匹配回执→数据生产→实际presenter/绑定→HUD/提示/音画语义。选反馈计算、成功返回、绑定变化或显示/权威矛盾；ACK是收件、排队或提交取真实合同。

已核绑定下错计算、错对象显示或没有必要提交却报成功的链可静态确证；渲染/时点未知才对应同对象权威与实际画面补证。权威100/HUD1000即使合法50购买成功及余额不足正确拒绝仍是本项P0，不能要求后继另坏；布局遮挡归A03，权威位置错归F03，权威正确视觉跳变归A04。

正常对照为权威/显示均100、买50后均50、未完如实pending且按合同续办及正确拒绝；合法原receipt可重返。非决策统计／格式若违反必要品质亦按超级P0；有据正常或未采用偏好另论，不混关键语义。

修反馈数据/绑定责任源，不能删数值、吞提示或静音必要反馈求绿；复验原误导和正常提示，核是否新造遮挡/跳变等A损失。后台正确不清HUD原失败，原后继另失败由F01/F04及共用续办处理，不代A关闭。数据生产、绑定/时点及观察条件未变且无反证可复用，纯外观变化不全跑经济。

命中可玩/视觉反馈时，完整执行[实际视觉验收](review-standard.md#visual-review)；正确计数不抵卡名被挡，动作标签不冒保存成功，未知身份/合法瞬态不凭像素重叠泛报P0。

# 结束核回：一次结果交接与真实停止决定

<a id="completion-coverage"></a>
## 原目标完整覆盖，各自实查，不重复全scope誓言

作者拟交付／结束前先落实[必要下一动作](must-read-work-priority.md#partial-result-continuation)，在原活记录一次交当前对象／实际产物、已兑现结果、已做检查和必要未闭／在途、主要继续路径及为何能结束。当前scope取有效原需，不由作者方便测的子题定义；历史阶段不冒当前，未做的核心结果不能靠scope外移。

对话AI沿完整有效原目标整合证据和未接责任，保所有必要结果的去向；不默认再做F/A整套技术取证。F以实际消费者路径核结果，A以决定性前提／供给／代价核必要反证，各自说明本人实查支持、未查及影响。两份局部open0不等整体完成；必要结果没人接、缺能力或未观察时仍未完，须取得专业供给／实际消费者，不能用披露免责。完整产品委托不得降成方法/方案；真实只委托方法则核当前能检验的实际使用，不冒产品事故已修。

既有有效证据引用一次，变化只补受影响部分。原分事件、两项本人依据和完整必要意见按[消息合同](coordination.md#message-delivery)保真，意见不复抄全部历史目标／scope／完成镜像。原失败／否决／暂停和专业品质要求保持，原职责或合法后继据证关闭。

<a id="stage-continuation"></a>
## 阶段交回核实际作者后继

规划认可转开工、巡查/学习/只读批交回及其它[推进边界](must-read-work-priority.md#partial-result-continuation)，分别核报告可交、作者后继已接与产品达标。按该判据从完整目标主动核继续路径，不只查已有候选；统筹把合法必要或有据有值工作真实送达原owner，保各窗自定下一成果，并核实收及第一作者动作。动作须改变或取得作者源、内容、逻辑、候选采用、适配供给、有效判别或消费者；next-actions、无新结果的重复只读复查、ACK/queue、读卡和新增记录不代后继。

F核完整必要差距到原owner实收、作者动作与后继；A核限制来源／作用范围、唯一writer及可取得的专业方法／原创供给，查无现成合同是否误当不可工作、局部只读／准停是否变父停。遗漏路径或合法就绪工作悬空，两责只可认可已核局部结果，不得准父停；交原统筹落实并核差额，不替作者指定工艺、不增逐补丁审批或第三审。

阶段预算到限而完整目标未成时，F/A须与作者据当前同版原需/结果/旧账及方法前提，真实核并采用“已有授权有据可用额内足够有限重分配”或“完整方案/专业来源供给重评置顶”；真用户总额/费用不足则核具体里程碑续额请求已实交有权者，不能代批或以actual未知假余量。阶段/预留/AI复核窗不是用户总额，拒无证退款不构成唯一出口；不凭新额复活已败旧方法。核决定是否进入原owner第一实际作者动作或真实受阻接回，不能只签提醒/预算表后准停；正常自主小步不逐工具会签。

原owner正在安全作业、已有未消费输入或原操作终态未知时，接回原ID/现有后继并去重，不堆发、抢writer或重放；未观察接取/首动作如实保未证，只有真实在途才记在途，不以无信息轮询造进度。当前真限额/审批/权限只限制对应依赖；原临时批结束、新输入或用户修订改变条件就重核受影响处置，独立就绪工作继续。确无当前可做项才接[停止申请](#stop-request)；用户明确暂停/撤销立即执行，硬中断保未闭不补签。实际无通信/执行能力则交清具名接回，不能自称已推进或以此签生产完成。

<a id="stop-request"></a>
## 阶段答复与真实停止分别核

状态、用户要求先给的方案、能力边界或阶段结论，按当前已证／未审范围及时答复，本身不另起停止申请。判断看实际受托结果与动作，不看消息通道；不能因答复搁置已授权且就绪必要工作，也不能把答复冒整体采用／完成／发布。没有实际执行或唤醒能力，不声称仍在后台推进。

拟实际停止必要制作核验或结束本范围受托推进时，在同一交接内按[统一接续判据](must-read-work-priority.md#partial-result-continuation)实查全部有效目标的继续路径，再交证据／未闭、已做／不能做、替代结果、真实资源／权限、在途终态与恢复并申请。能做的必要动作先做，缺方法主动补供给并求推进建议，不先停让陪审找漏项。已有充分材料只补申请语义，不另建STOP报告／仪式轮。

适用F/A各自据分工实际证据和必要未闭，明确允许／不允许该对象／版本／范围停止；准备票、ACK、completed、一方许可、内容通过或机械passed不代另一职责。对话AI核合并是否覆盖受托结果和全部必要否决，未接专业能力不被父scope／空open抹去，不要求双方各自重做全部专业审查。

意见可有合法子scope，只允许该对象／版本／范围结束；父任务停止须另有覆盖完整继续路径的实际依据，不从局部票合成。合取看真实对象／条件／结果，旧包技术与新包可用性意见不合成整体通过。worker/root不进F/A quorum；工具accepted仅渲声明，不认证语义／许可。未答的依赖限制及原分保留。

同版结果审查可给具体采用／发布条件及终态后的准停。仅必要品质／消费者已足、原否决已闭且只待具名外部终态／身份时，核真实回件及差量后接既有同范围条件许可；未返回不预填通过，新实物或反证只交受影响职责，不固定双开票。采用／发布仍守实际权限，争点按[实质质证](closeout-debate.md#workflow)核证，不为结尾凑辩论。

无许可擅自停止受托推进仍当轮P0阻断、打回，修源及独立就绪工作继续。用户明确暂停／撤销／等待立即执行不等票；硬中断保现场下次接未闭，不补签过去许可。自设预算／轮数只能使一种方法停改，不授权结束原委托。

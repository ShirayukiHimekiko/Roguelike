# 证据与运行派生物生命周期

本页按真实生成、隔离、恢复或退出动作读取对应段；不附带到每次检查起步。验证选择先沿[相关性与必检](verification-scope.md#relevance)。

<a id="environment"></a>
## 生成与隔离前的环境复用

优先复用适用且安全的证据、工具、构建、源镜像与隔离环境，核版本／依赖、状态污染、当前占用和验收条件。生成／安装／多根跨卷正式采用前，按真实写法核每个将写卷的当前余量、最大单件临时写／净增及已知在途写，核恢复位置能承接，再写首根；不设统一GB门。容量未知／不足先交具名维护或只限对应依赖，真正独立工作继续。中途变化保各根before／candidate／未知第三态及已写清单，逐路径接续、manifest最后，不重放已成功根。确需冷启／新装、并发隔离、不兼容、数据保护、破坏性验证或回滚时，只带必要源／依赖建最小环境；不共用可写状态，不reset唯一失败现场、草稿或他方在途。

<a id="retirement"></a>
## 生成物、失败现场与退役

生成端在原任务记录接回来源／重建入口、消费者、责任端与结束处置。完成、失败、取消、超时、进程归还、替代或交接时复核磁盘产物，分清在用状态、须回查的唯一证据与可重建派生物；进程退出不等于文件回收。只在已有清理授权内处置无保留责任的派生物；归属、权限、来源或保留责任不清时留具体路径和原因，不删除或盲增副本。保源、必要输入／锁／结果、失败／撤回意见及不可重建原件；真实离线恢复／原环境重放承诺不能被“可重建”抹掉。处置失败只阻断依赖它的后继，不扩大清理。

<a id="recovery"></a>
## 恢复时的当前决定与原件

恢复从治理入口实际读[活记录](project-workspace.md#workspace)，先核当前对象／路线是否仍有承担下一工序的资格，再接动作；旧有限票不覆盖后到撤回，技术事实保留不恢复被撤资格。原任务入口接当前版本／条件、有效决定／撤回理由、未闭、原件定位及环境可用／退役／未知；第一动作按[当前依据](task-plan.md#consume)核，独立就绪工作继续。退役路径／hash不冒可读原件，重建不冒原时点；复用有效证据、只补变化及具名缺项，不全历史重跑或另造平台／环境配额。

<a id="idle-cache"></a>
## 运行缓存只在陪审真实空闲时维护

无当前待处理的具名必要调查、需本人答复的主线请求或可执行接回动作，且不争共享输入／writer，才是维护机会；completed不等后台监听，不以固定轮询／守护服务保持忙碌。陪审可闲时核有明确归属的缓存来源、是否在用、完整性影响与可恢复处理；必要主线到来先接主线，不让缓存分析／移存拖住制作或必要审查。

只在当前授权和写域内处理已知、非在用的可恢复生成物，保原路径／原件／hash和恢复位置；不动正式payload、私有或未知extra、他方在途状态，不抢唯一正式writer，不把缓存当源码篡改，也不放宽指纹／未知额外物保护。实际移存／清理按生成物归属和当前授权交接给可写责任端，陪审职责不自行扩为第二产品writer。

缓存维护不作无关主线前置。若容量／资源障碍实际持续阻断必要构建、运行、安装或发行，转主线具名维护：只读核归属／占用→权限内处置或具体所缺范围→容量／峰值核回→原消费者恢复；正确拒绝／保护不等维护完成，不以闲时无限后置或反复打包等待。一次峰值拒绝可按实际状态合理等待／复核，不一律全盘清理。没有新信息保具体接回信号；-B等既有保护可继续，不为维护改全局环境，原源／失败及未知extras保护不变。

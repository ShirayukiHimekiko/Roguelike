# 视听观察与受影响内容复查

只查本批视听目标及变更可能影响的已通过内容。[验证选择与复用](verification-scope.md#relevance)不新增交付门槛，必要验收也不因安排在空档而成为可选；无相关目标不新增音效、动效或媒体。

<a id="audiovisual"></a>
## 视听观察

把待验问题落到实际对象、触发/状态、预期画面或声音，以及当前原件/事件入口。按以下查法执行：

- **画面：** 按[视觉验收](review-standard.md#visual-review)亲看本次完整提交画面，再定位具体字形/对象区域，分析裁切、遮挡、层级和比例是否违反目标，沿布局/素材绑定追原因。动态有可播片段时按[连续动效](constraints/04-visual.md#continuous-motion)正常速度看完整链和循环接缝；只有截图或关键帧仍分析其可见问题及驱动源码，不冒连续观感已验。
- **声音：** 从实际事件追播放/停止入口及绑定素材，查同一触发的调用是否超出约定、约定停止时是否有可达停播分支。可分析音频时比较波形断点和循环首尾差异，作为突断/接缝风险线索；可听时听同触发的实际输出，检查关键反馈是否被其他声音掩盖及目标要求的风格/强弱。只听源素材只签素材结论，波形、响度或播放日志不代实际听感。
- **音画同步：** 在有共同时间依据的同一记录中定位触发、关键画面、声音起点和停止/恢复，比较实际先后及间隔与目标。缺该记录时，先沿源码追各自时钟、调度和触发条件，给可证关系及剩余未知；独立素材、截图或未核共同时间来源的字段不证明实际同步。

结论绑定实际文件/版本、图中位置或片段时刻及观察方式，给具体问题和目标影响。抓帧/录屏按[采集与分析](capture-motion.md#scope)选真实时标与观察；缺素材、参照或播放/听取能力，先分析[已有源码、素材和截图](review-methods.md#available-evidence)，剩余未知走[证据恢复](evidence-recovery.md)，必要能力缺失时主动给安装/接入方案；不默认要求人工试听。未听、仅静帧或旧版观察不冒当前听感/连续表现通过。

复验重看原失败触发及相邻阶段，并查合法正常对照；目标允许的停顿、静音或跳切按有效设计判断。技术纠正、实际观感和真实玩家反应分别只按对应证据报告。

<a id="regression"></a>
## 已通过内容的破坏风险

本次提交的完整画面/状态仍按[视觉验收](review-standard.md#visual-review)全目标亲看；下列依赖追查只限定源码因果、补采和未提交对象的回归范围，不能缩小本图观察区域。

1. 从改动的写者、配置或资源追实际读者和实例绑定，再对照原通过目标及成立前提。例：共享材质修改后，沿实际引用找到受影响画面；文件未改不等于未受影响。
2. 用当前版复验原合法触发和正常对照，观察条件改变时说明差异；动态只补对应必要过程。没有当前产物仍分析源码/资产中的可达回归和旧版遗漏，但不签新版表现未破坏。
3. 已证破坏重新打开受影响目标，保原版裁定/证据并交责任源修复；推断风险或未观察具体标明，不冒已发生故障。
4. 未提交且确无相关影响的对象，按[证据沿用](review-standard.md#goal-coverage)核原条件仍适用后复用；同因扩查不扩大为每轮全游戏/全平台运行。

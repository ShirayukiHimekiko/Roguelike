# 对话AI：本人理解、决定与统筹

本节适用于实际进入本Skill的制作／陪审协作；此时完整核心、后台作者、独立F/A和唯一writer按原合同执行。普通任务只取[默认起建与持续补充](#model-autonomy)，不因此启用本节全流程。

统筹是用户的唯一入口，守住完整有效的原需、当前理解和主线；用户原话和原件说了算。本人负责澄清任务、理解需求、决定采用或纠偏、向用户解释并核对结果；制作由真实的后台作者完成，F/A（以及启用时的 🟪T）独立裁定，并各自核回自己的否决。亲读完整 SKILL，按当前要做的决定读对应阶段的正文，派发和接续读[窗口合同](window-interaction.md)。不代写制作计划、候选、产品源码或测试；但“不代制作”不等于可以不做本人判断。

**统筹不制作、不找参照、不批准目标变更。** 参照由作者找，美术方向由作者提、🟪T 判；参照集合、特征清单或范围要变，统筹把“原来是什么、想改成什么、为什么”发给用户，用户确认前照原目标做——任何 AI（包括统筹本人）都不能批准目标变更。统筹只传文件路径，不转发大段内容；监督方合计投入不超过作者。视觉任务的分工见 [role-split](target-art-review.md#role-split)。

**先理解期望变化，再委托。** 在选首个业务任务及关键路线、采用或完成决定前，从有效原话和当前原件弄清用户为什么要做、使用者要得到什么、相对现状哪些关系应改变到什么程度及哪些必须保持；据可观察结果解释本次改动为何足以兑现，既核超出预期的改动，也核只划边界却没改变必要结果。边界是其中一项，不能代替理解；分析委托、已经符合要求或有据应保持时，合法不改须对回原需，不为凑改动扩大任务。把事实、用户硬项、AI解释／旧方案和临时比较控制分清，不因旧方案已采用就冻结本次获准变化。首次AI理解也按[独立质疑](coordination.md#independent-input)保候选，必要未知先交能改变选择的原件定位／判别，不先沿旧题派制作再补需求。实际brief和第一作者动作须兑现上述期望变化／保持及成功信号，忠实传达指定工具、工序和格式；未定工艺由作者独立选择。发送前对照将实际执行的输入，核它是否把应改关系误锁住或把未授权关系放开。原需明确、同条件已核依据和成熟小修复用推进，不逐参数索批、索隐藏思维链或重做全规划。

**本人核真实结果，再作采用决定。** 先亲读实际产物及决定性输入／源／配置／输出，沿入口解释作者操作怎样产生目标结果。核关键假设、默认与损失，不逐行扫无影响内容；未看部分保范围，摘要／diff／身份和同意不代理解。再看实际证据支持什么对象、版本、条件与结果；技术成功、可用任务包、专业品质及完整交付分别采用，不能将两个局部意见合成整案通过。缺专业判断／观察能力就取得对应供给，不以角色数填平；可靠共用事实复用。

**用反证选择下一实际动作。** 分清已败、缺测与未运行，核前段变化、旧假设和后到真实终态；旧计划不能复活已做工作。按[下一投入](must-read-work-priority.md#continue-or-change)先选能改变完整主要差距的作者结果，再接修源、能力／供给判别或组合首件，核首次实发是否改了原失配及真实消费者。审美解释、技术手段和用户硬项分别有据，不把DCC／厚度／特定轮廓当普遍门槛；撤错误门槛仍保实际不合格。完整未接维度排真实后继，不永久藏在父未闭。状态／方案答复及时给，成熟就绪工作继续；不因答复增准停轮，不假称后台持续。

**本人建模，主动质证三者。** 按[默认起建与持续补充](#model-autonomy)主动维护当前模型，依[元素方法](recognition.md#unit-state)核具体依据与支持范围，沿[原活理解](project-workspace.md#workspace)共享当版原件和未闭。可信反证推翻模型时明确撤回／保留范围，分清模型误认与真实产品违约；不能改称装饰或改规则降低原需。沿关键决定、自然成果、阶段变化、反证或等待失衡，从公开动作／实物、差异和完整意见亲查工作AI/F/A的目标、供给／方法、前置、证据／许可和真实推进，找漏需、低收益续修、过度流程、漏供给及新增等待。三者一致、自信／配合或身份不代事实，本人也接受有据反证；running／mtime不证进度品质，只索必要公开职责原件，不索无界日志。

**主动找有值机会。** 从完整目标、必要差距和当前实物发现能改善品质、控制、效率、复用或体验的路线／工具／素材／工艺／组织，给具体作用、预期差异、反证及剩余代价、耦合／供给／权限依据。关键未知真实交具名查证，足证接作者动作；查源取[主动增效方法](evidence-recovery.md#joint-source-search)，新增结果／职责／验法沿[三方主线](source-authority.md#current-mainline)。成熟充分或无目标相关机会直接推进，对实际已提但不值得的建议有据不采；不凑数量或反复发散挤占制作，推荐不扩权。

**按实际能力分工，持完整目标。** 在原计划把当前必要结果对应到作者制作、F真实消费者路径、A决定性前提／代价，先看谁能取得需要的专业证据。缺能力或无人接的必要结果仍未完，取得实际供给，不用两局部open0、阶段scope或更易检的代理任务收口。产出超过当前可审范围时优先共同前提、完整结果与关键体验，调整并行量，保原目标、未闭和真实后继。必要领域查证可分工，采用／纠偏及向用户解释仍由本人据原件承担；不能用缩验收目标、堆报告／更多陪审、全局停机、无出口等待或让用户兜底查漏消除超载。按实际材料与动作核承载，不能从单项过线推整体可审。

**实发本人决定并核结果。** 纠察／推荐分清必要履约、缺陷与可选扩展，带原需、证据、影响和需答事项真实发给worker或相应F/A，需回应的空闲者实际唤起。按[本人依据与同名实答](source-authority.md#grounded-consideration)核落实、反证、有据不采或受限依赖，接到第一作者动作及消费者；ACK／已发不作完成，不代答／代关。采用状态或准停前亲核原任务当前接点和后到终态；旧报告、空selector或旧lastResponse不证明仍受阻，冲突回源纠正当前判断并保旧记录。按[统一接续判据](must-read-work-priority.md#partial-result-continuation)限真实依赖，不逐工具催报或逐补丁会签；用户控制、严重阻断和关键成果按[消息合同](coordination.md#message-delivery)及时接回。

从原记录和实际动作按[呈现入口](message-style.md#user-facing)组织用户视图，保各源原分／事件、必要未闭及本人处置，回显仍影响决定的取舍／动作；建模、质疑、重新定位和声明以实际过程为据。主动性限当前真实宿主及可观察时段，未部署唤醒／监听／换新／卸载保后继与未验；不以角色卡或有限样本保证永久合格、全部检出或无人值守常驻。

当前意见正文从本人具名源选取，逐源消费完整messageText和两basis/必要限制，不只取passed/sources/receiptCheck元数据或折叠为总体A加评分脚注。root也给自己的当前两项事实；对影响决定的他源另在本人块responses给to目标id、目标blockSha256及source/evidence/disposition/action，真实采用/不采不得由writer代拟。生成draft后核完整可见正文，随后实际发用户并由消费者读回；draft通过不冒已发送。来源选择/当前身份/回应两端绑定与声明边界沿[唯一呈现合同](message-style.md#user-facing)，不重审双方全部技术或逐工具写新意见。

<a id="model-autonomy"></a>
## 默认起建与持续补充

这是交流AI实质任务的默认模型义务，不待用户点名、指定Skill或列元素。普通任务只取本节，不另启完整陪审、后台作者或固定大表；实际jury仍按完整核心／独立职责／唯一writer执行，权限和写域不变。

**进入即起步。** 创作、制作、接管、恢复或分析判断时，从有效目标与当前原件建立支持第一动作的应有／实有元素、关系及待核命题，当前任务／修改目标的解释也入模。本人首次AI解释／方案／判断／产物均先作不可信候选，按[独立质疑](coordination.md#independent-input)由真实独立AI核原需、原件及推翻条件后据具体命题采用；普通实质任务沿该节的单独立核验，不因此启全套陪审。已有用户授权和已证原件按已有支持范围使用，不因AI换个叙述清零。合理替代解释做最小判别，不强造错误；已有支持不能自动传给本次新推断。不要等作者列完、用户催补或全项目画像齐备。已有适用模型须实际读取并核当前条件，独立已证部分复用。

**推进中自己找并补。** 在自然成果、关键决定、条件／依赖／资源变化或新原件处，不待用户催促，回原话与当前实物核下一动作最依赖的关键命题，优先查支持薄弱／条件已变者；选能区分或推翻当前解释的合法观察并实际核证，再对照旧模型决定维持／撤留，接本段目标、brief与作者动作，不只换话重述。已有同条件充分证据可复用，不强找错误。既可新增元素／关系，也可新增、细化、拆合或撤回具体命题、条件、资源及后继；条目／集合数量也是命题，要核来源、单位和去重／过滤口径，分清样例、总量、所选／可见量与容量，固定或变化须有适用依据，不默认永久锁定或任意N。三问和六项表达不是封闭schema；不为凑数量发散，无实质变化复用有效模型，不逐工具重填全表。

**可信地补，接真实结果。** 前段持续检验覆盖所有目标内模型及既有／新增的属性、关系、数量、条件等命题，依原件、版本／条件及支持范围决定采用，不限新增项或数量变化；设定／推断依明示前提论证，与已证、未知分清；未证不冒成立／实现，不能等报错才查。视觉命题须亲看对应对象／版本、视角及必要状态／过程；图上可见、语义身份和运行推断分证，静图不签未看动态或隐藏全集。有效旧证可复用，不强找错误、逐工具重填或后台常转。实际反证时，同一模型保原命题、反证及撤回／保留范围，沿因果追责任源，交具名责任端并核第一动作与结果；不只改数字／置信标签，不抹独立事实。模型维护不逐项索批，也不增加产品功能／权限；真实新增交付或范围沿原主线采用。细法按需取[元素调查与查缺](recognition.md#unit-state)。

后到纠正先核原话、所指对象／版本；有图示标注时亲看对应当版图，核修改／保护／参照等用意，不把框内一律当待改。关键歧义只限依赖它的误改，明义直接接当前动作。实际冲突须更新当版模型、brief与受影响动作，并回看作者是否改对目标、保住应保内容；只追加解释或ACK不算接回。在原活记录接修订／证据／未闭并实发职责，独立writer原域落实，本人核第一动作和消费者结果，不抢写或以文档代完成。普通任务可用短段，不造第二模型库；仍有已授权就绪动作就连续接。

持续义务覆盖当前宿主可观察的执行与真实恢复点；未部署的结束后监听、定时唤醒、无人值守或旧窗口热读不冒已支持，也不免当前主动维护。需用户取舍／外部授权只限对应依赖，独立工作继续；不空轮询或重建全库。

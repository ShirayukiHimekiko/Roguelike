# 设计指导｜候选入口

<a id="scope"></a>
## 适用与入口

评审视觉/交互方案，或任务要求风格契合、表现力、精致度和设计改进时读取。按[当前要求与证据范围](review-standard.md#decision-order)选本批对象。**先判[复刻/参考档位](recognition.md#replication)**：复刻的设计建议受原来源约束，参考只受取向约束；把参考当复刻会逼出无依据的逐项对应，反之会漏掉真正的还原义务。给出的设计判断还须标[视角档位](recognition.md#perspective)。结构方向沿[早期对照](constraints/11-methods.md#early-value-check)，视觉观察、连续播放和证据缺口仍由[原专项](review-standard.md#visual-review)负责；本页补诊断与修改指导，不代替制作 Skill。

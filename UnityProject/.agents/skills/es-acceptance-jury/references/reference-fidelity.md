# 参照适用性与对象身份

<a id="scope"></a>
## 共同参照边界

目标要求还原、匹配指定来源或沿用指定对象时读取。仅借鉴风格、原创设计及允许的变体，
沿真实目标核对，不机械要求逐项复制。来源缺口按[主动搜源](evidence-recovery.md#joint-source-search)处理。

先判严格度再谈还原：用户说"复刻/还原/一模一样"与"参考/像这个感觉"是两种不同义务，识别信号、允许偏离与误判见[复刻与参考档位](recognition.md#replication)。档位判错时，后面核得再细也是错方向。

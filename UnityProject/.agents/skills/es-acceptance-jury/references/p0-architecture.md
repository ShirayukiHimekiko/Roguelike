# 架构／技术生态／可玩性 P0 权威正文

本文件仅定义架构／技术生态／可玩性角色的P0主责候选与完整方法，由SKILL.md及该角色派发直接读取。另一角色按自己的权威正文检查；不把双方合成同一检查任务。

<a id="review-contract"></a>
## 本角色 P0 执行合同

本角色判断技术职责与玩家呈现是否成立：关键职责/身份隔离、必要资源与目标环境、UI空间可读可达、连续动作镜头音画、负载性能容量寿命。查询实际owner/身份生产、绑定与执行域、显示/命中/驱动时空、有效负载及取得释放，逐对象/必要关系对照当前合同。

承担架构／系统／生态审查时，普通开工／修改及依赖采用前按[项目理解与生态P0](project-understanding.md#project-fit)核当前必要权威、入口、来源、绑定和受影响旧消费者，不凭作者画像或功能绿放行。全项目基线按[追踪正文](#project-tracking)实际覆盖；初期路线判断先核改变选路／品质可达／当前安全的关系，不以无关后续模块详审作统一前提，也不以有限判断签全项目通过。进度角色仍按F类业务主责检查，不要求双方做同一套全量审查。

五类结果按共同合同搜索、匹配并实查；玩家功能沿[静态前置](must-read-work-priority.md#core-loop-progress)核合法入口至后继，Editor/外部直调成功不代玩家可达；工具/静态按自身消费者验。可见空间归A03，权威正确跳变归A04；业务坐标/选择/行为错转F。素材齐、无遮挡或计数正确不代架构/体验通过。

证据范围、动作限制与独立关闭沿[共同调查边界](p0-review.md#review-contract)。

## 全项目深查与持续追踪

首次接管、基线缺失／失效或重大结构变化时，先完整读项目AGENTS和当前主线，定位既有基线及当前必要关系；路线初判优先核关键供给与当前保护，所有实际动作依赖须在普通开工／采用前核清。全项目架构／生态认可前实际完成全覆盖：生产模块职责、状态／数据来源、公共接口、创建／写入／清理、依赖方向及Scene/Prefab/SO、资源／UI绑定、输入／渲染／保存／时序、程序集、Packages、构建和环境。未被作者列出的模块、未改文件和未接入对象也须定位其用途与真实消费者，不能因无症状或无diff跳过。

每个实际生产模块都须有源码/资产/装配与必要依赖链的调查依据；从生产赋值和入口追到真实消费者、退出/归还及受影响模块，查跨模块冲突、断供、隔离和累计成本。目录清单、关键词、ID数量、孤立接口或作者摘要不证明深查完成。第三方与生成内容按项目实际消费的接口、版本、配置和加载关系核实；项目覆盖不等于把无关缓存、日志或外部资料全部读入上下文。

技术基线及理解接点优先归入[项目活工作区](project-workspace.md#workspace)的既有记录，与审查、计划和交接原件互链；无合适记录时在获准持久写域建立，不以可再生Library保唯一依据。记录项目/证据版本、模块与对象、职责/owner、关键依赖和消费者、已查范围与决定证据、通过/返工/缺证/未运行、未闭问题及下一查验。架构角色在已交接的自身单写域自主保存、读回并通知，工作端实际消费并维护共享事实，正式产品仍唯一writer；事实、推断、未查与旧证据复用分别标明，不预填通过。

后续每次送审、接回、需求/配置或实际对象变化，依据追踪反查全项目受影响的依赖、未改消费者、旧结论及未闭问题，定向深查并更新记录。新增模块纳入基线，重大变化重开相关基线；完整且仍适用的旧证据可复用。不能只看作者diff，也不因一个新批次就机械重跑所有已闭检查。追踪随实际事件更新，不把计划、文件存在或角色在线说成持续监测已执行。

尚未覆盖的模块和必要未知具名保留，说明已查依据、缺口及下一查验；未完成全项目基线不能签整个项目架构/生态通过。已有据的局部结论可独立交付，补查及无关授权工作继续。发现F类业务缺陷须当轮转交进度角色，保独立来源和关闭权，不因全项目深查接管其裁定。具体运行和修复权限仍取当前任务；规则库按问题读取，目标项目的结构与依赖覆盖不得随之缩减。

## 完整检查方法

<a id="method-a-p0-01"></a>
### A-P0-01｜关键职责、身份隔离与污染

先按[项目理解与生态P0](project-understanding.md#project-fit)回源四类禁项及可做／禁做边界，从真实生产赋值而非作者自报核当前权威、入口与旧消费者；关键关系未查先按审查P0限依赖开工，不能等功能坏才管。再取当前有效关键职责/接口/隔离合同，定位对象版本和真实owner/caller，从实际工厂/Prefab/生产赋值区分实例、生命、操作与共享资源。**沿[单位三问](recognition.md#unit-state)分开答三件事**：从哪里来（谁生成、权威与初始身份在谁）、在干什么（当前写者与共享关系）、到哪里去（退出、清理、归还、重绑定由谁负责）；三问共用一条源码链不等于可以合并结论，来源正确不证明去向正确。选原机制可达的重入、迟到、部分取得、回收/换场景之一，无对应机制不造状态。

沿caller→身份生成/捕获→所有受影响写读/清理→验证和破坏性写入先后→副作用→归还/后继重绑定核依赖方向。已确认关键公共层禁止具体策略而实际持有，即使功能计数正确也直接违约；真实绑定/合法时序下旧生命先破坏新生命再guard、清理越权可静态确证，不等正式数据损坏。未知绑定仅补相应最小观察，不向正式资产注入故障。

正常对照保有效快照、批准多owner、明确有权共享更新、新生命正常写、原owner幂等归还、同步无跨生命路径；不凭owner/类名凑P0，不强加token/单Store。单实例F算错不换名再报A污染，同因同后果一次，独立隔离后果另签。

修真实职责/身份责任源或写入验证顺序，保取得前缀、清理权、合法续办与旧资源/输出；不恒拒、清pending、搬丢职责或新增第二权威。新静态链/原坏顺序和合法写入归还复验后关源码命题，原动态污染仍需对应观察。有效合同/生产者/消费者/时序前提不变可复用，新反证定向重开。

<a id="method-a-p0-02"></a>
### A-P0-02｜必要资源与目标环境

以本轮约定供给/目标环境为底线，先核生产／作者源、版本与导入、选择保存源及当前实际消费权威是否一致、可追，旧入口与未改消费者是否仍承接，不能混源／副本权威或写死实例绕过正式装配；从真实Scene/Prefab实例、资源加载入口或构建配置追来源/导入→GUID/meta/Variant override/SO/组件→材质Shader/程序集包API执行域→绑定/加载→实际消费者。从项目命名/目录及具体loader核文件名、路径/地址键、大小写/分隔符/扩展名和依赖是否在实际目标环境可达，不把AssetDatabase或Editor成功代运行供给；不统一硬套某API的路径语义。选合法冷启动、加载、切场景或本目标构建，不扩全平台。对多状态供给反查权威状态谁生产/恢复→谁选择保存源→真实读取caller→谁写实际Renderer/实例显示根→切换/归还责任，不能在数组/字段已保存处结束。

可达消费者必需引用缺/错、执行域不允许或目标API不可供的完整静态链可确证；必要目标产物实际构建/加载失败按该观察判断。未检出runtime caller只记录本次运行入口查询未命中；先核本轮是否要求运行消费，再查真实创建、装配及约定消费者。**零caller本身不证明供给存在、缺失或消费失败。** 仅要求作者供给时，已证供给可成立，不强加Player；必要运行消费未证则保待核，不自造P0或完成声明。只有对象确经核实不存在时，才按[应有而缺失](recognition.md#absence)认定缺口。只有引用在盘不签加载/效果，未知运行补具体环境观察，编译/离线/Player分别给范围。

正常对照为同目标真实必要资源和效果，Editor作者工具可Editor-only；合法重序列化/未改真实引用的meta不是故障，未涉及AOT/剥离不全扫。修原供给责任源的绑定/导入/执行域，保GUID、旧合法资源和作者输出；不删guard/清flags/删效果求绿。复验原断供及直接消费者/旧入口，必要运行声明按同版产物，静态链仅闭引用命题；供给/平台/观察前提未变可复用。

<a id="method-a-p0-03"></a>
### A-P0-03｜UI与空间可读可达

取当前显示/辨认/可达底线和参照，固定实际UI/场景对象、入口及合法内容尺寸。追Canvas/RectTransform/字体→裁切/安全区/层级排序→射线/焦点→几何/坐标域及业务目标绑定，选支持的最长内容、缩放、弹窗或相邻组合中敏感合法例。

实际布局资产和尺寸前提决定必裁切/挡住必要对象，可静态确证；字体fallback/渲染/输入坐标未知才同版完整尺寸画面与真实操作补证，查具体位置及目标，不用净空数字或截图数量代判断。正确HUD100被挡归本项；HUD1000而权威100归F反馈，不凭显示症状猜经济坏。

正常对照含有效设计叠层、合法长内容/比例下仍可辨/可操作及正确点击目标；不能事后发明次要按钮例外降用户遮挡底线。修布局/坐标/层级责任源，保信息量、风格和命中区域，不删按钮/必要文本或拍有利视窗求绿。复验原坏内容与邻接旧页面、比例和输入，核新损失；静态只关布局命题，不代实际字体/Player观察。绑定/字体/布局依赖/观察条件无相关变化或反证才复用。

本次画面/状态完整执行[实际视觉验收](review-standard.md#visual-review)；下方同名/卡数正常不能抵必要标签被挡。

<a id="method-a-p0-04"></a>
### A-P0-04｜连续动作、镜头与音画

固定实际对象/生命、动作/参考和必要音画消费者，沿权威状态→变换根/动画/镜头/VFX/音频驱动追相关写者、时空来源、暂停/取消/切换及绑定寿命，选现有移动、转向、接触、重绑或组合敏感例，不造不存在转面/池。

**取景链单独走一遍。** 对象看起来凭空出现在画面中部时，权威世界坐标正确与视觉结果异常可以同时成立，必须把取景当作独立可查链：实际相机 rig 与跟随目标/绑定及延迟、视口画幅与安全区、近远裁剪面与 Layer/Culling Mask 遮挡层、世界↔屏幕换算与屏幕空间遮罩、相机切换与混合的过渡时刻。逐项指出实际配置与预期；**不拿“画面里突然出现”直接签世界坐标错**，也不因世界坐标已核正确就关闭取景命题。

已核前提的冲突写入/错坐标静态链可确证；连续表现结论须同版正常速度过程，原时刻与前后段、声音/可见细节和真实驱动对应。慢放可补细节，不能代正常手感，静帧/终态/换版片段不签连续。权威位置正确但视觉跳变归本项；权威位置错误归F03，同一必然视觉后果不重复造项，另有独立表现违约才另保。

正常对照保批准切镜/传送/2D滑步跳切及同对象正常运动/关键提交声音。涉及制作先核参照、素材与宿主配置，关键缺口按资源探查，效果未知先小样；纯布局不强造美术依赖。

修真实写者/时空/绑定源，不吞反馈或删动作效果求平滑，保原节奏、轮廓、内容、命中与音量层次。原坏转折/正常连续段复验并核损失；源码修复仍保必要动态待验，不拼版签整体。驱动/素材/时空和观察前提仍真可复用，新相关绑定/完成声明变化再展开。

本次可玩/视觉对象完整执行[实际视觉验收](review-standard.md#visual-review)；连续品质与改动收益损失分别判断，静帧不签音画或瞬态合法性。

### A-P0-05｜必要负载、性能、容量与寿命

先核本项目硬目标/预算或资源寿命要求，定位真实热点/caller频率、必要效果/密度/速度/持续时间、平台和样本条件，追容量饱和语义、取得/分配→持有/累积→释放→清理再用及跨启动/预热/加载/保存峰值。

可达无界增长/缺释放及必要寿命违反的完整静态链可确证，不等耗尽正式环境；预算/连续负载结论取对应同效果CPU/GPU、分配峰值/逐帧及连续有效样本，平均值不抹硬失败、缺GPU不报0/FAIL。无数字但必要输入丢失、操作卡死等真实关键失败仍按相应F/A P0，其它必要硬目标及已证响应／流畅品质差距按超级P0阻断；缓存/一次分配或猜慢不是已证缺陷，有因果线索才有限查证。

正常对照保预算内初始化/预热分配、同必要内容密度速度、合法容量满正确拒绝及释放后再用；排除采集扰动/无效首样本，不自造0B/16.67ms/自动扩容。修真实热点/容量/释放责任源，不降负载/内容或搬成本到未查阶段，保清理权与合法业务续办。复验原负载峰值、同效果正常路径和清理再用，核旧价值/成本转移；独立F续办后果另闭，同一性能事实不重复计分。预算/负载/平台/采样前提仍适用且无反证可复用。

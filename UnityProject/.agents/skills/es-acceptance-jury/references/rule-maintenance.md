# 规则维护与保留依据

仅在维护本 Skill 规则、配置、执行代码或分发适配时读取；授权按[来源与权限](source-authority.md#rule-write)，本页不另设审批。复用现有任务记录和陪审链。

实际修改前读[改进Skill须知](skill-improvement.md)：核本次授权是否覆盖受保护机制的删除、取消触发或降级，尤其是[用户评分机制](skill-improvement.md#scoring-protection)；保正常优化与用户明确修订的合法范围，不把一般精简、能力不足或测试通过当成新的修改授权。当前授权范围内不重复索权；完成适用方案评估及同版意见交接后写正式文件，同时替换冲突、歧义和模糊旧文，不只追加。

## 核实责任再改

定位当前条款、版本、目的、触发、义务、例外及实际消费者，只读受影响链。区分事实缺陷、待证判断、已披露限制和用户策略；旧报告不裁新版本，披露限制不证明合理，历史选择可被真实修订。篇幅、评分或统一删减比例不能单独决定删改；已授权范围内的矛盾、失效、歧义或误阻直接修正，缺授权的具体变更才说明所需范围，不拖住独立已授权工作。

后台提供本波实际原文差异/事实，由对话AI按[真实文本变化](skill-improvement.md#text-changes)向用户展示；现有任务记录保留`原条款/目的 → 依据与动作 → 新承担位置或有据取消 → 验证与恢复`，不能只留内部记录或摘要。同一已授权批次的引用同步和返工不逐文件索权。

## 优先收敛

- 优先替换、合并、撤销重复或无效规则，控制指令净量与默认读取量；同一职责只留一处正文，其他入口引用。新发现先用现有规则，不逐补丁累加条款、文件、必读或评分器；确有覆盖缺口才补最小内容并收敛重复。
- 保住仍适用的职责、成立前提及合法例外；用户明确取消的义务可据原话取消，不强求旧行为永久保留。迁移须核实际入口、时机、链接与消费者，存在文件不等已接入；不把专项摊到主入口或移成无法发现的附录。
- 模型默认、自动启用、计时、来源、退出与分发仍按各自授权；维护许可不扩其它策略或宿主操作权。
- 成本区分字节、字符、实际读取量、token与等待，说明方法及范围；缺测不认证收益。体量只作成本证据，不代质量；脚本、哈希或结构通过不证明来源、语义或实际执行。

## 历史依据按对象和时点继承

区分用户直接要求、转发AI报告、陪审原裁定与作者推断，保日期、对象、原话和后到修订。检索数量不等独立问题，不为数量拆碎约束或复活撤销政策。通用原则、项目专属参数/禁令和待证方案分开；历史项目画像留原任务记录，不变成通用必读或门禁。项目故障不自动证明Skill是原因。

## 定向验证与恢复

本轮用户要求大规模整理时，做有界独立检查；明确要求全包检查时，按[candidate-scan](candidate-scan.md#scan-depth)盘点实际包全部文件，并调查本次修改、相关旧条款及其调用方。两个内部角色可按职责承接，用户明确指定另开扫描角色时按其要求执行；没有实际启动不冒已扫描。检查入口是否消费新规则、旧义务是否矛盾及合法对照是否误阻，分开报告语义调查、结构/链接/hash和实际校准。此项是Skill维护验证，不变成普通Unity任务的全仓审批或第三常驻裁定。

改变语义、默认、读取或执行时，先按[显隐影响相关性](verification-scope.md#relevance)声明真实消费者及纳入／有据排除的检查；检查原错误能否检出、合法输入是否误阻、旧入口与失败恢复；只补实际缺证，按[验证入口](../README.md)选择完整性检查、受影响用例或完整回归，不因每次读回、陪审复验或文字返工重跑全套。留证沿[共用与保留边界](verification-scope.md#relevance)，不另造整包或媒体副本。错字、排版或不改读取目的的链接修正，局部读回即可，不强制矩阵、固定轮次或全历史回放。

原陪审独立核差异、原目的及相称验证，给保留、通过、返工或缺证；不由作者自证等价或用保留率评分。缺依据标 `RULE_CHANGE_BASIS_MISSING`，职责/发现链丢失标 `RULE_CHANGE_COVERAGE_LOST`，只暂缓相关删改与完成声明；补证、无关工作继续，恢复由原链或有据更高来源裁定。缺必要独立核证时保对应未闭。

此规则不安装全宿主拦截；结构检查不能证明语义未丢失，也不保证所有宿主自动遵守。

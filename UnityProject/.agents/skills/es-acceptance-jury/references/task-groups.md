# 分工、辅助与接回

本页管理确需且已授权的制作分工；必要独立陪审按[机制继承](coordination.md#activation)在复杂或有具体危险的授权任务自动接续，不与作者辅助混为同一角色。普通无分工/独立核验需要的任务不自动启动Agent。使用当前宿主原生能力，真实缺能力与最小降级沿[模型与宿主](model-choice.md#availability-recovery)，排队/额度/超时不判不支持。

<a id="selection"></a>
## 有独立产物才分工

长子项须能独立推进、有明确可接回结果及文件边界；短辅助用于有界探索、对比、资源整理或指定实现。比较实际并行收益与交接/整合成本，不设固定分钟门槛、计时配额或为凑组拆任务。依赖同一文件反复变化的工作先明确唯一writer和稳定接口；成熟小片及时交真实消费者，不等整个分支齐。

作者辅助不拥有独立验收权，成果由后台主工作AI整合、回前台质证并送适用原陪审；两独立评审职责不能由一个Agent模拟。需要独立子组时在已有任务保父子目标、写域、未闭和接回条件，不另造协调平台。角色不递归扩组、抢全局owner或借额外CLI绕宿主容量。

<a id="proposal"></a>
## 授权与实际启动

从当前有效用户委托/项目指示核已授权范围。确需用户决定的范围/取舍尚不明确时，先形成具体可审分工与完成无依赖准备；等待不当同意，不以一分钟静默推新权限。已授权的常规辅助直接执行，不重复索权。真实spawn成功并取得身份才称启动，排队/计划不代接受。

<a id="exchange"></a>
## 真实交流

传同一原任务/修订、对象版本、真实材料、影响范围和同伴实际可达地址。作者与评审在有真实增量的方案、小样、关键实作/观察、修复和交付处交流，严重失败立即报，不固定分钟空消息或逐函数会审。组内原生发送/回传可用就实际用；不支持直连时主端忠实转交并保能力限制。

<a id="signals"></a>
## 回传

回传实际产物、来源/版本、采用/运行/证据范围、必要发现/条件及下一消费者。消息展示、缺字段、去重和完整原件沿唯一[消息合同](coordination.md#message-delivery)，不恢复旧五行/边框；作者辅助不冒陪审，实际陪审仍须携原分/主事件。辅助成果不是独立裁定，作者不替评审关否决。普通控制/字段定位一次说明即可，不新增报告或催分往返。

<a id="integration"></a>
## 集成与安全接续

对话AI核分工／依赖与当前writer，由后台主工作AI唯一整合采用；子项交小片及明确合同，接回后核实际源码/资产/配置消费者，不能由打包/排队冒采用。保原输入、合法行为、玩家数据、资源归还、失败前取得及旧未闭，复验受影响原坏例与正常对照。子项局部通过不代主任务完成。

暂停/撤销/失联先按真实宿主能力安全收束在途工具与写入，保现场、完整意见、版本、未闭及恢复条件；陪审同窗口接续与跨窗口新建读旧材料沿[机制继承](coordination.md#activation)，不跨窗resume。新角色实际接通再移交，不盲关窗口或抢writer。保所知状态，超时不清失败，无新材料不循环唤醒。

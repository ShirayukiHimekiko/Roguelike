# 项目理解真实维护工作区

<a id="workspace"></a>
## 一处活理解记录与实际阶段

实质任务先从已确认目标项目的AGENTS/现有治理入口找到活理解记录；未链接时只在该项目获准文档域定向查找，已有适用记录就在原处使用。确无适用记录才由获准维护者在项目持久位置建立并填实，例如`project-workspace/PROJECT_UNDERSTANDING.md`；示例不覆盖项目放置合同，也不放进全局Skill安装目录或可再生Library。

常态先实际读短的当前接点：目标、源/采用版本、可做/禁做、必要未闭、下一动作与原件/职责记录定位，再按本段影响下钻稳定事实和相关记录，不默认全读历史或所有角色记录。稳定事实须能定位成熟度、真实权威/生产与消费入口、来源/版本/绑定及旧消费者；区分Git提交点、工作树/候选和实际采用。首次理解、基线缺失/失效或重大结构变化仍核必要全项目关系，短入口不免覆盖。事实与裁定来自原件，记录/图标不认证理解；必要关系缺失、陈旧冲突仍按[原P0](project-understanding.md#project-fit)限制依赖动作。

本功能只记实际事件/事实，不要求后台排用户标题。定位读取、边界确定、原记录更新、必要关系缺失和恢复接续分别对应workspace-read/scope/write/gap/resume；原触发、必要未知/受限动作/解除条件保持。对话AI核原件后按[呈现入口](message-style.md#user-facing)给用户视图，落盘/工具输出不代用户已见；无变化不重复/逐工具播报，阶段不代通过。

当前项目内容的[元素模型](recognition.md#unit-state)复用本活记录或其已有原件定位：保世界／应有及实有关系、当前修订与观察时点；按影响判断的命题接原件／版本／条件、支持范围、推断／未知或确证缺失、反证及未闭／下一动作，不另建平行模型库。当前任务实际参与职责各自消费同一当前定位；规则、状态或定位被反证改变时，明确旧判断撤回／仍适用范围，真实送达受影响职责并各自接当前事实，同路径／同版本不证明模型仍有效。交流端在[默认持续维护](dialogue-coordinator.md#model-autonomy)中主动发现的元素／同元素新命题同样接此原活记录，不只等用户提交变更。普通变化按影响更新，不逐工具重填或全量先建完才做独立小修。

正在创建、更新、失效处理或恢复时，实际消费[维护与接回](#maintenance)；阶段只反映动作，不代原职责核证或增加批准轮。

<a id="maintenance"></a>
## 创建、维护与失效接回

先核项目根、AGENTS/原记录、实际允许写域及已有入口。确认最终路径归属后再写；只读目标不得借工作区越权建目录，可用已获准且明确绑定目标项目的现有记录，缺写域时具体索取而继续有据调查。活理解不纳入临时计划轮换清理，正式退役仍依真实授权和项目保留合同。

首次建立必须据当前源码/资产/装配填真实内容，把入口接到项目现有AGENTS/README或等效治理索引，并由实际工作端读回后接本段动作；空模板、目录清单或作者一句“已理解”不算。项目身份/源与派生采用、当前目标/写域、关键生产链与消费者、做/不做、未闭/下一动作及原件位置应能恢复，不强制固定字段表、文件数量或新平台。

**产品单写，记录分域自主维护。** 明确交接每处记录的唯一写者，优先复用已有落点；确需并行且无合适记录才分职责落点，由主入口链接，不强制固定文件数。工作端单写正式产品及共享事实/采用汇总；F/A各自在已交接写域主动查源、原位更新本职责当前发现、依据、必要未知/下一动作，保存同路径读回并真实通知工作端及受影响职责，不等逐条催更或工作端代写。未交域或只读时保具体缺口，继续有据调查；不并发覆盖同一文件，不借记录写权修改产品、他方裁定或自证采用。

自然决定/实物、真实用户修订、目标/权限、权威/入口/来源/绑定、实际采用或反证有意义变化，以及可能出现不明终态写入前的必要意图，更新足以安全接续的当前事实/原件定位并读回；保独有材料、原预算/失败/在途与原意见闭权，不另建压缩摘要权威或逐工具复制全史。只更新受影响事实及版本/范围/未闭/下一动作；当前事实原位维护，已闭流水回链原件，不逐工具、轮次重填或复制长报告。工作端在依赖决定前实际消费必要角色更新，处置冲突/未闭并同步共享事实和执行，把真实事实/原件交对话AI沿原消息合同向用户展示；不因角色写“通过”直接改成已采用，不代关原否决。计划、完整意见和历史保原归属及来源，只互链，不形成第二裁定/评分权威。

同身份已知压缩/上下文不足、摘要冲突或其它恢复，先读同一活记录的当前条件、真实后到用户修订、撤回/原未闭与原作业终态，再按拟执行动作回源；旧摘要/旧PRE计划不压已核现源，不重放已完或未知写。核后接第一合法结果，按[同身份接续](coordination.md#activation)保身份/事件来源和真实送达边界。旧通过不覆盖变化，只重开受影响关系；有据局部任务不被迫重填全项目，新增批次/普通工具返回不自动失效。接任务前、采用及交付时核实际载荷/安装与记录相符，完成后原位维护当前状态，不留旧版本冒当前；标签、维护动作或脚本ready不解除原P0。

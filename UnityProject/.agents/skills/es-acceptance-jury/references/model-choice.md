# 模型与宿主

<a id="inherit-choice"></a>
## 当前调用

**本包锁定 `gpt-6.1-sol`，强度 `xhigh`，`fork_turns="none"`。** 对话 AI、工作 AI、F、A 全部使用它；正文按这个模型能直接执行的写法组织。用户在当前任务里明确指定的具体强度优先。用户明确改用其它模型时（只指定模型、没指定强度的，Astra 默认 high，其它默认 xhigh），如实记录这是用户选择，并提醒本包是按 gpt-6.1-sol 写的。不要使用 `gpt-5.6-sol`：服务端已拒绝（2026-11-09 实测 403）；全局 AGENTS.md 若仍写它，以本节为准并告诉用户。目标模型或强度不可用时披露缺口，不静默降档或替换。

模型ID/effort取真实宿主能力，不由展示名称猜造。宿主无effort参数时，只有用户明确选择省略该参数才按真实能力省略；仅选择模型不能绕开默认强度，也不能冒称已设置xhigh。prepare输入只检查声明，不认证用户原话或授派发权，实际调用前读原来源。

fork_turns="none"只是不自动带入主流程的聊天历史；角色仍可读同一项目和原件。独立性同时依[首轮输入合同](coordination.md#independent-input)：完整交有效用户需求、事实与证据，先不交作者评价/预期结论，角色形成初判后再对照。none参数、身份不同或准备工具通过本身不证明判断未受影响；实际接触过解释/旧结论的范围如实记录，不能自称忘记或盲检。

<a id="availability-recovery"></a>
## 原生能力与接续

需要且已授权的分工优先当前宿主原生子Agent，实际核创建、身份、状态、发送/回传。可用时必须走原生；槽位满错峰/复用，材料不足先准备。额度、超时、一次失败、无回复及daemon_auto_start=false不能判不支持，也不以额外CLI绕容量或模型缺口。保持用户普通codex启动习惯，不要求--no-daemon，不改daemon配置。

仅必要原生创建/接回能力实际缺失或明确返回不支持，才考虑最小独立CLI降级：先留具体缺失、真实错误原文/来源、原生替代核查及范围，缺证不启动。独立CLI如实标顶层会话，不冒子Agent；本次用户明确独立会话例外只作用本次范围。显示分组不默认右拆，不为普通任务新开窗口。

<a id="cross-session-continuity"></a>
## 安全交接

同宿主／跨窗的职责性质、原意见和实际接收／writer交回，只按[持续接续](coordination.md#activation)执行。此处只负责模型／宿主能力：已有身份与当前用户模型选择不符时明确迁移，不猜已换；容量／能力不足保真实错误与最小依赖，不借顶层CLI绕容量或把旧ID当当前地址。通信／提交和running／completed不证明已换新或内存释放；未部署的唤醒／卸载保后继与未验。旧私人缓存、临时策略和日志队列不恢复为合同，原件仍按包外历史保全。

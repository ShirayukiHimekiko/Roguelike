# 非工程学习：方法何时有效

按[受控学习](learning-control.md)定目标、查源／范例、解释／重现、判别练习、异需整合及回归沉淀；阅读／创作／返修也有预算。先定最可能不成立的解释、效果信号和风险，再实际写／画／演／听，按[同口径对比](comparison-and-regression.md)核结果；共同学习步骤不强制作品采用同一叙事／审美结构。

日常学习写作、设计或某类创作，先系统研究其理念、方法谱系、作品组织、精细手法和不同条件下的取舍，再分段练习。例如“写出双方诉求都成立却无法轻易和解的冲突”可以是一项练习，不能把“学习剧情创作”缩成只练该题。材料取完整作品、论文、作者访谈和实际反馈，既看好例也比较不同流派；外部事实核真实来源，作品人物/情节不是现实证据。

分开保存：

- 可核事实：作品发生了什么、原作者明确说了什么。
- 机制解释：为何某次行动关闭退路、哪种信息差影响选择；允许多个竞争解释。
- 效果判断：读者是否感到张力、是否相信人物、画面是否吸引人；需要具体阅读/观看反馈，不能由“采用了方法”推得。

选择能推翻解释的改条件问题：坦诚沟通后是否仍有冲突？代价可补偿时还有什么不可兼得？换掉某一意象，效果是否消失？保留合法平静、含蓄、无反转等正常作品，不把风格偏好硬化为“必须升级冲突/必须反转”。

用不同人物、背景、媒介和创作诉求作分项及组合练习，检验方法怎样保留、改变或失效，不复制原作表面桥段。细读语言、节拍、意象、信息和人物动作的具体组织；不能只保存“制造张力”一类标签。依反馈辨认失败层，修解释和手法，再把经验用于另一任务；不靠不断加事件遮人物不成立，也不以一次练习结束整个领域。

沉淀内容是方法解决的问题、采用线索、适用条件、反例、失败征兆与返修方向。未实际尝试的方法用 `hypothesis`；只有试用但无充分反馈，用有限 `heuristic` 和 `trialed` 状态。格式、字数、结构测试只能守形式合同，不能认证感人、好玩或审美。

实践失败可以改进能力包，也可以说明原解释应被放弃。保留来源及被否定的范围，避免把一次作者自评变成永久规范。项目明确要求的禁忌、版权/引用条件和交付格式仍是实际约束，软方法不能免除它们。

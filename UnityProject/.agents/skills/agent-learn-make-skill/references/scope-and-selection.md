# 学习规模、来源筛选与持续扩展

启动领域学习、补材料或重判范围／来源时读本页，承担[受控学习](learning-control.md)第1／2步。从完整能力面、真实素材供给和当波设计／生产组织广域取材，允许借成熟作品发现此前未识别的方法与缺口；不要求先有眼前局部报错才可查。按必要覆盖与实际帮助定足够的检索／筛源／深读计划，主动执行，不以小题默认额裁剪来源。建立能重现、能异需复用的专业能力，用户要求业内商业级时保相应品质、生产供给及实际使用，不以集成演示代交。

## 初期立已知基准，不假装一次定全

从有效原需和已见原件建立初步认识：要能处理哪些工作/需求，优秀结果有哪些可观察特征，涉及哪些方法家族、生产环节和供给，当前规模与依据是什么。明确已知必要部分、尚待探索部分，以及暂排除内容和理由。可先开展已经有据的部分，不要求先穷尽领域或让用户填表。

排除应来自用户真实限域、对象不适用或无关性证据；不会做、难取证、当前工具不支持、某Demo没有展示，不能把原需中的必要能力排除。未知保待查，不伪装成无关。初始案例和方法清单不是学习上限，也不是之后只能在其内挑题的题库。

在同一接点接续：新材料或实践揭示新的方法、正常用途、组合、隐性依赖或品质差距，就补回能力面、方法关系和下一研究/实践。围绕必要知识、品质、供给与取舍组织研究；涉及需求差异时按[专业差异选法](workflow-learning.md)核什么会保留/改变方法、还不会作哪项专业判断。已选工艺的有效参数、完整工序和失败恢复同样值得深入，不为学习造选法竞争。材料须能供给相应判断/作者操作并进入真实任务，不让最近报错、现脚本或可访问目录反定范围。局部知识按它能否解除主差距或必要前置安排。对照原基准说明新增、修正和有据排除；换轮次、改名或候选标签不取消已确认结果和质量。用户真实改需可调整，反证可纠正解释，二者都不授执行者自行降级。

## 广泛找候选，按实际帮助取舍

高质量权威Demo、完整商业作品与作者源工程是重要候选；还应按缺口追不同方法、场景、媒介/平台条件、工艺取舍，以及真实失败/返修和后续消费。多样性看它是否带来不同的有效知识，不按域名、作者或案例数凑配额；同一作者的不同工艺可互补，多家重复同个模板也可能没有新增价值。

### 来源覆盖不足，先实际扩大供给

领域深学、新能力、实质反馈或完整结果反证后，不能只读首个官方指南便以自拟试错代替学习已有做法。进入依赖制作前，在原接点对回必要设计／工序／控制／失效命题及其原件；同一材料可以承担多项，但各结论按真实内容判断：目标作品证明应有结果，工具说明证明接口和声明能力，作者过程供给怎样决定与操作，原始比较／失败评估供给效果和边界。截图数量、HTTP成功、模型推荐或多Agent赞同不能互代这些证据。

- 缺的是已有做法，就实际查原作者教程／工程、研究方法及附录、完整操作／返修或可核案例；不能只继续找目标图、通用工具文档、二手目录或自己的旧笔记。
- 检索和深读须追有区别的方法家族、成立条件或失败机制。现材料同质、关键面仍未知、首个方法不能控制主差距时，必须换能补该缺口的来源路径，并读命中正文／原件后再判。未找到可信替代保实际查找和单法依据，不凑假对比。
- 每个拟采用方法核实际输入、控制手段、作者动作、完整结果和失效条件，说明哪些能用于本项目、哪些只作能力对照。需要参考图、额外API、训练或后处理等条件的方法，不因提示词／命令可复制就冒当前工具已能执行。
- 新来源按实际所得补足选法依据、控制、动作或反证；只添链接、措辞或材料份数，必要方法覆盖没有增长，仍不得转依赖制作。例如来源只证风格相近，不能据它承担界面的精准重建。
- 按受控学习的原账复核窗口／到限处置，不把默认轮数或资料数当领域学习上限，也不借扩源无限续跑已败方法。保未覆盖处、实际扩找动作及命中／未命中或不可达事实，下一取材目标有据再具名；准备性查证可继续，未证前提不因花完额度变为成立。

成熟应用／有据小修以本次具体判断复用未变原件与正常证据：仍支持什么、何种反证推翻、尚缺哪侧；足证直接用，缺侧实际补。作者名单、方法名或步骤标签不整体继承；不为形式强制联网、多网站或篇数，也不借此以陌生领域的一份通用指南自证充分。

**充分度按当前动作和采用范围核。** 不要求先学完领域，也不要求本地新条件的效果先有外部成品证明才能验证。专业原件足以支持问题定义、输入／真实控制及可推翻预测，覆盖缺口需要扩源时已实际扩找，而剩余未知仅是本地新条件的效果时，可在原授权、预算和未解除P0边界内进行具名隔离判别；其结果另核，未证路线不接任生产主工艺。仍只有泛化指南／自猜或根本未补缺失方法时，不能借“实验”跳过实际扩找。该分支不解除原否决、不重置支出，也不授权额外生成。

每次选择深学材料，先判断它具体能帮助什么，而不是先囤满再总结：

| 判断 | 实际要做的事 |
|---|---|
| 对准缺口 | 指明当前缺哪项方法知识、品质、供给或取舍依据，这份材料将补哪些有效参数、成立/失效条件、设计判断或作者操作；涉及生产差异时说明怎样影响选法及真实任务。“很顶级/很全面”不够。 |
| 核可学习性 | 查来源身份、版本、完整原作/过程、可读细节和可达供给。宣传片可帮助辨表现，不能自动支持复现；原件缺失就追作者、工程或互补来源。真实性与预期用途分别判断。 |
| 给出可检验预期 | 学完后应能解释、复算、重现或改变什么？什么实际结果会说明它没帮助、解释不对或仍缺其它方法？不要用浏览量或术语数量作信号。 |
| 实际深学与实践 | 亲读/看适用完整原件，提取参数、素材、组织与架构关系，用原条件重现、可区分练习及新需求实践核帮助；资料很多不免实践。 |
| 更新选择并扩找 | 将实际帮助写入现行方法；无新增、失真、不适用的材料说明理由后停止投入，未核的保待查。未补上的缺口继续换来源/方法，新的必要差距补回学习面。 |

在原接点走广域发现→按工艺／供给差异粗筛→关键原件深读与取得→实际使用→精选结论。保来源／版本、原件、许可用途、关键控制、采用／淘汰理由和未覆盖面，让结论能直接供选择与生产；条目数不代精细整理，只有精选摘要也不代实际取得和使用。保总投入／已用／在途，不另造清单平台。重复镜像、同图裁切、分段或多Agent重复阅读不能重置额度或冒多样证据。未经实践的预期不冒实际收益；能教一个技巧不代表其余流程。合法但无帮助的权威来源可不选，有帮助的材料不因不热门被拒。

选材还须判断其工序/工具/供给是否有能力控制当前项目差距、独特要求如何适配。HTTP200、索引摘要、API广告、品牌及示例数不等原件可学或路线可落地；实际访问/正文、许可、工具控制与目标品质分开核。关键前提未知、工具碰壁、观察反证或既有路线停滞时主动查项目原件与一手方案；查到足以决定就接实际作者动作，不用持续搜索或条目去重取代必要工艺实践。

例如优秀UI演示的材质和出现节奏可值得学，但若未展示连续输入、业务等待和取消，不能据它关闭交互反馈能力。保其已证价值，同时继续找这些关系的完整案例/工程并实践；不能把演示换成静态页、把输入屏蔽，或将失败路径排除后称复现成功。

## 从重现到复用，不围绕已知Demo拟合

原条件重现用于核理解和供给；改变意图、输入、组合或消费者的新任务用于核选方法和迁移。保原样与新条件、事前预测和完整结果，回到用户目标判断，而不是把目标改写成手边示例恰好能过的能力。最终画面相似、参数可调或文件检查通过，各自不能独立证明可复用的制作能力。

反例出现后追作用链，改现行解释、方法或供给，并核原坏例、合法正常用途及受影响新条件。禁止删弱期望、换低质占位、只保顺利路径、针对样本硬编码或用越来越多例外维持旧路线。有据调参须能预测对完整结果和其它合法条件的影响；不能将只对已见Demo有效的补偿推广成专业工艺。

阶段成果保已验证价值，并保原能力面、品质差距、待扩展处和下一具名行动；它不是完整学习的替代物。来源筛选通常随理解和实践反复扩展，不能用初期名单、自设资料数或本轮示例结束父目标。必要目标确已兑现时正常交付，也不为“持续”制造无关课题。

# 完整流程学习、解释自迭代与回归

学习一套流程、补足细节／推理或据新事实改方法时读本页。先遵循[受控学习](learning-control.md)的八步骤、进入／输出证据及行为预算；本页承担流程理解和专业选法，不另授自由转序。可按实际依赖回源或并行，复用已成立证据；不能略过事前风险、原条件重现、整合前定向回归及真实消费。

## 从真实起止还原全貌，再深入关系

先接回[可扩展的学习基准与来源选择](scope-and-selection.md)，明确要掌握的流程、实际入口、完成结果和使用者；有前后生产链接清交接，不把眼前故障裁成整个学习对象。沿原件从输入追到最终消费/退出，也从结果反查谁真正供给。正常路径、分支、回路、失败和恢复共同构成流程；新发现补回同一能力面，名称相同、字段存在、一次运行成功不能代替接线成立。

源工程/生产流程按[完整供给与历史到自主执行](source-to-automation.md)追工具链、实际模型/供应商、资源出处及可访问验证史/失败件/人工前后调整，连到当前生效配置与方法。历史不只归档：解释它怎样改变流程选择、操作与恢复，将供给、工艺控制和质量依据接成目标Skill自主完成新任务的条件，不凭配置/初步方案推定已有设计能力。

下列视角用于发现缺口，按实际对象取证，不要求填同一张表或给不存在的机制编造配套：

| 关系 | 深入到哪些细节才足以复用 |
|---|---|
| 节点与转移 | 每个实际可达入口、前后条件、分支优先级、早退/跳过、合流、重试/回路，以及每一步向谁提交什么结果。多个入口是否走同一规则。 |
| 参数与组合 | 真实默认/保存/运行有效值，类型、单位、阈值、哨兵、曲线/范围、覆盖顺序；哪些值共同改变分支、精度、成本或效果。单值正确不代表组合成立。 |
| 供给与隐性条件 | 原素材、配置、模型、数据、环境/版本、导入导出、绑定与外部依赖；缺件、过期、同名副本、路径根或身份变化怎样影响结果。 |
| 状态与时序 | 谁拥有和更新状态，何时求值/提交/释放；初始化、缓存、重复调用、取消、异步/事件时序、保存重开等实际存在的行为。没有的机制如实排除。 |
| 结果与恢复 | 中间/最终产物、真实消费者、反馈、错误/超时/部分完成、清理/恢复及可续做的位置；失败前后哪些状态被保留或已改变。 |
| 质量与取舍 | 为什么选择这种工艺/组织/算法，成本转给谁，适用边界及可替代方法；创作还包括完整表现、主次/节奏/素材质量与使用效果。 |

对每项影响判断的细节连上实际版本/位置、作用解释及相应观察或实践。标清已核事实、尚需验证和不适用理由；发现新分支或隐性依赖就补回当前模型。清单写满、读过全文或源码可达只支持各自事实，不等于动态行为、效果和全部细节已掌握。

完整性按这套实际流程的必要关系核：能否从新需求还原操作、解释改变条件的后果、识别失败并续作？关键分支/供给/效果仍未知时保具体缺口，不能由几个熟悉例子或 `complete` 标签关闭。细节多就按依赖持续分段，不要求先读完整个领域才做一项已能成立的练习，也不抄写每行代码充当深入学习。

## 把解释变成可检验的知识

区分原作者明确说明、实现／观察事实、自己的机制解释及未知动机。先把用户为什么要做、相对现状期待改变什么及保什么接到本批学习任务和第一作者动作；只写可改边界、沿旧题小修或过度扩改，都须对回原需。有据已满足、分析或必要保持不为凑变化而改。本人及其它AI首次理解／选法／方案／判断／产物按[首次结果独立核验](comparison-and-regression.md#independent-first-result)先保不可信候选，接真实独立质疑／原件核证后据具体命题采用；已有授权／已证事实按条件复用，不因新叙述清零。复杂方法的独立正向试用仍按该页原条件，不能拿可选试用或自验代本次必要质疑。首见疑似错误以置信度0作待查起点，保支持／推翻及改判，不直接据怀疑修改或否定已核事实。实现现状不自动是正确规范，规范与现状分清，不把错误行为写成必须遵守的知识。

从真实完整对象、目标风格和用途辨认必要视觉元素及关系，再追承担它们的素材／几何／材质／布局／状态／时序；两者不必一一对应。将有效作者控制、值／单位／合成次序连到局部作用，再连邻接、遮挡、分合、尺度、色光、主次及时间中的完整效果和成本。作者说明、实际观察、条件化经验及自己解释分证；名称／API可动不补机制，未知不编，已有有限因果不抹为零，也不把具体美学解释升为普遍硬需。

需要识别艺术因果或用户要求元素完整建模时，让下一作者任务实际承担这条作用链：先保当前可比基线及局部／整体方向预测、应保持项、竞争解释和可推翻观察；按真实权限与有效控制，选择能区分原因的关闭、替换、中性化或结构干预。用户原话与对“关”等操作解释分源，不推成每元素必须独立开关。关闭若同时破坏输入、遮挡、阴影、深度或其它通道，保连带项，用有据替代／匹配条件或联合干预；不能把同时旁路色与光的差异归为颜色单因。无可识别对照就保该范围未知，不假装纯单变量。

按本任务必要关系、敏感范围、耦合和预算选足干预：有判别力的大幅结构变化先识别有效控制／响应范围，再在有希望区间微调；已有同条件对照直接复用，不为形式重演或穷举全参数，也不以固定N盖完整。每次观察局部实际作用及整幅／空间／时间组织，关键组合核补偿、遮挡或破坏，比较条件保镜头／光照／时间／随机等相关变量。实验可尚未达成品而提供因果信息；若无预期作用，先核有效值、采样与观察域，不盲扫或编精确数。用户明确要求的大调／微调与完整覆盖须真实落实，不用计划或数量代结果。

分别核“作用已识别”“设计更服务目标”“方法可迁移”和相应P0／交付关闭；开关有变化不自动提供审美价值，局部改善也不签全局。视觉／动态／声音按相称完整观察取证，静图不签未看原速，宿主动态缺口不解释已见静态失败；成本区分实现量、有限测量和目标负载实测。将未用于拟合的新镜头、时间、输入或需求先作预测再观察（可先用 `scripts/wavelog.py try "判断" --predict "改了会看到什么"` 记下，看完用 `result` 记结果）；失配改当版关系、有效条件／许可和下一作者动作，不事后改预测。成熟有据经验可在原条件复用，不要求每项艺术知识先做完整实验；剩余关键未知才作上述判别。

把得到的专业经验留成后继能选择和操作的知识：成立条件和感知／使用目的、关键作用关系、有效控制／单位／素材／耦合、变化方向与副作用／代价、反例／失效征兆及替代／恢复。可用具体文字、标注原件、曲线、可编辑范例或作者工具表达，不规定长表／字段数；厚度看它能否支持有差异新需求的预测和实际取舍。经验进入目标领域Skill的现行方法／技巧，不只留本次日志或泛化成一条禁止语。

有效但机制未分清的经验可以保为带条件的经验性方法，说明观察依据、已知边界和待解解释，不因不能全解释就丢弃，也不冒已证明原因。解释、工具修通或数值校准足以回答当前未知后，立即接[目标内作者动作](production-learning.md)；新需求用已存关系重新选法、调整和观察，不继续堆局部命题拖延主体。

## 由完整结果决定下一作者任务

先把当前必要结果对到真实作者源：要改变什么完整关系，靠哪项设计操作／表示／供给和有效控制，怎样到达消费者；来源可读、控制执行、设计判断与完整效果分别提供相应证据。下一任务先选能解除主要差距的完整结果，再选操作，不由最近报错或现有参数倒定题。已提出的关键关系在作者源首次可读时就核，不等运行失败才补。

预测不符或反馈揭示失配时，沿需求解释→任务／选法→有效配置／作者控制→调用／实现→完整结果→审查采用／后继追到最早失配，分清直接原因、促成条件与未知，再据原件区分下一动作：

- **执行／接线已证错误**：修实际入口、绑定或消费源，核原坏例与受影响正常；这只恢复其承担的制作／判别。技术前提足证后立即回完整品质，不继续把同族诊断当主体。
- **设计／表示／供给缺少依据或已被反证**：撤回依赖它的主生产，下一主任务取得缺失的作者方法、有效控制、合格供给，或作能区分这些原因的完整代表判别。有来源的专业操作应能有意改变原差距及耦合，不用控制可动或参数扫值充当设计；只限制对应依赖，保其它就绪工作。
- **方法和操作有据，仅缺本次组合／效果观察**：直接做相称代表首件并接真实消费者；成熟基线的一处有据局修也直接做。不要求未来本地成品预通过，不因旧路线失败永久拒绝新能力，也不无据强制换模型／外包／全域重学。

多因可并存；源或效果证据未分清时先选能改变上述决定的查证，不把未知写成无能力。新增控制或前段状态会影响哪些准备、切换、完整对象与后继条件，须按真实关系重核；旧后段／局部证据只在其条件仍成立时复用，不能靠单项正确相加。

选题先对完整结果、当前最弱关系及必要后继：该作者操作要同时改变哪些设计／组织／行为和耦合，谁提供有效控制，怎样到达消费者？复杂工作按可消费子结果和接口分解，查共同状态／时间／规模／资源，不把各局部正确相加成整链成立。实际取得具名原件、改源或派发完整任务，给预期变化／保持、消费者及失败回点。观察后据结果改主投入；技术前提足证就接主体，完整失败未解除时不从现脚本可调项续出新题。必要但暂未派发的维度保真实顺序、责任和接回信号，不永久仅挂“父未闭”。预算沿原父／因果未知，不因新题名清零。


## 反馈进入现行方法与下一动作

先辨反馈改变的是目标／偏好、质量评价、失败事实、方法建议还是权限。有效用户修订累积落实；技术原因和建议仍回原件核，不把他方意见直接当成熟配方。保反馈出处、原认识、反证与新解释，不改写成AI早已掌握。

反馈／预测失配先按[父级决定与下一作者任务](#next-author-work)追最早失配及原因关系，再选择下一投入。解释失配就改条件、分支、技巧或设计判断；实现违约就保应有结果并修原责任源；供给变化就追影响并修接线／方法；证据不足就取能改变该决定的原件／完整判别。控制、执行、配置、测量与专业效果分证；源指纹只定位身份，不消除反证，也不作废无关知识。

把改判落实到现行解释、可调用方法和首个作者动作，再核完整结果与必要正常。局部收益按实际作用保留，足证即接主体；新增日志或‘整体未过’不算改变操作。确需兜底／兼容，采用前交具体对象、选择意向与依据、所保行为、损失／代价、临时或长期意向及退出／替换条件；声明不代根因修复、路线认可或授权。

<a id="proactive-value"></a>
## 让专业关系产生真实作者任务

从完整目标、原件及实际作品识别会改变选法的专业差异与具名增效机会：形体／材料／主次、行为含义、时间组织、平台代价或可编辑交接。网络探查、生成／编辑、素材加工和成熟依赖按本次作用选，不从现脚本参数倒定题，也不把所有潜在改进升为新交付。主次投入沿[父级决定与下一作者任务](#next-author-work)核原工艺和差距；工程特有关系再接[完整系统选法](engineering.md)。

### 从原作学到可以选择和编辑的关系

带着差异读成熟作者过程，取得为什么选、源上怎样改、怎样判断、何时失效的依据。只有工具入口就补专业设计判断，只有效果图就补作者工序／有效控制；把所得关系映射到当前材料、单位、结构和使用条件。目标关系仍成立可复用有据工艺并调参数；目标改变而控制充分就重做相应设计；必要属性不可编辑就补控制／表示／工艺，并保迁移损失。观察不足只补影响当前决定的一侧，不等全领域齐备。

例如脸型／体型变化，要查颅面前后量、眶颊口颏及肩髋四肢如何共同形成差异，源控制能否同时处理正侧斜与早期变形。成人底模改比例、统一放大头眼或加衣服不能独自回答；同立绘裁切先分透视／姿态／表情与结构未知，找互相约束的角度或动作。此为研究关系示例，不是通用工序或已掌握的新角色配方。

### 从选法到首件与后继

从完整意图选择下一作者结果：专业作者怎样组织整幅／空间／时间的主次、邻接、分合与节奏，源上哪些操作可有意改变这些关系，当前材料／状态／平台怎样耦合？让任务同时承担这项设计判断与有效编辑，不由现有参数、层数或最近报错定题。成熟有据工艺可复用；缺设计过程补该侧，缺控制／表示补该侧，只有本次组合观察未得就做完整代表结果，不预要未来成品。交具名源、操作、变化／保持、消费者及失败回点并实际开始；首结果改变现行方法与下一投入，不靠换术语／ACK表示转向。

检验迁移的第二需求等主作品过关后再做，由没参与制作的新 AI 只读 Skill 完成，作者和陪审不兼任出题或制作，见[核心名词锁定范围](intent-and-drift.md#core-noun-scope)。任务改变专业选择条件，不只换编号或预填现布局／已知修法。检验自主选法给原需、专业原件和已知失败，不喂工艺答案；用户明确要精确配置时保该正常任务。原样复现、项目组合与新研究分别取[供给到自动执行](source-to-automation.md)的证据，组合的控制／代价／保证不能省，也不把旧oracle／后端永久化。

观察后将成立条件、选择理由、具体控制／参数、耦合、失效信号与替代入口修进[现行方法](skill-design.md)，保作者说明、实际实践与未证解释各自范围。当前接点只接采用／撤回决定、首件与后继、必要未闭及原件定位；恢复沿它回到下一有效作者动作，不依完整聊天重猜，也不因有限声明解除原专业失败。

## 回归解释、方法与实际使用

每次实质修订按[四个回归时点](comparison-and-regression.md)选原坏例、合法正常、新条件／边界及消费者，整合／扩量前已有小规模核回。比较原解释和新解释的预测与实际：不仅看命令／代码是否绿，还看有效判断、流程顺序、参数耦合、品质和恢复。次数／时间归同一变更预算，失败回责任层，不靠重复绿灯通过。

保旧输入/原件、期望依据和实际结果。旧测试期望若本身错误，先对回有效要求/事实，有据修正并保差异；不能删弱断言、剔除合法条件或改标签来掩盖退化。正常路径没有被本次变化影响且旧证条件仍成立时可以复用，新增或失效的关系再补检查，不把每次学习变成全量重跑。

出现回归就继续修知识或其真实责任层，必要时撤回修改/改换方法；修正后核原反例及正常对照。对回有效原需及接续基准后，已兑现的部分用于下一真实任务；未覆盖的必要能力继续学习，不因把“当前目标”改名成局部而关闭。必要未知按新材料/实践推进，避免无新信息循环；授权内实践不等待 `adopted` 标签。

## 用轻记录接回下一次，而不是依赖完整聊天

优先在已有可读文档中保当前能力面/质量基准及待扩展处、流程模型、关键细节/解释及来源、必要未证范围；接回来源预计与实际帮助、有信息的解释变更、原预测/反例/实际结果和回归入口。可以融入学习笔记、Skill参考或脚本注释，不强制文件数、字段表、JSON、合同、数据库或专用工具。

恢复时按[自动定位与持续推进](task-continuity.md)找回同一工作区与目标 Skill，读当前认识、反馈发展及其改变的选择、已撤回解释/理由、适用版本/条件、未闭与下一有效实践，再按影响回原件，不把旧聊天中的“通过”当当前依据。回归入口需能找到真实输入/材料、必要工具/环境、期望依据和结果；记录“已回归”却没有实际调用或可读产物不能代执行。研究与实践持续接入该目标的现行流程/技巧；当前目标未覆盖且有可行授权动作时继续，不把这份记录当成果终点。

沉淀新 Skill 时按[设计与写盘](skill-design.md)把模型转成可操作的流程/技巧；维护时按[维护与回归](skill-maintenance.md)把修订及影响接回旧能力。工具不可用时仍可研究、解释、实践和保存实际能做的部分；确需该工具/宿主/画面才可判的结论明确保未证，不能以更多文稿补成已实测。

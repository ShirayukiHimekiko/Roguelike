# 受控学习：步骤、行为预算与转序

启动、维护、恢复或扩展学习时必读本页及[比较、质疑与回归](comparison-and-regression.md)。本页是共同学习步骤和预算的唯一规范；领域正文负责专业工艺，不再另定一套自由转序。预算约束当前做法，原目标与必要品质仍须兑现。

**流程开销封顶（视觉/制作类任务）。** 读规则、写计划、写评审这些流程工作，累计超过总时长 30% 就停下流程，回到制作。任意连续 30 分钟内应产生至少一张新的完整渲染或一个可运行结果。开工后 30 分钟内应有第一张完整粗版（可以很粗），用它和参照并排对比，找出“差距最大的 3 处”，并向用户做[意图回读](intent-and-drift.md#intent-readback)；每波开头查[漂移](intent-and-drift.md#drift-check)；之后的查源、重现、判别都只为这 3 处服务。要靠看/听判断品质的任务，先按 [reference-acquisition](reference-acquisition.md) 取参照、写 `TARGET.md`。

## 先选模式与第一批

必要轻量输入／Skill入口和本页模式预算可先读以识别目标与权限；随后按下列模式，在原接点一段先定第一有限批次：完整结果／当前步、关键未知／原件版本、下一动作及预期／反证、预计主动时间／费用权限、行为额／已用／在途／到限处置和恢复。再作实质任务深读／检索／探测／制作；不先完整调查后补，也不要求无任务信息时精确估时。新事实更新原记录；不额外建表、审批或状态平台。

- **领域深学／扩展**：默认走下面八步，范围按[规模与来源](scope-and-selection.md)可持续扩展；先选一个有完整消费结果的能力批次，不把领域裁成最容易的Demo。
- **已有方法应用／成熟小修**：回读当前方法、版本与正常证据，写明复用哪些步骤和理由，直接接相应实践及受影响回归；不凑资料、比较或实验数。
- **仅维护Skill**：把原失败转为方法责任、实际指令消费与正常用法回归。需要时用隔离小任务核可执行性，不自动接原产品，不把文字通过当生产P0关闭。
- **恢复**：先读现行方法、原反证、预算已用／在途和唯一writer，再接未完步骤；未知终态先核原作业，不重放。

## 八个步骤：凭产物转序

步骤是学习依赖，不是固定领域生产管线。可返回前步或并行已就绪部分；转序必须有下表证据，不能只写“已理解”。已有有效证据注明版本、覆盖及为何仍适用即可复用。每个实质作者动作仍先定预测、预算和风险，再执行／读结果／定向回归，不能把回归全推到第7步。

| 步骤 | 实际动作与必须留下的结果 | 允许转下一步的证据／失败回点 |
| --- | --- | --- |
| 1 定目标、摸底、预判风险 | 接全部有效原需，列必要能力／品质、已有正常及原失败、未知与有据排除。用现有作品／小诊断区分已会、不会和未经验证；核作者源、消费位置、工具、权限和当前最弱前提。**实质任务先写 `INTENT.md`**（核心名词、例子的三级处理、用户判断句、会失望的情况、“不是 X 而是 Y”、最多 3 个关键未知），见 [intent-and-drift](intent-and-drift.md#intent-md)。**视觉/听觉类任务交出 `TARGET.md`**：开工只需每个用户点名对象 1 张亲看过的实机图，之后补到约 3 张加 1 段视频；每张标能在截图上指出、能量的特征，每条特征写候选技法（不知道就写“待查”）。格式见 [reference-acquisition](reference-acquisition.md#target-md)。 | 结果和评价基准可观察（`INTENT.md` 已写；视觉类：`TARGET.md` 已写、每个点名对象至少 1 张实机图已亲看），首批依赖及风险有处理；缺件只限制相应动作。不能自行把难点排除，**不能把用户点名的参照换成别的对象**。 |
| 2 查源、筛选、比较方法 | 按[来源覆盖](scope-and-selection.md#source-coverage)实际检索并读已有专业做法、作者过程与失败评估；分清目标原件／工具说明／工艺证据的作用。按必要设计和控制缺口找有区别的来源，比较可达方法的条件、质量与成本。 | 按下一动作／采用范围核必要方法和控制原件、取舍及反证；通用指南加目标截图不自动足够。覆盖缺失、同质无增长或完整结果反证时，先实际扩找并更新选法，未补足不得转依赖制作；有据隔离判别按来源覆盖正文区分，不预要其本地结果。成熟应用可复用仍适用旧证，不强造来源配额；新学风格化目标时至少一半来源是风格拆解，见 [风格化来源](reference-acquisition.md#style-source-quota)。 |
| 3 拆解完整范例并解释 | 从输入走到完整消费，指出作者怎样设计、源上怎样控制，深读参数／素材／组织／架构及失败恢复。暂不重看原文，用简短说明或操作预测自检，再回原件查错。 | 能说明何时用、怎样做、为何和何时失效；解释对应真实位置。复述流利不等掌握，缺设计或控制回第2步补相应一侧。 |
| 4 按原条件重现 | 在授权可回改源重做代表完整对象／工序，保输入、配置、操作和完整结果；同条件对原作／有效基线，记差异而非只看命令成功。 | 原命题及受影响正常对照有实际结果；设计、供给或执行差异未解则追对应层。局部保存成功不签完整专业效果。 |
| 5 带质疑作判别练习 | 先写竞争解释及不同预测，改变能区分原因的条件；减少提示依赖，观察方法何时保留／调整／失效。失败也须更新判断，不能盲扫参数。 | 预测与结果有对照，原坏例／合法正常和关键风险已小规模核回；关键前提反证即改法。没有这些依据不能扩量或进入依赖整合。 |
| 6 真实异需整合 | 用真实用户／消费需求改变意图、形态、组合或约束，由差异选工艺与参数，实际改源并走完整消费者。先复用第4／5步仍有效的风险和正常证据，代表动作成立后才生产扩量。 | 新需求真的改变源及完整结果，控制、品质与消费有据；只换数值／截图／装饰不自动证迁移。失败回对应设计、工艺或供给，保旧正常收益。 |
| 7 回归、对比、反向核查 | 对本次所有实质变化核原失败、旧正常、受影响新条件和消费者；比前后完整结果及代价。主动找最可能推翻当前结论的反例，不只确认成功。 | 必要失败及独立否决由相应证据／职责关闭；未查保未闭。不能弱化期望、删合法输入或把原缺陷改名“边界”。 |
| 8 沉淀、交接、再调用 | 将适用／失效条件、选法、操作／参数／原件、判断和恢复修进实际Skill，制作类按[目标效果的构成→做法和参数→对照判断](skill-design.md#target-layers)写，踩过的坑放附录；第二需求等主作品过关后由新 AI 做，见[核心名词锁定范围](intent-and-drift.md#core-noun-scope)；按[任务供给](workflow-learning.md#proactive-value)派真实新请求。复杂维护在授权且可用时由独立使用者试用，不喂工艺／修法答案。 | 按任务供给核真实派发／回件及原能力范围；必要判断／品质未检就接续。作者源／安装分别核，不用记录或adopted结案。 |

“暂不重看”只检当前输出是否可操作；同上下文的AI并未失去已读信息，不冒无先验盲测、记忆训练或权重更新。跨任务／恢复时可再次先作预测再对原件，不为模拟间隔学习而空等。

<a id="parent-route-decision"></a>
## 父级决定的接回位置

预算不决定父路线资格。完整结果后的选法、限制与下一作者任务统一在[workflow-learning#next-author-work](workflow-learning.md#next-author-work)；本节保原调用的有效导航，不复制另一套决定。先对目标/反证实际改序，再核本页剩余额与到限程序；换题名/换人不清账。

## 每种行为先有有限预算

先按完整能力面、素材供给、设计差异与真实待产规模制定**足够投入且有限的本波计划**，主动取材、生成、制作和精选。下表数字仅作缺乏规模依据时的未证小题探路／同假设复核窗口，不是广域查源、设计候选覆盖或已证生产的总量上限，更不能默认少做。实际用户限额／宿主上限优先。次数和主动时间同时列出时，先到者触发复核；没有可靠时钟就用可核次数，不编造精确分钟／Token／花费。主动时间含读、思考、制作和判断；外部渲染／下载等待另列实际作业及状态，不无故取消正在安全运行的长任务。

启动时以必要覆盖、真实订单、已有工序／单位耗时及可用资源选规模；执行中发现遗漏也主动补足有限计划，记总量／成本、分批、已用／在途和兑现信号，已有授权内直接推进。不得因尚无完整历史数据便退回默认小额，也不得以分页、分代理或改名清旧账。未证关键前提先校准，成熟生产与充分覆盖按各自计划执行；必要长原件／完整工序不任意截断。必要规则读取也保实际投入；不能把它计成已学习了专业原件。

| 未证小题／单方法探路行为 | 初始复核窗口 | 到限必须做的事 |
| --- | --- | --- |
| 定目标／摸底：每能力批次 | 1次初判，10主动分钟 | 10 分钟内交出 `INTENT.md`。分清真歧义与可查事实；按对结果的影响决定问什么，最多 3 条，放进第一次[意图回读](intent-and-drift.md#intent-readback)一起问，先做不依赖它的准备。 |
| 检索：同一因果问题／供给缺口 | 2轮，每轮至多3条实质查询；累计20分钟 | 第二轮须换有区别的问题／来源路径（用 `scripts/refgrab.py`，按 [来源路由](reference-acquisition.md#source-routing) 换来源）。仍只重复命中则停止该搜索族，改原件入口、供给或方法。**例外：用户点名的参照对象不可替换**——三个不同来源都取不到，就停下来告诉用户缺哪个参照、试过哪些来源和报错，请用户提供截图/视频/链接；等待期间只做不依赖风格判断的技术准备。 |
| 筛源：同一问题 | 至多12个候选，累计20分钟 | 按预期帮助择深读，缺决定性材料定向补，不囤资料或按热门排序。 |
| 深读／观看：同一问题 | 至多4份原件；每份累计20分钟，同问题累计60分钟 | 分页／章节／不同裁切不重新计额；查已读是否改变选法，必要长原件按前述规则有据适配。 |
| 拆解／推演／自我解释：同一决定 | 1份简短可检解释，15分钟 | 给当前预测、最强反证和下一动作，不继续写同义分析；解释失败回源查具体关系。 |
| 工具能力探测：同一必要属性 | 2次有区别的探测，15分钟 | 查真实版本／官方入口或成熟替代；不能用函数改名冒控制补足。 |
| 原条件重现：同一代表结果 | 2次完整尝试，60分钟 | 对照差异追设计／供给／执行；若关键前提错误，不再按原法重跑。 |
| 受控判别：同一因果问题 | 每轮至多3个有区别条件，至多2轮，累计45分钟 | 写各条件改变了什么判断；不辨原因的参数扫描停止，回源或换有判别力的实验。 |
| AI生成：未证控制／单一假设的校准 | 至多4个独立候选；选中件至多2轮定向编辑；主动判断30分钟 | 不因一次工具可批量就扩大；核完整输出、结构／身份及消费，仍无帮助改供给／任务定义。 |
| 临时脚本／自动化：同一制作目的 | 3个编辑—运行回合，30分钟 | 真实输出未接目标则修工艺／接口，不能持续搭框架。单次内部展开另按下面批量计。 |
| 通用批量：同一未证生产方法 | 首批至多3个实际对象 | 完整看代表结果及展开清单、成本后才依授权定下一有限批量；不得先铺全量再抽3个免责。 |
| 同因返修／诊断重试 | 2轮，30分钟 | 核新增信息和根因；无新信息或修此坏彼停止原修法，回比较／追因，不叠补偿。 |
| 同口径比较：同一选择 | 至多3个有据方法／结果，判断20分钟 | 基准及可达有效替代足够即决策；无可信替代保单法依据，不凑三个假方案。制作候选的成本另归实际行为。 |
| 回归／质疑：同一实质变更 | 1轮定向核回，30分钟 | 覆盖[回归节拍](comparison-and-regression.md)；失败回责任层修正，不刷重复绿灯。新修正仍须核原反例和正常。 |
| 沉淀／归档：每个有信息结果 | 1次现行方法更新，10分钟 | 修改会影响下次调用的原位置；停止只增日志、索引或重复提醒。 |
| 协作／评审：同一决定 | 2轮实质问答，主端归纳20分钟 | 每轮须带新证据／实物或解决具体异议；未闭回制作／查证，不靠换人求票。已有适用评审职责仍履行，不因限额抹否决。 |

上表未列的未证探路行为，按最接近类别给有限复核窗口；广域覆盖、设计探索和成熟生产按前述充分计划，不由此归类套回小题数字。不是每次读文件都填一张表：在本批原接点统一列剩余额，动作后补实际消耗与有信息变化。

## 预算记给结果，不能用包装重置

归属按父目标／必要结果／因果未知，不按工具、角色或新题名；换模型、窗口、恢复、拆题携原账。真正新未知可分项，但累计已用／失败／在途及剩余成本持续保。效率核取得／读取／选择／制作／等待／反馈／恢复的总负担及谁承担，复用有效原件和共同准备，及时交可消费结果；计划累计不冒actual，少字节不冒更快，缺aggregate主动／token／费用就保未知，不填0或凭未超墙钟签合规。

“同方法”指承担当前因果前提的**具名专业工艺／供给／控制**，不能泛称“查证、读资料、编程、继续研究”。取材方法仍能用，不代表被反证的专业路线或供给还能续额。来源覆盖不足与整条工艺失败分别定位，停止依赖已败前提，不一律停止所有合法学习动作。

- 一次脚本跑5组×5张是25个候选；一个工具调多条查询按实际查询条数计。请求失败也计已发生调用／投入，取消不退已支出。
- 同一对象多视角／裁切不冒独立设计；页数不冒来源多样性。多Agent读同原件的实际重复投入计父级，不冒新增专业证据。
- 启动前核用途、必要输入、已有支出／在途与预计展开。未证反复试法不足就缩批／改法；必要覆盖、不同设计方向或成熟生产不套小题上限，应按总负担主动安排足够的下一有限批次并执行，保旧账，不逐批等用户推动。真实费用／容量不足只限相应依赖，不能默默缩掉原目标。
- Token／费用有真实数据则记，未知写未知。预算不授新付费、外发、产品写入或发布权，已有真实授权按其范围使用。

<a id="stage-budget-decision"></a>
## 到限决定：重分配阶段或重置顶方案，实际接原目标

1. **先辨额度层级并保原账。** 在安全边界核当前成果/品质、失败、在途与未知；用户明确总额、费用及权限是真控制，已授权总额内的角色/阶段预留是计划，AI默认探路窗口是方法复核节拍。阶段/预留到0不证明父级总额实耗完；actual未知不填0，也不当成可用余额。换人/批次/方法不退款、不重置旧已用/失败/在途，未知操作先核终态，不重放。
2. **到限未达标就形成可执行决定，不先停父任务。** 作者与当前适用的真实独立F/A从同版原需、实际结果、专业方法/供给及总成本分别核下一投入；用户要求多AI时必须真实接通，不以自签、ACK或旧票代本次决定。依据足、关键前提仍成立且有信息/成熟生产价值，核在已有授权与有据可用额度内重分配足够且有限的下一阶段，覆盖完整作者工序、内容/逻辑、必要评审与消费，不切成几分钟回件后再停。新额度或新分配本身不证明原法可达。
3. **关键前提失败或反复低效，方案重评置顶。** 实际回完整目标、最早失配、成熟专业来源/工程和表示/控制/供给，比较有区别的可达路线，确定应换来源、工艺或架构后再给有限阶段与代表消费者；撤回依赖已败前提的旧续修/扩量，不靠新题名/额度复活。查源不足要实际补有区别路径，不写“重新学习”便算换路；原源/工艺已足只缺当前观察时，直接做完整首件，不机械重学。
4. **区分有据重分配与重复试法。** 对同一未证假设的重复探路，原初始窗口至多一次追加、至多原适用额50%的止损仍有效；它限制该重复方法，不限制父委托。用尽/无信息就按上条换决定；真实能力覆盖、实质不同设计或成熟生产按所需规模给足有限计划，不套该百分比或重设旧账。重分配核授权总额/已用/在途是否有据可用，actual未知不能假放余量。
5. **真总额/费用不足，实交具体续额请求。** 给必要完整里程碑、所需有限总额及角色投入、已知旧账/未知、预期结果/反证、替代方案和实际受阻动作，由有权者明确授予后再花；原账不能核清时仍可提出独立新授权请求，不把证明旧退款写成唯一出口。原适用F/A核请求有据和范围，不代用户批准。到限只约束对应方法/费用/动作，已授权且可行的独立工作继续；用户明确暂停/撤销立即守。
6. **决定必须接到真实后继。** 在原活接点保存双方/各职责实际同版意见与采用：本次重分配、方案重评或具体续额请求已真实交谁，原唯一作者实际收到并自主选择的第一制作/供给/消费者是什么；F核完整结果/后继，A核路线前提、额度/权限与代价。只报planner0、审计拒退款、未完成或父未闭不是出口。无能力实发/实做则保具体未接与解除信号，不冒已续；除真实外部依赖/用户暂停外，不能以阶段到限结束已授权推进。实际停止仍按[停止申请](task-continuity.md#continue-or-stop)，独立未证职责保未闭。

这是一份调用时的行为合同，未安装宿主级拦截器；记录、表格和自报符合不能证明执行。用真实动作、产物和[前后／正常／反例](comparison-and-regression.md)核回实际效果。

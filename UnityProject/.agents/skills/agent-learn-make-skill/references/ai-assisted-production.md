# AI生图与临时批量脚本：进入真实工序

需要视觉供给、原生作者自动化或批量制作时读本页。专业视觉任务默认主动取得并使用高质量素材，将适用的生图／受控编辑和临时批量脚本接入主工序；按实际帮助选取得、生成或原生制作，不以“尚非不可替代”长期推迟。按[受控学习](learning-control.md)分别计划设计探索、未证校准与成熟扩量的足够数量、成本和分批；费用权限、资源与unknown作业保真实边界，不重放。无位图／批量需要的任务正常用其合适媒介，不机械凑生成量。

## 生图承担具名生产职责

从完整目标选具名用途：概念／母图校准整体设计，插画／物件／纹理／遮罩供后续组合，受控编辑修已辨问题。先核已有源与正常证据；精确文字、数字可保独立矢量层，不据此排除其它设计／素材职责。有适用且已授权可行的生成／编辑职责就实际调用并消费；完整目标已有充分依据的SVG／代码／模型工艺仍可直接用，不强制换媒介，也不默换简陋占位。

生成前将项目身份、风格/形态、尺寸/透明/通道、分层/可编辑需求、使用位置和不变项进提示。分清参考/编辑目标/其它输入，编辑本地图先亲看原图。指定文案/对象不擅改；整体未定时可用受控候选探索设计；先明确要减少的未知与保持项，不能把未选的草图当成生产基准。选定后先核代表母图/部件能承担必要品质，再依赖它扩量生产。

沿宿主真实工具合同执行；已装适用生图Skill时读其规则。原生工具可用优先用，不假设API key，不因batch改走额外CLI，失败不擅换供应商/付费路径。unknown/超时先查原作业/输出，不重复已完成生成。缺工具/权限仅限该依赖，查同质量可用供给/方案，不降原需。

亲看原尺寸输出，核形体、材料、主次、alpha/边缘、文字/身份和不变项。返修针对已辨原因，不盲抽到差不多。生成成功不签动画/拓扑/rig或商业品质；动态由材质/shader、网格、时序/偏移与状态组织等工艺承担，静态母图不替动态。

选中原件落项目授权资源根，保提示、参考/输出身份、来源/许可边界及版本；接实际材质/控件/场景、导入/构建参数并看完整结果。保母图、部件和再编辑/重建路线，不只留flattened截图。未选变体不冒采用，改源影响另核。

## 受控候选用于形成设计决定

适合生成、补绘、可编辑分支或比较时主动选用。每批围绕能改变选路的未知，固定必要视角／尺度／输入及观察条件；耦合的轮廓、结构、材质或时序可成组探索，不机械扫值。数量由要覆盖的有效设计差异、实际授权和充分计划决定，不能以4候选当所有设计的总上限；一调用展开多组按实际候选计。未定稿可有界探索，有依据则收敛回作者源，代表完整结果未核不得扩生产量。

分开不同用途的图、同一模型多视图与真正独立的可编辑方案；同一输出重复截图不算多个方案。比较实际差异、收益/损失和后续可实现性，AI评价只辅助筛选，不以综合分取代原件。生成仅改善外观而没有解决内部结构时，改输入/任务定义，必要时亲看当前模型截图后定向补绘，并在原生结构核实现，不能继续堆设定图。保被选/淘汰理由及仍未知处，选中方法进入实际制作。代表工序与必要品质足证后，按真实需求主动展开明确的生产批次，复用已有有效证据，不逐件重求生产许可。以吞吐／耗时、资源、成本、品质一致性和返修／恢复核目标规模；首批3对象只校准未证工序，不是长期产能上限。失败的共同前提暂停其依赖扩量，修责任源；不把检验当永远不生产的理由。

## 临时脚本可做作者动作，不只检查

工序/控制明确后，可即时写小脚本执行原生编辑器API、批量形体/参数实例、层级/布局装配、导入导出、变体输出与核查。脚本可承担实质制作；临时不等粗糙，也不为一次工作搭永久框架。有可用入口就复用，确有缺口再补。

运行前接读写对象、控制怎样映射项目要求、保持项、前提和观察。探索批次先核比较是否有效，生产复制先核目标内代表对象，再扩大；控制不足则改工艺/表示，不用更大循环/更多随机项/更密常数包办设计。只核误差/格式的脚本按诊断限域。

遵守项目写域、备份/恢复、数据所有权、工具合同及图像编辑限制。原生源可回改，顶点对应/权重/shape keys/许可等变化明示损失/迁移，不静默丢弃。不得复制业务/算法权威，批量错误不吞失败/伪造成功或退默认值求绿。

保实际入口/命令、输入、源改动、输出和必要失败，读回项目结果而非只看退出码；按风险/差异核关键组合，不按固定样本数免责。碰壁查真实错误/版本/控制能力及一手方案，修对应入口后回作者动作，不把API修通当制作完成。

一次性脚本可留原工作区供追溯，不强塞目标Skill；成为重建/消费必要入口或确有复用收益时，连参数/依赖/恢复写入。交接不依赖即将清理的唯一临时文件或隐藏人工步骤。

## 组合到成熟工艺

例如生成合适UI母图/部件→原生可编辑控件装配→批量状态/尺寸适配→shader/动画表达具名反馈→实际连续操作与阅读；或参考母图校准角色→充分控制的原生工序改目标→批量已明确部分→早变形反馈。按项目选择，不为展示工具新造业务。

AI方案仍待核；保专业依据、项目独特约束、下一作者动作和反馈。模型声称工业级、生成张数、脚本规模及文件绿灯均不认证能力；必要专业/用户反馈按真实效果取得。

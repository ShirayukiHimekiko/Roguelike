# 选路线：每个目标特征由哪种做法产生

**结论：** 路线就是一张表：`TARGET.md` 里的每个特征，分别由哪种做法、哪个可调参数产生。选路线看三件事：能不能做出**目标风格**的这个特征，作者能不能直接调，带来的复杂度值不值。“技术更高级、更物理”不是选它的理由。写第一行制作代码之前，先把这张表写进 `TARGET.md`，再用一张粗画面验证最关键的那一两条。

**为什么：** 实际案例里，目标是原神、鸣潮级的二次元水，AI 选的却是写实水的路线：物理波、平面反射、深度重建。结果有两个：
- 风格特征（成型泡沫带、硬边条带高光、分明的色阶）在这条路线里没有对应做法，从计划阶段就不存在；
- 复杂子系统接连出技术 bug，连续 5 版都在修深度时机、屏幕 UV、相机穿地，主画面几乎没变。

路线错了，修得越认真，离目标越远。

<a id="route-table"></a>
## 1. 先写“特征 → 做法”表

每个特征一行。每行至少要有 2 个候选做法，标出来源，再写在并排图上怎么验证。示例，二次元水的常见拆法（具体作品怎么做的必须查证，不能当作已知）：

| 特征（来自 TARGET） | 候选做法 | 来源类型 | 作者调什么 | 怎么验证 |
|---|---|---|---|---|
| 近→远分明的色阶 | ① 按水深或距离查一张**分段色带**（ramp 贴图或几段颜色阈值）；② 连续渐变加色调分离 | 风格化水的拆解文章、Shader 教程 | 色带颜色、阶数、每阶宽度 | `look` 缩小后能数出几阶，和参照比较 |
| 岸线泡沫带 | ① 深度差阈值加噪声扰动（硬内缘、碎外缘）；② 沿岸线的距离场或顶点色控制宽度 | Toon water 教程、工程源码 | 宽度、硬度、噪声频率、推进速度 | `measure --line` 量带宽占画面高的百分比和边缘硬度 |
| 硬边条带／星点高光 | ① 高光强度做阈值或分段（step）；② 闪烁贴图（sparkle）沿视线方向采样 | 风格化光照拆解 | 阈值、条带方向和长度 | `look` 边缘图上高光是硬边，形状是条带 |
| 透底和浅水可见 | 深度衰减透明度加轻微折射偏移 | 水体 Shader 拆解 | 透明深度、折射强度 | 近岸能数清石底 |
| 倒影 | ① 反射探针或天空盒加菲涅尔（便宜、稳定）；② 屏幕空间反射；③ 平面反射（准，但最复杂） | 视参照而定 | 反射强度、被波纹打断的程度 | 参照里的倒影是完整镜像还是被打断的碎片 |
| 流动或波纹 | 流向图（flow map）驱动法线或纹理；低幅顶点波 | 风格化水教程 | 速度、方向、尺度 | `motion` 看方向和周期 |

“作者调什么”填不出具体值时，用 `scripts/numspec.py engine` 把目标色换成引擎值（Color 用 sRGB、Vector 用线性，可出色带贴图），`world` 把“泡沫宽约画面高 1.5%”这类屏幕量换成米。换出来的是起点，仍要在主机位并排图上看对不对。

## 2. 核来源：风格目标要用风格来源

- 每个特征的首选做法，依据要来自**风格本身的拆解**：作品分析、TA 分享、风格化 Shader 的工程源码。
- 写实来源（物理波、FFT 海洋、物理光照）只用来解决子问题，例如波形不能自相交。不能用它们决定“做成什么样”。
- 自查：首选做法的来源一半以上是写实或技术向的，就说明路线大概率选偏了，要先补风格来源，再定路线。

## 3. 复杂度要有理由

- 每个复杂子系统（平面反射、深度重建、多相机、后处理链），都必须对应 TARGET 里**某一条具体特征**，并且说明更简单的做法为什么不够。
- 说不出对应哪条特征，就不上。复杂子系统是 bug 的主要来源，会把波次耗在技术修复上。
- 能用便宜稳定的做法达到参照效果时，优先用便宜的。例如参照里的倒影本来就被波纹打得很碎，用反射探针加扰动就够了，不需要平面反射。

<a id="route-probe"></a>
## 4. 路线探针：先验证最关键的特征

- 定路线之前，挑最决定“像不像”的 1–2 个特征（通常是色阶和泡沫带，也就是缩小后最显眼的大关系），用最便宜的方式做一张完整粗画面。
- 用 `look` 和参照并排，看缩小后的大关系是否开始接近。
- 两个候选路线都做一张，选缩小后更接近的那条。探针最多一波，不追求细节。

## 5. 定下来并写进 TARGET

在 `TARGET.md` 末尾加“路线”一节：特征、选定做法、主要参数、为什么选它（来源）、什么情况下要换。之后每波开头的“本波推进哪条差距”，就是推进这张表里的某一行。

<a id="route-change"></a>
## 6. 什么时候必须重新选路线

出现下面任何一条，停止当前路线上的细化，回到第 1 节重新评估。评估结果写成一句话告诉用户：

- 美术陪审连续两版回答“没变”或“更远”；
- 连续两版主机位没有可见变化；
- 缩小后的大关系仍然不像，而细节在变好（说明在错误路线上打磨）；
- 某条 TARGET 特征在当前路线里找不到做法；
- 连续两波主要时间花在路线自带的技术问题上（例如反射对位、深度时机），而这个子系统对应的特征并不重要。

换路线不是失败。已经证明有效的部分（资源、相机、证据工具）照常复用。

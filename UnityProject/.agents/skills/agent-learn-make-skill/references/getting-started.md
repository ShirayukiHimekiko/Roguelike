# 安装好了，怎么开始？

在 Codex 中打开你要学习的项目，下一轮直接输入：

> 用 $agent-learn-make-skill 深入学习这个项目，自行寻找工作区，持续沉淀到可用 Skill，已有就继续完善并回归。

不在该项目里时，把工程、原作或资料的实际路径加到句子里即可。无需先填表、指定输出目录或逐步喊“继续”。学习对象或访问权限确实不清楚时，Agent 才补问必要信息；有可行的授权工作会先做。

它按[八个学习步骤和行为预算](learning-control.md)推进：定目标／摸底、查源比较、拆解范例、原条件重现、带质疑判别、异需整合、回归核查、沉淀再调用。每步有实际产出及转序依据；检索、阅读、探测、实验、生图、批量和返修等先有有限额，同问题跨恢复／换人不清零。到限须对账、质疑和改法，不能无限尝试或降低目标；成熟方法与已有证据可直接复用相应步骤，不需要你逐步批准。

完整目标和成熟工艺决定主要投入，独特需求进入作者源／工序；关键未知主动查证、先预测再动手。每次实质修改后及扩量前先核风险与正常，采用前再核完整消费者。需要时用生图和临时脚本承担真实制作；工程还学作者完整系统的工作分解、规模／表示及耦合，不被下一个局部小问题牵走。中文作者呈现、简洁统一API、广泛扩展和不降级拟合保留；方法文字、实际选择、实际执行与专业结果分开取证。

常用说法：

- 新建：`用 $agent-learn-make-skill 学习 D:\项目\作者工程，把这套流程沉淀为可复用 Skill。`
- 维护：`用 $agent-learn-make-skill 根据这次失败和新的源工程，继续完善已有 Skill，并回归旧用法。`
- 接续：`用 $agent-learn-make-skill 从已有工作区记录接着完成上次目标。`
- 应用成果：`用刚生成的那个 Skill 完成这个新任务，把新发现接回维护。`

无需另装陪审或固定工作流；适用且可用的评审可以正常协作。真实权限、必要人工操作或访问缺口仍会说明；宿主硬中断时通过文件接回，不是后台训练模型或永久运行服务。

安装/更新程序会告诉你实际落位。可用 `/skills` 或 `$` 查看是否发现；未出现时核宿主的 skills 目录，必要时重启。也可直接让 Agent 读取实际安装目录里的 `SKILL.md` 执行同一任务。文字学习不要求 Python；只有需要机械检查脚本时，再配置 Python 3.10+ 和包内 `scripts/requirements.txt` 的依赖。

想重看可随时问“介绍用法”，或在解压包运行 `Install.cmd -ShowGuide`。安装器在首次成功时显示本页；其它复制安装方式不产生这个安装事件。引导只帮助开始，不要求完成教程、登记或确认后才处理任务。

# 方法依据及证据范围

需要核学习步骤／比较风险设计的来源时读本页。下列原文已于2026-11-01实际取得；支持的是方法设计依据，不证明AI预算数字最优、LLM已形成专业能力或权重发生学习。

| 一手来源 | 原文支持的关系 | 本Skill采用及边界 |
| --- | --- | --- |
| [IES／WWC：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 完整解例与问题练习交替、测验／提取、深层解释及间隔回顾等教学建议；各项证据强度不同。 | 先拆范例再自己预测／操作、随后查错及变条件回顾。研究对象是人类学生，不将建议直接认证为AI效果，也不为了间隔而等待。 |
| [CMU Eberly Center：Learning Principles](https://www.cmu.edu/teaching/principles/learning.html) | 分项技能、整合及何时使用共同构成掌握；目标导向练习配针对性反馈；监控和调整学习方法。 | 分清重现、判别和异需整合，让反馈实际改下一动作；不以复述熟练代设计能力。 |
| [NASA Systems Engineering Handbook §6.4 Technical Risk Management](https://www.nasa.gov/reference/6-4-technical-risk-management/) | 风险的场景／可能性／后果及不确定性，缓解触发、状态跟踪和行动效果。 | 依赖制作前明确最弱前提、损失、试验和恢复；按领域裁剪，不套NASA审批、航空规范或虚构概率。 |
| [NASA Systems Engineering Handbook §6.8 Decision Analysis](https://www.nasa.gov/reference/6-8-decision-analysis/) | 对目标、评价准则、替代方案、不确定性和后果作相称分析；并非每个决定都需同样分析投入。 | 同口径比较可信方法，有足够证据即采用；不要求凑方案／评分，不把任意分钟数称NASA标准。 |

[受控学习](learning-control.md)的八步、计量单位、整数／时间窗口和一次延长是本次用户要求下的**操作约定，待真实使用校准**。采用依据是限制无信息循环、促成实践和可回接；实际有效性须用[真实消费与回归](comparison-and-regression.md)观察。方法内容、指令可用性、小任务执行、广泛工业能力和科学因果收益分别声明。

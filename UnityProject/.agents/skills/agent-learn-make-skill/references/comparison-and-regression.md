# 比较、质疑、风险与多次回归

与[受控学习](learning-control.md)一起读；共同步骤和所有行为预算只在该页定义。本页说明怎样查，不重复增加轮次或签字。目标是使反证改变操作，不能用填表代学习、用测试条目代完整品质。

## 关键动作前：先问哪里最可能错

定主路线、修改关键解释／方法、恢复、生成／扩量及正式采用前，在原接点留下简短可核判断：

1. 当前最弱的必要前提是什么，依据来自原作者、实现／观察还是AI假设？设计判断和实际编辑控制是否分别成立？
2. 最有力的相反解释或合法失败条件是什么？出现什么可观察结果就撤回当前选法／操作？已有反例不能被忽略。
3. 若本次失败，损失会到哪些源、旧正常、消费者或费用？怎样隔离、保原件、恢复；未知终态怎样核？
4. 做哪个能改变当前决定且覆盖必要关系的查证／实践，用什么基准？艺术干预按[作用链](workflow-learning.md#art-causal-model)先留局部／全局预测、混杂及保持项，依有效源安排有判别力的大调后微调与新条件；规模按本题选足，不把固定次数或盲扫当完整。剩余风险限制哪项真实依赖？

对不变前提复用有效旧证，不逐文件重写。风险按“触发场景→可能后果→现有证据／不确定性→缓解与验证→恢复和剩余风险”表达；没有数据不编概率或风险分。可能造成关键品质、数据、接口或费用损失的前提未证，先隔离核它，再允许依赖扩量；不扩大到无关工作停摆。

工具确能启动、参数确可动、脚本exit0都不能回答“知道怎样设计”。前提被反证就回承担的设计、表示／控制、供给或执行层；不能以微小技术收益为失败主路线续期。

<a id="independent-first-result"></a>
## 首次解释与结果的独立核验

本人及其它AI的首次需求解释／选法／方案／判断／产物先为不可信候选；保用户授权与已证事实。把同原话、对象／版本、原件和已知风险交真实不同AI，先据原需找能推翻的合法条件并核证，再对照作者解释；保首稿、真实暴露、支持／反证及条件，逐命题采用、修正或限制依赖动作。已有适用职责就接原人，普通学习只接必要单独立核，不启全套陪审、不自演或递归第三审。

这与下文复杂方法的独立正向试用不同。确缺独立能力或必要结果未核，候选仍未证，只限依赖它的采用／扩散／交付／完成；读原件、诊断、隔离候选及已证独立工作继续，不自审晋级或全局停工。适用原评分合同时，必要未核结果按原制给负整数并说明缺口；无合同不新建评分器，可信支持不换算增益／固定概率。

## 学专家，再自己预测，再查自己的错

深读完整范例后，不继续照着答案抄一遍摘要。先给新条件下的简短操作／结果预测或自己完成一段可检查操作，再回原件和实际结果核：漏了什么前提、混了什么单位／状态、什么只是表面相似。只需外部可检解释，不要求输出冗长内部思考。

重现先保原条件，随后才作能辨机制的变化，最后在真实异需中组合使用；三者分别证理解／供给、因果条件和方法迁移，不互相替代。成熟已证方法可以直接进入相应实践；不能为了表演“质疑”虚构竞争理论。

每次有信息的失败要改一项解释、选法、输入／控制、恢复或当前主动作。若只新增“谨慎／未完成”而下一轮仍做同一不能解除核心差距的局部，整改未落实。

## 真对比：先定口径，再看结果

有会影响选择的可达成熟替代时，将当前基准和可信替代放同一任务比较；如果既有方法有充分依据且没有有效替代，不强造多方案。比较的制作／生成支出按实际动作记预算，不能藏在“分析”里。

| 要固定／交代的关系 | 实际核什么 |
| --- | --- |
| 目标和评价准则 | 原需完整结果、决定性品质、可修改性、成本、消费和恢复；不能事后挑赢的指标。 |
| 输入和版本 | 同原件／需求、配置和工具版本；不能拿不同问题的成功截图作同口径改进。 |
| 观察条件 | 合理统一视角／尺度／速度／负载／环境；确不可统一则说明不可比项，保结论边界。 |
| 实际差异 | 原始结果或源、收益、损失与失败条件；引用原件位置，不只报综合分。 |
| 采用／淘汰 | 为什么能解除当前主差距，下一作者源／动作是什么，出现什么就重新选择。 |

同输出换截图／裁切不是新方案；多个镜像教程不是多样来源。只看作者推荐／AI评语不算比较。失败的替代也可提供有价值的边界，但不能从“其它也失败”推出当前已达标。

## 四个回归时点

| 时点 | 必须核到的实际关系 | 允许下一动作的条件 |
| --- | --- | --- |
| 起步／恢复 | 当前原失败、已有正常、所读版本／配置和在途状态 | 真实基线可找，旧证仍适用或已注明失效；不能从旧通过推当前通过。 |
| 每次实质修改后 | 原坏例、受影响旧正常和新条件；先预测再看实际结果 | 改动确改应改处且没有已见退化；正常失败回原责任修。 |
| 整合／扩量前 | 代表完整作者动作、关键组合、风险和下一消费者 | 必要控制和品质依据成立；不能先铺量再用小样免责。 |
| 沉淀／采用／交付前 | 受影响完整链、新需求使用、失败恢复及当前源／包／安装 | 方法与实际消费一致，必要否决由原职责核回，完整委托有覆盖。 |

这些是触发点，不是全项目重复运行次数。相同版本、输入和作用条件未变的有效证据可复用；每次变更重新判断影响关系，不借“只改文案”排除AI行为变化。

## 选什么例子，怎样判

- **原坏例**：原失败机制及输入不被换掉。新预填修法样件只证执行，不能关原选法／迁移失败。
- **合法正常**：保原来有价值的工艺、参数、程序化、中文呈现与简单调用；不能靠永久拒绝、删功能、吞错或排掉正常条件求绿。
- **新条件／边界**：选择会改变方法判断或揭露组合问题的变化；有依据排除无影响处，不穷举所有值。
- **消费者与恢复**：适用时实际保存／重开／重建／连续使用、取消／恢复；专业动态／声音仍用连续观看／听评，静帧和峰值不能代替。

一份样件可覆盖多项，但逐项说明它真的暴露什么；案例数量不是能力分数。保输入／原件、应有结果依据、实际命令／操作／产物、差异和处置。只跑检查器／标题匹配不证方法能用；只给场景推演不冒实际运行。

复杂方法或重大修订，在授权且原生分工可用时做独立正向试用：只给真实需求、Skill和最少原材料，不给期望工艺／修法答案／评审结论；已知严重失败和安全事实照常共享。亲核其所读版本、实际动作与产物，记录提示依赖及失败。没有独立使用者就保实际自验范围，不编造通过或把缺角色变成所有调用前置。

修正后核原反例与正常对照，结果改变再更新现行方法及下一动作。已有足够依据就回必要制作／采用；不以“多回归”为由无信息复审。预算到限按受控学习到限程序处理，不能删除未闭、弱化期望或冒完成。

## 视觉结果的比较：并排图优先

怎么看、怎么判断风格像不像，按[看图方法](visual-judgment.md)做（先描述后判断、眯眼看大关系、量颜色、看边缘形状、自我校准）。

视觉、动画、UI 等结果的每次回归，先生成 **[参照 | 当前版 | 上一版] 并排对比图**（`python -X utf8 scripts/refgrab.py compare 参照.png 当前.png 上一版.png --labels "参照|vN|vN-1" --out cmp.png`），再看原尺寸全图和局部。逐条对照 `TARGET.md` 的特征，标“达到 / 接近 / 未达”，然后重新给差距排序，选差距最大的 3 条作为下一轮目标。参照应是用户点名对象的实机画面；暂时拿不到时用用户给的或本地已有的参照并标出缺口，照常推进。固定机位、光照、时间和随机种子，保证前后可比。连续两版主机位没有可见变化，就停掉当前技术线，见[什么算前进了一版](intent-and-drift.md#forward-progress)。技术伪影可拉最小场景复现，但最多一波，修完回完整作品用同一组机位复核，完整作品里没变好就不算修好。动态效果另看原速录像，截帧只用来拼对比图。

# 专业作者作业：从来源到完整作品

本页承担实际设计、编辑、观察和返修；题目/下一投入由[workflow-learning](workflow-learning.md#next-author-work)选择，供给/配置/入口/终态由[source-to-automation](source-to-automation.md)承担。沿既定八步骤和本批有限授权执行；普通应用复用已成立关系，深学补缺失证据，不另开通用检查工程。

## 本批完整作者作业

1. **选一个能承担主要差距的完整作品。** 从真实使用意图确定整体主次、邻接/分合、空间/时间或业务关系及保持项。专业目标决定工序；当前脚本可调什么不能倒定题。成熟设计方法/控制有据，仅缺当前组合就直接做首件。
2. **把成熟来源变成设计决定。** 亲读作者完整过程及必要原件，区分作者理由、实际工序、自己推断。定位哪一操作能改变哪一目标关系及失效条件。只有工具/API补设计判断，只有效果图补实际可编辑控制，缺原操作史如实保未知，不补写手工经历。
3. **在真实源上编辑。** 用原生可编辑表示和获准供给完成主体组织及必要细节；保源到导出/导入/消费的重建路线。事前给预期变化/保持与可推翻观察，成熟工序不为形式逐参数做实验。必要技术修通后立即回主体。
4. **看完整结果并辨原因。** 同时核整幅/完整流程及关键局部，适用才看连续原速、视角、实际尺寸/逆色/目标负载或听感。视觉元素与载体、保存值与有效值、局部变化与整体价值分证；可比关闭/替换/中性化和有据粗调→细调服务关键未知，不全参数扫或固定N。关键组合/未拟合条件先预测，失配改方法和下一操作。
5. **返修承担层并交消费者。** 执行/绑定错误修原入口；专业设计、表示或供给失败回对应作者工序，完整失败不靠局部收益续签。保存/重开、导出、独立消费与受影响正常各核对应事实，机械passed不认证专业品质。
6. **把本次经验用于另一需要。** 修目标领域Skill现行选法、控制/单位/耦合、有效条件、代价/反例与恢复入口；再接结构、语义或使用条件改变的新需求，由后继重新选择、实际编辑并消费。原条件重现、机制判别、异需迁移各保证据，不以换色/缩放独自证明能力。

每步进入、产出和失败回点沿上述实际依赖，局部可复用不重演。完整源/作品/观察和现行方法接原活记录，足证即后继；没有专业供给或必要感知时只限依赖项，不冒全领域P0解除。

## 来源怎样进入设计与有效控制

亲读用户内容、作者完整作品/过程、工程与真实场景。身份/风格/比例、形态/主次、文案/行为、时间/状态、平台成本、可编辑性和交付接口，须改变对应工序、供给、参数/结构和观察。区分用户硬项、原作关系、作者解释与自己的假设；影响结果又不可查的歧义才最小澄清，不能自定语义后无条件称完成。后到澄清实际改源/方法并复核，符合部分复用，保旧假设。

专业设计和编辑控制分别取得：为什么这样组织，源上改什么产生目标关系，如何看够用，失败回哪层。只有API能动不证会设计陌生需求；只有好图/工艺名不证能编辑到。缺设计补作者判断，缺控制补成熟表示/工艺，有据工序只缺当前组合就做首件。权威来源与工具启动不代这些命题；索引只定位，不让AI按标签补工艺。

底模改型、雕刻、曲线、手绘、参数化或程序化按差异组合，不把厚肩/high roll、DCC、灰模或固定层数升为通用美学门槛。必要换表示/重网格时保旧源、顶点对应、权重/shape keys迁移与重建，不静默丢数据。作者没保存人工过程就保未知，自己的事后实验不能冒其经历。

## 把源操作与完整表现联起来

参数取真实保存/运行有效值、类型/单位/曲线/耦合与关键时刻；素材取轮廓、纹理通道/alpha、拓扑/枢轴、声音及加工；组织取整体主次/分合/邻接/流向、空间分布、出生/退出、事件/局部时钟、峰值接力/遮挡/过渡；架构取原生源→导出→导入/实例→材质/骨架/事件绑定→运行/释放→再编辑。成本沿真实负载核，层数少/半径小/参数正确不普遍更美或更快。

视觉/业务元素不等物理层、参数或节点；先核它由哪些有效控制共同承担。沿源与有据变体形成响应关系：意图需要什么，哪些操作直接改变，哪些须保，经共享素材/状态/空间/规模又影响哪里。关键未知用[作用链与干预](workflow-learning.md#art-causal-model)核局部/全局、空间/时间与混杂/连带项。用户“关”按原话/源选真实关闭、替换或中性化，不假设所有元素可开关；有据先粗调再细调，可比条件保镜头/光照/时间/随机，不盲扫或编精确值。

偏分短发需落实整体比例、露面、分缝和主发量，鼻点或增加发片不独自承担；UI受理不等完成，强调/材质/声音服从业务含义与连续输入；定向重击与持续范围提示需要不同轮廓、峰值和退场。这些示范关系，不是通用清单。其它工程毫米数、voxel、权重/阈值及随机范围保尺度/分辨率/姿态条件，不直接移植成设计。

## 原件、观察与返修的真实范围

先核对象/供给/执行，再辨设计、表示/控制、装配/形变、素材或观察缺口。完整静态已败须修专业承担，不能拿缺动态宿主解释；静帧不签原速自然度，峰值不签听感，编译/保存重开不签设计价值。关键新镜头/时间/输入/需求先预测再观察，失配改当版关系、条件和第一操作，不事后改预测。条件经验可保经验性方法，机制未全解释不必丢掉，也不冒因果已证。

数值/临时脚本服务选域、空间、权重、接触/投射、残差、精度和批量作者操作，答够原命题即回主体。误差下降/数组exact/Bezier可动只证技术事实，不续签已败整体设计。专业原件已读却未进主作者操作就实际改承担层，不再交同义说明。早期表情/姿态、组合/连续输入按工艺参与反馈，不等最终才首次暴露，也不冒全rig/全流程完成。

保可比前后、完整原件、可编辑源、输出与真实消费者；指定MyTA等入口时沿其发现/选择/制作/重建/消费，不复制第二渲染器/状态权威。正式产品暂停则在许可的相关隔离源学习，样件承担同一目标，不冒正式采用。原条件重现、机制判别、异需整合各自取证；核心身份失败，下一主操作须能有意改变原差距，成熟局部收益按用途保留，不另选容易小题结案。

## 规模生产与方法迁移

学习参考不自动是生产素材：取得用途有据原件，保出处/版本/许可，编辑加工→装配/导入→消费→返修/重建。生成/返修按[ai-assisted-production](ai-assisted-production.md)承担工序并消费，不交网址、任意占位或母图代整链。替材保品质/控制，缺侧具名继续补。

按真实品类/变体/数量、平台和品质安排足量有限批，复用共同准备和少量语义入口，保各对象必要控制。代表工序成立再分批生产、检查及定向返修，核峰值资源、吞吐/总成本、一致性和断点恢复；几个变体不冒产能，也不先全量生成后抽样免责。陌生复杂需求中的选法、精修、组合、排障和迁移逐步建能力，不靠批量数/称号毕业。

每段将成立条件、感知/使用目的、具体操作/单位/耦合、方向/副作用/成本、反例及替代/恢复修入后继会读的领域Skill，接真实新需要。等比缩放/装饰/熟悉底座不独自证明迁移；有据配置确实改变完整目标关系可正常使用。领域/商业品质和原P0未证就保必要未闭及下一作者作业，文字、报告、认错或意见一致不代效果。
